## Pipelines सोबत काम करणे[[working-with-pipelines]]

<Youtube id="tiZFewofSLM" />

🤗 Transformers library मधील सर्वात basic object म्हणजे `pipeline()` function. हे model ला त्यासाठी आवश्यक असलेल्या preprocessing आणि postprocessing steps सोबत जोडते. त्यामुळे आपण थेट कोणताही text input म्हणून देऊ शकतो आणि समजण्यास सोपे answer मिळवू शकतो:

```python
from transformers import pipeline

classifier = pipeline("sentiment-analysis")
classifier("I've been waiting for a HuggingFace course my whole life.")
```

```python out
[{'label': 'POSITIVE', 'score': 0.9598047137260437}]
```

आपण एकाच वेळी अनेक sentences देखील pass करू शकतो!

```python
classifier(
    ["I've been waiting for a HuggingFace course my whole life.", "I hate this so much!"]
)
```

```python out
[{'label': 'POSITIVE', 'score': 0.9598047137260437},
 {'label': 'NEGATIVE', 'score': 0.9994558095932007}]
```

By default, ही pipeline English मधील sentiment analysis साठी fine-tuned केलेले एक विशिष्ट pretrained model select करते. तुम्ही `classifier` object तयार करता तेव्हा model download होऊन cache केला जातो. तुम्ही command पुन्हा run केल्यास cached model वापरला जातो आणि model पुन्हा download करण्याची गरज पडत नाही.

जेव्हा तुम्ही pipeline ला काही text देता, तेव्हा त्यामध्ये तीन मुख्य steps असतात:

1. Text वर preprocessing करून तो model ला समजेल अशा format मध्ये बदलला जातो.
2. Preprocessed inputs model ला दिले जातात.
3. Model च्या predictions वर post-processing केले जाते, ज्यामुळे त्या predictions चा अर्थ समजून घेता येतो.

## वेगवेगळ्या modalities साठी उपलब्ध pipelines

`pipeline()` function अनेक modalities ला support करते. त्यामुळे तुम्ही text, images, audio आणि अगदी multimodal tasks सोबतही काम करू शकता. या course मध्ये आपण text tasks वर लक्ष केंद्रित करू, परंतु Transformer architecture ची क्षमता समजून घेणे उपयुक्त आहे. त्यामुळे त्याचा थोडक्यात आढावा घेऊया.

उपलब्ध pipelines चा आढावा खाली दिला आहे:

> [!TIP]
> Pipelines ची संपूर्ण आणि updated list पाहण्यासाठी [🤗 Transformers documentation](https://huggingface.co/docs/hub/en/models-tasks) पहा.

### Text pipelines

* `text-generation`: Prompt पासून text तयार करणे
* `text-classification`: Text ला predefined categories मध्ये classify करणे
* `summarization`: महत्त्वाची माहिती कायम ठेवून text ची छोटी version तयार करणे
* `translation`: Text चे एका भाषेतून दुसऱ्या भाषेत भाषांतर करणे
* `zero-shot-classification`: विशिष्ट labels वर आधी training न करता text classify करणे
* `feature-extraction`: Text चे vector representations extract करणे

### Image pipelines

* `image-to-text`: Images चे text descriptions तयार करणे
* `image-classification`: Image मधील objects ओळखणे
* `object-detection`: Images मधील objects शोधणे आणि ओळखणे

### Audio pipelines

* `automatic-speech-recognition`: Speech चे text मध्ये रूपांतर करणे
* `audio-classification`: Audio ला वेगवेगळ्या categories मध्ये classify करणे
* `text-to-speech`: Text चे spoken audio मध्ये रूपांतर करणे

### Multimodal pipelines

* `image-text-to-text`: Text prompt च्या आधारे image ला response देणे

चला, यापैकी काही pipelines अधिक सविस्तरपणे पाहूया!

## Zero-shot classification[[zero-shot-classification]]

सुरुवातीला आपण एका अधिक challenging task वर काम करू, ज्यामध्ये आपल्याला label न केलेले texts classify करायचे आहेत. Real-world projects मध्ये ही एक common situation आहे, कारण text ला annotate करणे सहसा वेळखाऊ असते आणि त्यासाठी domain expertise ची आवश्यकता असते.

या use case साठी `zero-shot-classification` pipeline खूप powerful आहे. यामध्ये classification साठी कोणते labels वापरायचे हे तुम्ही स्वतः specify करू शकता. त्यामुळे pretrained model मधील labels वर अवलंबून राहण्याची गरज नसते.

आपण यापूर्वी model ला positive किंवा negative या दोन labels च्या आधारे sentence classify करताना पाहिले आहे — पण model ला तुम्हाला हवे असलेले इतर कोणतेही labels देऊनही text classify करता येतो.

```python
from transformers import pipeline

classifier = pipeline("zero-shot-classification")
classifier(
    "This is a course about the Transformers library",
    candidate_labels=["education", "politics", "business"],
)
```

```python out
{'sequence': 'This is a course about the Transformers library',
 'labels': ['education', 'business', 'politics'],
 'scores': [0.8445963859558105, 0.111976258456707, 0.043427448719739914]}
```

या pipeline ला *zero-shot* असे म्हणतात कारण ती वापरण्यासाठी तुम्हाला model ला तुमच्या data वर fine-tune करण्याची गरज नसते. तुम्हाला हवे असलेल्या कोणत्याही labels च्या list साठी ती थेट probability scores return करू शकते!

> [!TIP]
> ✏️ **स्वतः करून पहा!** तुमचे स्वतःचे sequences आणि labels वापरून experiment करा आणि model कसा behave करतो ते पहा.

## Text generation[[text-generation]]

आता pipeline वापरून text कसा generate करायचा ते पाहूया. यामागील मुख्य कल्पना अशी आहे की तुम्ही एक prompt देता आणि model उर्वरित text generate करून तो prompt auto-complete करते.

हे अनेक phones मध्ये उपलब्ध असलेल्या predictive text feature सारखे आहे. Text generation मध्ये randomness असते, त्यामुळे खाली दाखवलेल्या result प्रमाणेच result प्रत्येक वेळी मिळेलच असे नाही.

```python
from transformers import pipeline

generator = pipeline("text-generation")
generator("In this course, we will teach you how to")
```

```python out
[{'generated_text': 'In this course, we will teach you how to understand and use '
                    'data flow and data interchange when handling user data. We '
                    'will be working with one or more of the most commonly used '
                    'data flows — data flows of various types, as seen by the '
                    'HTTP'}]
```

`num_return_sequences` argument च्या मदतीने किती वेगवेगळ्या sequences generate करायच्या आहेत हे तुम्ही control करू शकता. तसेच `max_length` argument च्या मदतीने output text ची एकूण length control करू शकता.

> [!TIP]
> ✏️ **स्वतः करून पहा!** `num_return_sequences` आणि `max_length` arguments वापरून प्रत्येकी 15 words असलेली दोन sentences generate करा.

## Hub मधील कोणतेही model pipeline मध्ये वापरणे[[using-any-model-from-the-hub-in-a-pipeline]]

मागील examples मध्ये आपण प्रत्येक task साठी default model वापरला. परंतु एखाद्या specific task साठी, उदाहरणार्थ text generation साठी, Hub मधील एखादा विशिष्ट model देखील तुम्ही pipeline मध्ये वापरू शकता.

[Model Hub](https://huggingface.co/models) वर जा आणि डावीकडे असलेल्या corresponding tag वर click करा. त्यामुळे त्या task साठी supported असलेले modelsच दिसतील. तुम्हाला [या page](https://huggingface.co/models?pipeline_tag=text-generation) सारखे page दिसायला हवे.

चला [`HuggingFaceTB/SmolLM2-360M`](https://huggingface.co/HuggingFaceTB/SmolLM2-360M) model वापरून पाहूया! आधीच्या pipeline प्रमाणेच हा model load करण्याची पद्धत खाली दिली आहे:

```python
from transformers import pipeline

generator = pipeline("text-generation", model="HuggingFaceTB/SmolLM2-360M")
generator(
    "In this course, we will teach you how to",
    max_length=30,
    num_return_sequences=2,
)
```

```python out
[{'generated_text': 'In this course, we will teach you how to manipulate the world and '
                    'move your mental and physical capabilities to your advantage.'},
 {'generated_text': 'In this course, we will teach you how to become an expert and '
                    'practice realtime, and with a hands on experience on both real '
                    'time and real'}]
```

Language tags वर click करून तुम्ही model साठी केलेली search अधिक specific करू शकता आणि दुसऱ्या भाषेत text generate करणारा model निवडू शकता. Model Hub मध्ये अनेक languages support करणाऱ्या multilingual models साठी checkpoints देखील उपलब्ध आहेत.

एकदा तुम्ही एखादा model select करण्यासाठी त्यावर click केल्यानंतर, तो model थेट online try करण्यासाठी एक widget उपलब्ध असल्याचे तुम्हाला दिसेल. त्यामुळे model download करण्यापूर्वी त्याच्या capabilities ची पटकन चाचणी घेता येते.

> [!TIP]
> ✏️ **स्वतः करून पहा!** Filters वापरून दुसऱ्या भाषेसाठी text generation model शोधा. Widget वापरून experiment करा आणि तो pipeline मध्ये वापरून पहा!

### Inference Providers[[inference-providers]]

सर्व models थेट browser मधून Inference Providers च्या मदतीने test करता येतात. हे [Hugging Face website](https://huggingface.co/docs/inference-providers/en/index) वर उपलब्ध आहे. या page वर custom text input करून आणि model input data कसा process करतो ते पाहून तुम्ही model सोबत थेट experiment करू शकता.

Widget ला power करणारे Inference Providers हे paid product म्हणूनही उपलब्ध आहेत. तुमच्या workflows साठी त्यांची आवश्यकता असल्यास ते उपयोगी ठरू शकतात. अधिक माहितीसाठी [pricing page](https://huggingface.co/docs/inference-providers/en/pricing) पहा.

## Mask filling[[mask-filling]]

तुम्ही पुढे `fill-mask` pipeline वापरून पाहणार आहात. या task ची कल्पना म्हणजे दिलेल्या text मधील blanks भरून काढणे:

```python
from transformers import pipeline

unmasker = pipeline("fill-mask")
unmasker("This course will teach you all about <mask> models.", top_k=2)
```

```python out
[{'sequence': 'This course will teach you all about mathematical models.',
  'score': 0.19619831442832947,
  'token': 30412,
  'token_str': ' mathematical'},
 {'sequence': 'This course will teach you all about computational models.',
  'score': 0.04052725434303284,
  'token': 38163,
  'token_str': ' computational'}]
```

`top_k` argument च्या मदतीने तुम्हाला किती possibilities दाखवायच्या आहेत हे control करता येते.

इथे model विशेष `<mask>` word भरून काढते, ज्याला अनेकदा *mask token* असे म्हटले जाते. इतर mask-filling models मध्ये वेगवेगळे mask tokens असू शकतात. त्यामुळे इतर models explore करताना योग्य mask word verify करणे नेहमी चांगले असते.

हे तपासण्याचा एक मार्ग म्हणजे widget मध्ये वापरलेला mask word पाहणे.

> [!TIP]
> ✏️ **स्वतः करून पहा!** Hub वर `bert-base-cased` model शोधा आणि Inference API widget मध्ये त्याचा mask word ओळखा. वरील `pipeline` example मधील sentence साठी हा model काय predict करतो?

## Named entity recognition[[named-entity-recognition]]

Named entity recognition (NER) हे असे task आहे ज्यामध्ये input text मधील कोणते parts person, location किंवा organization यांसारख्या entities शी संबंधित आहेत हे model ने शोधायचे असते. चला एक example पाहूया:

```python
from transformers import pipeline

ner = pipeline("ner", aggregation_strategy="simple")
ner("My name is Sylvain and I work at Hugging Face in Brooklyn.")
```

```python out
[{'entity_group': 'PER', 'score': 0.99816, 'word': 'Sylvain', 'start': 11, 'end': 18}, 
 {'entity_group': 'ORG', 'score': 0.97960, 'word': 'Hugging Face', 'start': 33, 'end': 45}, 
 {'entity_group': 'LOC', 'score': 0.99321, 'word': 'Brooklyn', 'start': 49, 'end': 57}
]
```

इथे model ने योग्यरित्या ओळखले की Sylvain ही person (PER), Hugging Face ही organization (ORG), आणि Brooklyn ही location (LOC) आहे.

Pipeline तयार करताना आपण `aggregation_strategy="simple"` हा option pass करतो. यामुळे एकाच entity शी संबंधित sentence चे वेगवेगळे parts पुन्हा एकत्र group करण्यास pipeline ला सांगितले जाते.

इथे model ने "Hugging" आणि "Face" यांना एकाच organization म्हणून योग्यरित्या group केले, जरी त्या नावामध्ये अनेक words आहेत.

खरं तर, पुढील chapter मध्ये आपण पाहणार आहोत की preprocessing काही words चे आणखी छोट्या parts मध्ये विभाजन करते. उदाहरणार्थ, `Sylvain` चे चार pieces मध्ये विभाजन होते: `S`, `##yl`, `##va`, आणि `##in`. Post-processing step मध्ये pipeline या pieces ला पुन्हा यशस्वीपणे एकत्र group करते.

> [!TIP]
> ✏️ **स्वतः करून पहा!** Model Hub वर English मध्ये part-of-speech tagging (सामान्यतः POS असे abbreviated केले जाते) करू शकणारे model शोधा. वरील example मधील sentence साठी हे model काय predict करते?

## Question answering[[question-answering]]

`question-answering` pipeline दिलेल्या context मधील माहितीचा वापर करून प्रश्नांची उत्तरे देते:

```python
from transformers import pipeline

question_answerer = pipeline("question-answering")
question_answerer(
    question="Where do I work?",
    context="My name is Sylvain and I work at Hugging Face in Brooklyn",
)
```

```python out
{'score': 0.6385916471481323, 'start': 33, 'end': 45, 'answer': 'Hugging Face'}
```

लक्षात घ्या की ही pipeline दिलेल्या context मधून information extract करून काम करते; ती स्वतः answer generate करत नाही.

## Summarization[[summarization]]

Summarization म्हणजे text मधील महत्त्वाचे मुद्दे कायम ठेवून तो text छोट्या text मध्ये रूपांतरित करण्याचे task होय. याचे एक example पाहूया:

```python
from transformers import pipeline

summarizer = pipeline("summarization")
summarizer(
    """
    America has changed dramatically during recent years. Not only has the number of 
    graduates in traditional engineering disciplines such as mechanical, civil, 
    electrical, chemical, and aeronautical engineering declined, but in most of 
    the premier American universities engineering curricula now concentrate on 
    and encourage largely the study of engineering science. As a result, there 
    are declining offerings in engineering subjects dealing with infrastructure, 
    the environment, and related issues, and greater concentration on high 
    technology subjects, largely supporting increasingly complex scientific 
    developments. While the latter is important, it should not be at the expense 
    of more traditional engineering.

    Rapidly developing economies such as China and India, as well as other 
    industrial countries in Europe and Asia, continue to encourage and advance 
    the teaching of engineering. Both China and India, respectively, graduate 
    six and eight times as many traditional engineers as does the United States. 
    Other industrial countries at minimum maintain their output, while America 
    suffers an increasingly serious decline in the number of engineering graduates 
    and a lack of well-educated engineers.
"""
)
```

```python out
[{'summary_text': ' America has changed dramatically during recent years . The '
                  'number of engineering graduates in the U.S. has declined in '
                  'traditional engineering disciplines such as mechanical, civil '
                  ', electrical, chemical, and aeronautical engineering . Rapidly '
                  'developing economies such as China and India, as well as other '
                  'industrial countries in Europe and Asia, continue to encourage '
                  'and advance engineering .'}]
```

Text generation प्रमाणेच, result साठी `max_length` किंवा `min_length` देखील specify करता येते.

## Translation[[translation]]

Translation साठी तुम्ही task name मध्ये language pair दिल्यास default model वापरू शकता, उदाहरणार्थ `"translation_en_to_fr"`. परंतु [Model Hub](https://huggingface.co/models) वरून तुम्हाला हवा असलेला model select करणे हा सर्वात सोपा मार्ग आहे.

इथे आपण French मधून English मध्ये translation करून पाहूया:

```python
from transformers import pipeline

translator = pipeline("translation", model="Helsinki-NLP/opus-mt-fr-en")
translator("Ce cours est produit par Hugging Face.")
```

```python out
[{'translation_text': 'This course is produced by Hugging Face.'}]
```

Text generation आणि summarization प्रमाणेच result साठी `max_length` किंवा `min_length` देखील specify करता येते.

> [!TIP]
> ✏️ **स्वतः करून पहा!** इतर languages मधील translation models शोधा आणि वरील sentence चे काही वेगवेगळ्या languages मध्ये translation करून पहा.

## Image आणि audio pipelines

Text च्या पलीकडे जाऊन Transformer models images आणि audio सोबतही काम करू शकतात. त्याची काही examples खाली दिली आहेत:

### Image classification

```python
from transformers import pipeline

image_classifier = pipeline(
    task="image-classification", model="google/vit-base-patch16-224"
)
result = image_classifier(
    "https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/pipeline-cat-chonk.jpeg"
)
print(result)
```

```python out
[{'label': 'lynx, catamount', 'score': 0.43350091576576233},
 {'label': 'cougar, puma, catamount, mountain lion, painter, panther, Felis concolor',
  'score': 0.034796204417943954},
 {'label': 'snow leopard, ounce, Panthera uncia',
  'score': 0.03240183740854263},
 {'label': 'Egyptian cat', 'score': 0.02394474856555462},
 {'label': 'tiger cat', 'score': 0.02288915030658245}]
```

### Automatic speech recognition

```python
from transformers import pipeline

transcriber = pipeline(
    task="automatic-speech-recognition", model="openai/whisper-large-v3"
)
result = transcriber(
    "https://huggingface.co/datasets/Narsil/asr_dummy/resolve/main/mlk.flac" 
) 
print(result) 
```

```python out 
{'text': ' I have a dream that one day this nation will rise up and live out the true meaning of its creed.'} 
```

## Multiple sources मधील data एकत्र करणे

Transformer models चा एक powerful application म्हणजे अनेक sources मधील data एकत्र करून त्यावर process करण्याची क्षमता. हे विशेषतः तेव्हा उपयुक्त ठरते जेव्हा तुम्हाला:

1. अनेक databases किंवा repositories मध्ये search करायचे असते.
2. वेगवेगळ्या formats मधील information (text, images, audio) एकत्र करायची असते.
3. संबंधित information चे एक unified view तयार करायचे असते.

उदाहरणार्थ, तुम्ही अशी system तयार करू शकता जी:

* Text आणि image सारख्या multiple modalities मधील databases मध्ये information search करते.
* वेगवेगळ्या sources मधून मिळालेले results एका coherent response मध्ये एकत्र करते. उदाहरणार्थ, audio file आणि text description मधील माहिती एकत्र करणे.
* Documents आणि metadata च्या database मधून सर्वात relevant information सादर करते.
