# परिचय[[introduction]]

Hugging Face कोर्समध्ये तुमचे स्वागत आहे! हा परिचय तुम्हाला कार्यरत वातावरण (working environment) सेट करण्यासाठी मार्गदर्शन करेल. तुम्ही नुकताच हा कोर्स सुरू करत असाल, तर आम्ही शिफारस करतो की तुम्ही आधी [Chapter 1](/course/chapter1) पाहा आणि त्यानंतर परत येऊन तुमचे वातावरण सेट करा, जेणेकरून तुम्ही स्वतः कोड वापरून पाहू शकाल.

या कोर्समध्ये आपण वापरणाऱ्या सर्व लायब्ररी Python packages म्हणून उपलब्ध आहेत. त्यामुळे, येथे आपण Python environment कसे सेट करायचे आणि तुम्हाला आवश्यक असलेल्या विशिष्ट लायब्ररी कशा install करायच्या हे पाहणार आहोत.

तुमचे working environment सेट करण्याचे दोन मार्ग आपण पाहणार आहोत — Colab notebook किंवा Python virtual environment वापरून. तुम्हाला जो पर्याय अधिक सोयीचा वाटतो तो निवडण्यास मोकळे आहात. नवशिक्यांसाठी, आम्ही सुरुवात करण्यासाठी Colab notebook वापरण्याची जोरदार शिफारस करतो.

लक्षात ठेवा की या कोर्समध्ये Windows system समाविष्ट केलेले नाही. तुम्ही Windows वापरत असाल, तर आम्ही Colab notebook वापरून कोर्स follow करण्याची शिफारस करतो. तुम्ही Linux distribution किंवा macOS वापरत असाल, तर येथे दिलेल्या कोणत्याही पद्धतीचा वापर करू शकता.

या कोर्सचा बहुतांश भाग करण्यासाठी तुमच्याकडे Hugging Face account असणे आवश्यक आहे. आम्ही आत्ताच account तयार करण्याची शिफारस करतो: [create an account](https://huggingface.co/join).

## Google Colab notebook वापरणे[[using-a-google-colab-notebook]]

Colab notebook वापरणे हा environment सेट करण्याचा सर्वात सोपा मार्ग आहे; तुमच्या browser मध्ये notebook सुरू करा आणि थेट coding ला सुरुवात करा!

तुम्हाला Colab ची ओळख नसेल, तर आम्ही शिफारस करतो की तुम्ही [introduction](https://colab.research.google.com/notebooks/intro.ipynb) पाहून सुरुवात करा. Colab तुम्हाला GPU किंवा TPU सारख्या काही accelerating hardware चा वापर करण्याची सुविधा देते आणि छोट्या workload साठी ते मोफत उपलब्ध आहे.
