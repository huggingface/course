在本章中，你已經認識了 Transformer 模型與大型語言模型（LLM）的基本概念，以及它們如何徹底改變人工智慧及其他領域。

## 涵蓋的關鍵概念

### 自然語言處理與 LLM

我們探討了什麼是 NLP，以及大型語言模型如何改變這個領域。你學到了：
- NLP 涵蓋從分類到生成的各種任務
- LLM 是以海量文字資料訓練而成的強大模型
- 這些模型能在單一架構中執行多種任務
- 儘管能力強大，LLM 仍有其限制，包括幻覺（hallucination）與偏見

### Transformer 的能力

你看到了 🤗 Transformers 的 `pipeline()` 函式如何讓預訓練模型輕鬆應用於各種任務：
- 文字分類、詞元分類（token classification）與問答
- 文字生成與摘要
- 翻譯及其他序列到序列（sequence-to-sequence）任務
- 語音辨識與影像分類

### Transformer 架構

我們從高層次說明了 Transformer 模型的運作方式，包括：
- 注意力機制的重要性
- 遷移學習如何讓模型適應特定任務
- 三種主要的架構變體：僅編碼器（encoder-only）、僅解碼器（decoder-only）與編碼器-解碼器（encoder-decoder）

### 模型架構及其應用

本章的重點之一，是了解不同任務應該選用哪種架構：

| 模型            | 範例                                       | 任務                                                   |
|-----------------|--------------------------------------------|--------------------------------------------------------|
| 僅編碼器        | BERT、DistilBERT、ModernBERT               | 句子分類、命名實體辨識、抽取式問答                     |
| 僅解碼器        | GPT、LLaMA、Gemma、SmolLM                  | 文字生成、對話式 AI、創意寫作                          |
| 編碼器-解碼器   | BART、T5、Marian、mBART                    | 摘要、翻譯、生成式問答                                 |

### 現代 LLM 的發展

你也了解了這個領域的最新進展：
- LLM 的規模與能力如何隨時間不斷成長
- 縮放定律（scaling laws）的概念，以及它們如何指引模型開發
- 協助模型處理更長序列的特殊注意力機制
- 預訓練與指令微調（instruction tuning）的兩階段訓練方式

### 實際應用

在整個章節中，你看到了這些模型如何應用於現實世界的問題：
- 使用 Hugging Face Hub 尋找並使用預訓練模型
- 利用 Inference API 直接在瀏覽器中測試模型
- 了解哪些模型最適合特定任務
