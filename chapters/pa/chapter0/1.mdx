# ਜਾਣ-ਪਛਾਣ[[introduction]]

Hugging Face ਕੋਰਸ ਵਿੱਚ ਤੁਹਾਡਾ ਸੁਆਗਤ ਹੈ! ਇਹ ਜਾਣ-ਪਛਾਣ ਤੁਹਾਨੂੰ ਕੰਮ ਕਰਨ ਵਾਲਾ ਵਾਤਾਵਰਣ (working environment) ਸੈੱਟ ਅੱਪ ਕਰਨ ਵਿੱਚ ਮਦਦ ਕਰੇਗੀ। ਜੇ ਤੁਸੀਂ ਹੁਣੇ ਕੋਰਸ ਸ਼ੁਰੂ ਕਰ ਰਹੇ ਹੋ, ਤਾਂ ਅਸੀਂ ਸਿਫ਼ਾਰਸ਼ ਕਰਦੇ ਹਾਂ ਕਿ ਪਹਿਲਾਂ [Chapter 1](/course/chapter1) 'ਤੇ ਇੱਕ ਨਜ਼ਰ ਮਾਰੋ। ਇਸ ਤੋਂ ਬਾਅਦ ਵਾਪਸ ਆ ਕੇ ਆਪਣਾ ਵਾਤਾਵਰਣ ਸੈੱਟ ਅੱਪ ਕਰੋ, ਤਾਂ ਜੋ ਤੁਸੀਂ ਖੁਦ ਕੋਡ ਅਜ਼ਮਾ ਸਕੋ।

ਇਸ ਕੋਰਸ ਵਿੱਚ ਵਰਤੀਆਂ ਜਾਣ ਵਾਲੀਆਂ ਸਾਰੀਆਂ ਲਾਇਬ੍ਰੇਰੀਆਂ Python packages ਵਜੋਂ ਉਪਲਬਧ ਹਨ। ਇਸ ਲਈ, ਇੱਥੇ ਅਸੀਂ ਤੁਹਾਨੂੰ Python environment ਸੈੱਟ ਅੱਪ ਕਰਨਾ ਅਤੇ ਲੋੜੀਂਦੀਆਂ ਖਾਸ ਲਾਇਬ੍ਰੇਰੀਆਂ ਇੰਸਟਾਲ ਕਰਨਾ ਦਿਖਾਵਾਂਗੇ।

ਅਸੀਂ ਆਪਣਾ ਕੰਮ ਕਰਨ ਵਾਲਾ ਵਾਤਾਵਰਣ ਸੈੱਟ ਅੱਪ ਕਰਨ ਦੇ ਦੋ ਤਰੀਕੇ ਦੱਸਾਂਗੇ: Colab notebook ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਜਾਂ Python virtual environment ਦੀ ਵਰਤੋਂ ਕਰਕੇ। ਤੁਸੀਂ ਆਪਣੀ ਸਹੂਲਤ ਅਨੁਸਾਰ ਕੋਈ ਵੀ ਤਰੀਕਾ ਚੁਣ ਸਕਦੇ ਹੋ। ਸ਼ੁਰੂਆਤ ਕਰਨ ਵਾਲਿਆਂ ਲਈ ਅਸੀਂ ਜ਼ੋਰਦਾਰ ਸਿਫ਼ਾਰਸ਼ ਕਰਦੇ ਹਾਂ ਕਿ ਉਹ Colab notebook ਨਾਲ ਸ਼ੁਰੂਆਤ ਕਰਨ।

ਧਿਆਨ ਦਿਓ ਕਿ ਇਸ ਕੋਰਸ ਵਿੱਚ ਅਸੀਂ Windows ਸਿਸਟਮ ਬਾਰੇ ਨਹੀਂ ਦੱਸਾਂਗੇ। ਜੇ ਤੁਸੀਂ Windows ਵਰਤ ਰਹੇ ਹੋ, ਤਾਂ ਅਸੀਂ ਸਿਫ਼ਾਰਸ਼ ਕਰਦੇ ਹਾਂ ਕਿ ਤੁਸੀਂ Colab notebook ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਕੋਰਸ ਨਾਲ ਅੱਗੇ ਵਧੋ। ਜੇ ਤੁਸੀਂ Linux distribution ਜਾਂ macOS ਵਰਤ ਰਹੇ ਹੋ, ਤਾਂ ਤੁਸੀਂ ਇੱਥੇ ਦੱਸੇ ਦੋਵਾਂ ਤਰੀਕਿਆਂ ਵਿੱਚੋਂ ਕੋਈ ਵੀ ਵਰਤ ਸਕਦੇ ਹੋ।

ਕੋਰਸ ਦੇ ਜ਼ਿਆਦਾਤਰ ਹਿੱਸੇ ਲਈ ਤੁਹਾਡੇ ਕੋਲ Hugging Face account ਹੋਣਾ ਲਾਜ਼ਮੀ ਹੈ। ਅਸੀਂ ਸਿਫ਼ਾਰਸ਼ ਕਰਦੇ ਹਾਂ ਕਿ ਤੁਸੀਂ ਹੁਣੇ ਆਪਣਾ ਖਾਤਾ ਬਣਾ ਲਵੋ: [ਖਾਤਾ ਬਣਾਓ](https://huggingface.co/join)।

## Google Colab notebook ਦੀ ਵਰਤੋਂ[[using-a-google-colab-notebook]]

Colab notebook ਦੀ ਵਰਤੋਂ ਕਰਨਾ ਸਭ ਤੋਂ ਆਸਾਨ ਤਰੀਕਾ ਹੈ। ਆਪਣੇ browser ਵਿੱਚ notebook ਖੋਲ੍ਹੋ ਅਤੇ ਤੁਰੰਤ ਕੋਡ ਲਿਖਣਾ ਸ਼ੁਰੂ ਕਰ ਦਿਓ!

ਜੇ ਤੁਸੀਂ Colab ਬਾਰੇ ਨਹੀਂ ਜਾਣਦੇ, ਤਾਂ ਅਸੀਂ ਸਿਫ਼ਾਰਸ਼ ਕਰਦੇ ਹਾਂ ਕਿ ਪਹਿਲਾਂ ਇਸਦੀ [ਜਾਣ-ਪਛਾਣ](https://colab.research.google.com/notebooks/intro.ipynb) ਪੜ੍ਹੋ। Colab ਤੁਹਾਨੂੰ GPU ਜਾਂ TPU ਵਰਗੇ ਕੁਝ accelerating hardware ਵਰਤਣ ਦੀ ਸਹੂਲਤ ਦਿੰਦਾ ਹੈ ਅਤੇ ਛੋਟੇ workloads ਲਈ ਇਹ ਮੁਫ਼ਤ ਹੈ।

ਜਦੋਂ ਤੁਸੀਂ Colab ਵਿੱਚ ਕੰਮ ਕਰਨਾ ਸਿੱਖ ਲਵੋ, ਤਾਂ ਇੱਕ ਨਵੀਂ notebook ਬਣਾਓ ਅਤੇ ਸੈੱਟਅੱਪ ਸ਼ੁਰੂ ਕਰੋ:

## Python virtual environment ਦੀ ਵਰਤੋਂ[[using-a-python-virtual-environment]]

ਜੇ ਤੁਸੀਂ Python virtual environment ਵਰਤਣਾ ਚਾਹੁੰਦੇ ਹੋ, ਤਾਂ ਸਭ ਤੋਂ ਪਹਿਲਾਂ ਤੁਹਾਨੂੰ ਆਪਣੇ ਸਿਸਟਮ 'ਤੇ Python ਇੰਸਟਾਲ ਕਰਨਾ ਪਵੇਗਾ। ਸ਼ੁਰੂਆਤ ਕਰਨ ਲਈ ਅਸੀਂ [ਇਸ ਗਾਈਡ](https://realpython.com/installing-python/) ਦੀ ਪਾਲਣਾ ਕਰਨ ਦੀ ਸਿਫ਼ਾਰਸ਼ ਕਰਦੇ ਹਾਂ।

Python ਇੰਸਟਾਲ ਹੋਣ ਤੋਂ ਬਾਅਦ, ਤੁਹਾਨੂੰ ਆਪਣੇ terminal ਵਿੱਚ Python commands ਚਲਾਉਣ ਦੇ ਯੋਗ ਹੋਣਾ ਚਾਹੀਦਾ ਹੈ। ਅਗਲੇ ਕਦਮਾਂ ਤੋਂ ਪਹਿਲਾਂ ਇਹ ਯਕੀਨੀ ਬਣਾਉਣ ਲਈ ਕਿ Python ਠੀਕ ਤਰ੍ਹਾਂ ਇੰਸਟਾਲ ਹੈ, ਇਹ command ਚਲਾਓ: `python --version`। ਇਸ ਨਾਲ ਤੁਹਾਡੇ ਸਿਸਟਮ 'ਤੇ ਉਪਲਬਧ Python version ਦਿਖਾਈ ਦੇਣਾ ਚਾਹੀਦਾ ਹੈ।

ਜਦੋਂ ਤੁਸੀਂ ਆਪਣੇ terminal ਵਿੱਚ ਕੋਈ Python command ਚਲਾਉਂਦੇ ਹੋ, ਜਿਵੇਂ `python --version`, ਤਾਂ ਉਸ program ਨੂੰ ਆਪਣੇ ਸਿਸਟਮ ਦਾ "main" Python ਸਮਝੋ ਜੋ ਇਹ command ਚਲਾ ਰਿਹਾ ਹੈ। ਅਸੀਂ ਸਿਫ਼ਾਰਸ਼ ਕਰਦੇ ਹਾਂ ਕਿ ਇਸ ਮੁੱਖ installation ਵਿੱਚ ਕੋਈ packages ਇੰਸਟਾਲ ਨਾ ਕਰੋ। ਇਸਦੀ ਵਰਤੋਂ ਹਰ application ਲਈ ਵੱਖਰਾ environment ਬਣਾਉਣ ਵਾਸਤੇ ਕਰੋ। ਇਸ ਤਰ੍ਹਾਂ ਹਰ application ਦੀਆਂ ਆਪਣੀਆਂ dependencies ਅਤੇ packages ਹੋ ਸਕਦੀਆਂ ਹਨ ਅਤੇ ਤੁਹਾਨੂੰ ਵੱਖ-ਵੱਖ applications ਵਿਚਕਾਰ compatibility ਦੀਆਂ ਸਮੱਸਿਆਵਾਂ ਦੀ ਚਿੰਤਾ ਨਹੀਂ ਕਰਨੀ ਪਵੇਗੀ।

Python ਵਿੱਚ ਇਹ ਕੰਮ [virtual environments](https://docs.python.org/3/tutorial/venv.html) ਰਾਹੀਂ ਕੀਤਾ ਜਾਂਦਾ ਹੈ। ਇਹ ਅਜਿਹੀਆਂ directory trees ਹੁੰਦੀਆਂ ਹਨ ਜੋ ਆਪਣੇ ਆਪ ਵਿੱਚ ਪੂਰੀਆਂ ਹੁੰਦੀਆਂ ਹਨ। ਹਰ ਇੱਕ ਵਿੱਚ ਇੱਕ ਖਾਸ Python version ਵਾਲੀ Python installation ਅਤੇ ਉਸ application ਲਈ ਲੋੜੀਂਦੇ ਸਾਰੇ packages ਹੁੰਦੇ ਹਨ। ਅਜਿਹਾ virtual environment ਬਣਾਉਣ ਲਈ ਕਈ tools ਉਪਲਬਧ ਹਨ, ਪਰ ਇੱਥੇ ਅਸੀਂ ਇਸ ਮਕਸਦ ਲਈ Python ਦੇ official package ਦੀ ਵਰਤੋਂ ਕਰਾਂਗੇ, ਜਿਸਦਾ ਨਾਮ [`venv`](https://docs.python.org/3/library/venv.html#module-venv) ਹੈ।

ਸਭ ਤੋਂ ਪਹਿਲਾਂ ਉਹ directory ਬਣਾਓ ਜਿੱਥੇ ਤੁਸੀਂ ਆਪਣੀ application ਰੱਖਣਾ ਚਾਹੁੰਦੇ ਹੋ। ਉਦਾਹਰਨ ਲਈ, ਤੁਸੀਂ ਆਪਣੀ home directory ਦੇ ਮੁੱਖ ਪੱਧਰ 'ਤੇ *transformers-course* ਨਾਮ ਦੀ ਨਵੀਂ directory ਬਣਾ ਸਕਦੇ ਹੋ:

```
mkdir ~/transformers-course
cd ~/transformers-course
```

ਇਸ directory ਦੇ ਅੰਦਰ, Python ਦੇ `venv` module ਦੀ ਵਰਤੋਂ ਕਰਕੇ virtual environment ਬਣਾਓ:

```
python -m venv .env
```

ਹੁਣ ਤੁਹਾਡੇ ਖਾਲੀ folder ਵਿੱਚ *.env* ਨਾਮ ਦੀ directory ਬਣ ਜਾਣੀ ਚਾਹੀਦੀ ਹੈ:

```
ls -a
```

```out
.      ..    .env
```

ਤੁਸੀਂ `activate` ਅਤੇ `deactivate` scripts ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਆਪਣੇ virtual environment ਵਿੱਚ ਦਾਖ਼ਲ ਹੋ ਸਕਦੇ ਹੋ ਅਤੇ ਇਸ ਵਿੱਚੋਂ ਬਾਹਰ ਆ ਸਕਦੇ ਹੋ:

```
# Activate the virtual environment
source .env/bin/activate

# Deactivate the virtual environment
deactivate
```

ਤੁਸੀਂ `which python` command ਚਲਾ ਕੇ ਜਾਂਚ ਸਕਦੇ ਹੋ ਕਿ environment ਸਰਗਰਮ ਹੈ ਜਾਂ ਨਹੀਂ। ਜੇ ਇਸ command ਦਾ ਨਤੀਜਾ virtual environment ਵੱਲ ਇਸ਼ਾਰਾ ਕਰਦਾ ਹੈ, ਤਾਂ ਇਸਦਾ ਮਤਲਬ ਹੈ ਕਿ ਤੁਸੀਂ ਇਸਨੂੰ ਸਫ਼ਲਤਾਪੂਰਵਕ activate ਕਰ ਲਿਆ ਹੈ!

```
which python
```

```out
/home/<user>/transformers-course/.env/bin/python
```

### Dependencies ਇੰਸਟਾਲ ਕਰਨਾ[[installing-dependencies]]

```
pip install "transformers[sentencepiece]"
```

ਹੁਣ ਤੁਹਾਡਾ ਸੈੱਟਅੱਪ ਪੂਰਾ ਹੋ ਗਿਆ ਹੈ ਅਤੇ ਤੁਸੀਂ ਅੱਗੇ ਵਧਣ ਲਈ ਤਿਆਰ ਹੋ!
