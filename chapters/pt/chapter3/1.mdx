# Introdução[[introduction]]

    chapter={3}
    classNames="absolute z-10 right-0 top-0"

No [Capítulo 2](/course/pt/chapter2) nós exploramos como utilizar tokenizers e modelos pré-treinados para fazer predições. Mas e se você quisesse aperfeiçoar via fine-tune um modelo pré-treinado para resolver uma tarefa em especial? Esse é o tópico deste capítulo, em que você vai aprender:

* Como preparar um dataset grande do Hub usando os recursos mais recentes do 🤗 Datasets;
* Como usar a `Trainer` API de alto nível para ajustar com fine-tune um modelo, se utilizando das melhores práticas modernas;
* Como implementar um loop de treinamento customizado com técnicas de otimização;
* Como aproveitar a biblioteca 🤗 Accelerate para facilmente rodar treinamento distribuído em qualquer setup;
* Como aplicar as melhores práticas atuais de fine-tuning para maximização de performance.

> [!TIP]
> 📚 **Recursos Essenciais**: Antes de começar, talvez seja intereressante revisar a [documentação 🤗 Datasets](https://huggingface.co/docs/datasets/) para processamento de dados.

Este capítulo também servirá como uma introdução para outras bibliotecas Hugging Face além da biblioteca 🤗 Transformers! Nós veremos  que bibliotecas dos tipos 🤗 Datasets, 🤗 Tokenizers, 🤗 Accelerate, e 🤗 Evaluate podem ajudar a treinar modelos eficientemente e efetivamente.

Cada uma das seções principais nesse capítulo vai lhe ensinar algo diferente, como:
- **Seção 2**: Aprender técnicas de pré-processamento de dados e manejo eficiente de datasets
- **Seção 3**: Ter maestria na poderosa Trainer API com todos os seus recursos mais recentes
- **Seção 4**: Implementar loops de treinamento do zero e compreender treinamento distribuído com 🤗 Accelerate

Ao final deste capítulo, você conseguirá aperfeiçoar modelos através do fine-tune com seus próprios datasets usando tanto APIs de alto nível quanto loops customizados de treinamento, aplicando as boas práticas mais recentes disponíveis.

> [!TIP]
> 🎯 **O que você construirá**: Ao fim do capítulo, terá aperfeiçoado um modelo BERT com fine-tune para classificação de texto e compreensão de como adaptar as técnicas para seus próprios datasets e tarefas.

Esse capítulo em particular foca em **PyTorch**, que se tornou o framework padrão para pesquisas e produções de deep learning moderno. Nós utilizaremos as APIs e boas práticas mais atuais do ecossistema Hugging Face.

Para fazer upload dos seus modelos treinados ao Hub Hugging Face, você deverá ter uma conta Hugging Face: [crie a sua conta 🤗 !](https://huggingface.co/join)
