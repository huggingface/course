# Giriş[[introduction]]

Hugging Face kursuna hoş geldiniz! Bu giriş, çalışma ortamınızı kurmanızda size yol gösterecek. Kursa yeni başlıyorsanız önce [1. bölüme](/course/chapter1) göz atmanızı, ardından buraya dönüp kodu kendiniz deneyebilmek için ortamınızı kurmanızı öneririz.

Bu kursta kullanacağımız bütün kütüphaneler Python paketi olarak sunulur. Bu yüzden burada bir Python ortamını nasıl kuracağınızı ve ihtiyaç duyacağınız kütüphaneleri nasıl yükleyeceğinizi göstereceğiz.

Çalışma ortamını kurmanın iki yolunu ele alacağız: Colab not defteri ve Python sanal ortamı. Size en uygun geleni seçebilirsiniz. Yeni başlayanların Colab not defteriyle başlamasını özellikle öneririz.

Windows sistemini ele almayacağımızı belirtelim. Windows kullanıyorsanız kursu bir Colab not defteri üzerinden takip etmenizi öneririz. Bir Linux dağıtımı ya da macOS kullanıyorsanız burada anlatılan iki yoldan birini seçebilirsiniz.

Kursun büyük kısmı bir Hugging Face hesabınız olduğunu varsayar. Hemen bir tane oluşturmanızı öneririz: [hesap oluşturun](https://huggingface.co/join).

## Google Colab not defteri kullanmak[[using-a-google-colab-notebook]]

Colab not defteri, mümkün olan en basit kurulumdur: tarayıcınızda bir not defteri açın ve doğrudan kod yazmaya başlayın!

Colab'i tanımıyorsanız önce [tanıtım sayfasını](https://colab.research.google.com/notebooks/intro.ipynb) izlemenizi öneririz. Colab, GPU ya da TPU gibi hızlandırıcı donanımlar kullanmanıza izin verir ve küçük iş yükleri için ücretsizdir.

Colab'de rahatça dolaşabildiğinizde yeni bir not defteri oluşturun ve kuruluma başlayın:

<div class="flex justify-center">
<img src="https://huggingface.co/datasets/huggingface-course/documentation-images/resolve/main/en/chapter0/new_colab.png" alt="Boş bir Colab not defteri" width="80%"/>
</div>

Sıradaki adım, bu kursta kullanacağımız kütüphaneleri yüklemek. Yükleme için Python'ın paket yöneticisi `pip`'i kullanacağız. Not defterlerinde sistem komutlarını başlarına `!` karakteri koyarak çalıştırabilirsiniz; dolayısıyla 🤗 Transformers kütüphanesini şöyle yükleyebilirsiniz:

```
!pip install transformers
```

Paketin doğru yüklendiğinden emin olmak için Python çalışma ortamınızda onu içe aktarabilirsiniz:

```
import transformers
```

<div class="flex justify-center">
<img src="https://huggingface.co/datasets/huggingface-course/documentation-images/resolve/main/en/chapter0/install.gif" alt="Yukarıdaki iki komutun sonucunu gösteren bir gif: yükleme ve içe aktarma" width="80%"/>
</div>

Bu komut 🤗 Transformers'ın çok hafif bir sürümünü yükler. Özellikle de herhangi bir makine öğrenmesi framework'ü (PyTorch ya da TensorFlow gibi) yüklenmez. Kütüphanenin pek çok farklı özelliğini kullanacağımız için, akla gelebilecek hemen her kullanım senaryosu için gereken bütün bağımlılıklarla gelen geliştirme sürümünü yüklemenizi öneririz:

```
!pip install transformers[sentencepiece]
```

Bu biraz zaman alacak, ama sonrasında kursun geri kalanı için hazır olacaksınız!

## Python sanal ortamı kullanmak[[using-a-python-virtual-environment]]

Python sanal ortamı kullanmayı tercih ediyorsanız ilk adım sisteminize Python kurmaktır. Başlangıç için [bu kılavuzu](https://realpython.com/installing-python/) izlemenizi öneririz.

Python'ı kurduktan sonra terminalinizde Python komutları çalıştırabiliyor olmalısınız. Sonraki adımlara geçmeden önce kurulumun doğru yapıldığından emin olmak için şu komutu çalıştırarak başlayabilirsiniz: `python --version`. Bu komut, sisteminizde artık kullanılabilen Python sürümünü yazdırmalıdır.

Terminalinizde `python --version` gibi bir Python komutu çalıştırdığınızda, komutunuzu çalıştıran programı sisteminizdeki "ana" Python olarak düşünebilirsiniz. Bu ana kurulumu paketlerden arındırılmış tutmanızı ve onu, üzerinde çalıştığınız her uygulama için ayrı ortamlar oluşturmakta kullanmanızı öneririz. Böylece her uygulamanın kendi bağımlılıkları ve paketleri olur; başka uygulamalarla olası uyumluluk sorunlarını dert etmeniz gerekmez.

Python'da bu iş [*sanal ortamlarla*](https://docs.python.org/3/tutorial/venv.html) yapılır. Sanal ortamlar, her biri belirli bir Python sürümüyle kurulmuş bir Python'ı ve uygulamanın ihtiyaç duyduğu bütün paketleri barındıran, kendi kendine yeten dizin ağaçlarıdır. Böyle bir sanal ortamı pek çok farklı araçla oluşturmak mümkündür; biz bu amaçla Python'ın resmî paketi olan [`venv`](https://docs.python.org/3/library/venv.html#module-venv)'i kullanacağız.

Önce uygulamanızın yer alacağı dizini oluşturun. Örneğin ev dizininizin kökünde *transformers-course* adlı yeni bir dizin açabilirsiniz:

```
mkdir ~/transformers-course
cd ~/transformers-course
```

Bu dizinin içindeyken Python'ın `venv` modülüyle bir sanal ortam oluşturun:

```
python -m venv .env
```

Artık başka bir şey içermeyen klasörünüzde *.env* adlı bir dizin olmalı:

```
ls -a
```

```out
.      ..    .env
```

`activate` ve `deactivate` betikleriyle sanal ortamınıza girip çıkabilirsiniz:

```
# Sanal ortamı etkinleştir
source .env/bin/activate

# Sanal ortamı devre dışı bırak
deactivate
```

Ortamın etkin olduğundan emin olmak için `which python` komutunu çalıştırabilirsiniz: Komut sanal ortamı gösteriyorsa ortamı başarıyla etkinleştirmişsiniz demektir!

```
which python
```

```out
/home/<user>/transformers-course/.env/bin/python
```

### Bağımlılıkları yüklemek[[installing-dependencies]]

Google Colab örneklerini kullanmayı anlatan önceki kısımda olduğu gibi, devam etmek için gereken paketleri şimdi yüklemeniz gerekiyor. Yine 🤗 Transformers'ın geliştirme sürümünü `pip` paket yöneticisiyle yükleyebilirsiniz:

```
pip install "transformers[sentencepiece]"
```

Artık her şey hazır, başlayabilirsiniz!
