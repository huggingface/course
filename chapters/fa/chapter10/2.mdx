برای شروع استفاده از آرژیلا، ابتدا باید نمونه‌ی آرژیلا خودتان را راه‌اندازی کنید. سپس باید SDK پایتون را نصب کنید تا بتوانید آرژیلا را با کد پایتون مدیریت کنید.

## استقرار رابط کاربری آرژیلا

ساده‌ترین راه برای راه‌اندازی نمونه‌ی آرژیلا، استفاده از فضاهای هاگینگ‌فِیس است. برای ایجاد فضای آرژیلا، [این فرم](https://huggingface.co/new-space?template=argilla%2Fargilla-template-space) را تکمیل کنید. اگر به راهنمایی بیشتری نیاز دارید، [راهنمای شروع سریع آرژیلا](https://docs.argilla.io/latest/getting_started/quickstart/) را ببینید.

>[!WARNING]
> ⚠️ ممکن است بخواهید **ذخیره‌سازی مداوم** را فعال کنید تا در صورت توقف موقت یا راه‌اندازی مجدد فضا، داده‌ها از بین نرود.
> می‌توانید این کار را از بخش تنظیمات فضای خود انجام دهید.

پس از راه‌اندازی آرژیلا، می‌توانید با اعتبارنامه‌های خود وارد شوید.

## نصب و اتصال SDK پایتون

اکنون می‌توانید به محیط پایتون یا نوت‌بوک خود بروید و کتابخانه‌ی argilla را نصب کنید:

`!pip install argilla`

بیایید به نمونه‌ی آرژیلا متصل شویم. برای این کار به اطلاعات زیر نیاز دارید:

- **URL API شما**: این نشانی همان جایی است که آرژیلا در آن اجرا می‌شود. اگر از یک Space استفاده می‌کنید، Space را باز کنید، روی سه‌نقطه در گوشه‌ی بالا سمت راست بزنید، سپس «Embed this Space» را انتخاب و **Direct URL** را کپی کنید. این نشانی باید شبیه `https://<your-username>.<space-name>.hf.space` باشد.
- **کلید API شما**: برای دریافت کلید، وارد نمونه‌ی آرژیلا شوید و به «My Settings» بروید، سپس کلید API را کپی کنید.
- **توکِن HF شما**: اگر Space خصوصی است، در حساب هاب هاگینگ‌فِیس خود به Access Token با مجوز نوشتن نیاز دارید.

```python
import argilla as rg

HF_TOKEN = "..."  # only for private spaces

client = rg.Argilla(
    api_url="...",
    api_key="...",
    headers={"Authorization": f"Bearer {HF_TOKEN}"},  # only for private spaces
)
```

برای بررسی درست‌کارکردن همه‌چیز، `me` را فراخوانی می‌کنیم. این فراخوانی باید کاربر ما را برگرداند:

```python
client.me
```

اگر این کار موفقیت‌آمیز بود، نمونه‌ی آرژیلا راه‌اندازی شده و شما به آن متصل هستید! تبریک می‌گوییم.

اکنون می‌توانیم بارگذاری نخستین دیتاسِت خود در آرژیلا را شروع کنیم.
