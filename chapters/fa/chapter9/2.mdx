بیایید با نصب Gradio شروع کنیم! از آنجایی که این یک بسته پایتون است، کافیست دستور زیر را اجرا کنید:

`$ pip install gradio `

می‌توانید Gradio را در هر جایی اجرا کنید، چه از Python IDE مورد علاقه‌تان، تا نوت‌بوک‌های Jupyter یا حتی در Google Colab 🤯!
بنابراین Gradio را هر کجا پایتون اجرا می کنید نصب کنید!

بیایید با یک مثال ساده «Hello World» برای آشنایی با نحو Gradio شروع کنیم:

```py
import gradio as gr


def greet(name):
    return "Hello " + name


demo = gr.Interface(fn=greet, inputs="text", outputs="text")

demo.launch()
```

بیایید کد بالا را مرور کنیم:

- ابتدا تابعی به نام `greet()` تعریف می کنیم. در این مورد، یک تابع ساده است که قبل از نام شما "Hello" را اضافه می کند، اما به طور کلی می تواند *هر* تابع پایتون باشد. برای مثال، در برنامه‌های یادگیری ماشین، این تابع *یک مدل را برای پیش‌بینی* روی یک ورودی فراخوانی می‌کند و خروجی را برمی‌گرداند.
- سپس یک Gradio `Interface` با سه آرگومان `fn`، `inputs` و `outputs` ایجاد می‌کنیم. این آرگومان‌ها تابع پیش‌بینی و _نوع_ مؤلفه‌های ورودی و خروجی مورد نظرمان را مشخص می‌کنند. در مثال ما، هر دو مؤلفه جعبه‌متن ساده هستند.
- سپس متد `launch()` را در `Interface` که ایجاد کردیم فراخوانی می کنیم.

اگر این کد را اجرا کنید، رابط زیر به‌طور خودکار در نوت‌بوک Jupyter/Colab ظاهر می‌شود؛ یا اگر آن را از یک اسکریپت اجرا کنید، در مرورگر و در **[http://localhost:7860](http://localhost:7860/)** نمایش داده می‌شود.

سعی کنید همین حالا از این رابط کاربری گرافیکی با نام خودتان یا هر ورودی دیگر استفاده کنید!

متوجه خواهید شد که در این رابط کاربری گرافیکی، Gradio به طور خودکار نام پارامتر ورودی (`name`) را استنباط می کند.
و آن را به عنوان یک برچسب در بالای جعبه متن اعمال کنید. اگر بخواهید آن را تغییر دهید چه؟
یا اگر می خواهید جعبه متن را به روش دیگری سفارشی کنید؟ در آن صورت شما می توانید
نمونه سازی یک شی کلاس که مؤلفه ورودی را نشان می دهد.

به مثال زیر توجه کنید:

```py
import gradio as gr


def greet(name):
    return "Hello " + name


# We instantiate the Textbox class
textbox = gr.Textbox(label="Type your name here:", placeholder="John Doe", lines=2)

gr.Interface(fn=greet, inputs=textbox, outputs="text").launch()
```

در اینجا، ما یک جعبه متن ورودی با یک برچسب، یک مکان نگه دارنده، و تعداد مجموعه‌ای از خطوط ایجاد کرده‌ایم.
شما می توانید همین کار را برای جعبه متن خروجی انجام دهید، اما فعلا آن را رها می کنیم.

دیدیم که تنها با چند خط کد، Gradio اجازه می‌دهد پیرامون هر تابعی با هر نوع ورودی یا خروجی یک رابط ساده بسازید.
در این بخش با یک جعبه‌متن ساده شروع کردیم، اما در بخش‌های بعدی انواع دیگری از ورودی‌ها و خروجی‌ها را پوشش می‌دهیم. حالا بیایید افزودن NLP به یک برنامه‌ی Gradio را بررسی کنیم.



## 🤖 گنجاندن پیش‌بینی‌های مدل[[including-model-predictions]]

حالا بیایید یک رابط کاربری ساده بسازیم که به شما امکان می‌دهد یک مدل **تولید متن** مانند GPT-2 را به صورت آزمایشی اجرا کنید.

مدل خود را با استفاده از تابع `pipeline()` در 🤗 ترنسفورمرها بارگذاری می‌کنیم.
اگر به یادآوری سریع نیاز دارید، می‌توانید به [آن بخش از فصل ۱](/course/chapter1/3#text-generation) برگردید.

ابتدا یک تابع پیش‌بینی تعریف می‌کنیم که یک اعلان متنی را می‌گیرد و تکمیل متن را برمی‌گرداند:

```py
from transformers import pipeline

model = pipeline("text-generation")


def predict(prompt):
    completion = model(prompt)[0]["generated_text"]
    return completion
```

این تابع اعلان‌هایی را که شما ارائه می‌دهید تکمیل می‌کند و می‌توانید آن را با اعلان‌های ورودی خودتان اجرا کنید تا ببینید چگونه کار می‌کند. در اینجا یک مثال است (شما ممکن است یک تکمیل متفاوت دریافت کنید):

```
predict("My favorite programming language is")
```

```
>> My favorite programming language is Haskell. I really enjoyed the Haskell language, but it doesn't have all the features that can be applied to any other language. For example, all it does is compile to a byte array.
```

اکنون که تابعی برای تولید پیش‌بینی داریم، می‌توانیم یک `Interface` را به همان روشی که قبلا انجام دادیم ایجاد و راه‌اندازی کنیم:

```py
import gradio as gr

gr.Interface(fn=predict, inputs="text", outputs="text").launch()
```


همین! اکنون می توانید از این رابط برای تولید متن با استفاده از مدل GPT-2 همانطور که در زیر نشان داده شده است استفاده کنید.
