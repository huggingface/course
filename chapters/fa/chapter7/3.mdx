برای بسیاری از کاربردهای NLP که شامل مدل‌های ترنسفورمر هستند، می‌توانید به سادگی یک مدل از پیش تعلیم‌دیده را از هاگینگ‌فِیس هاب بگیرید و آن را مستقیماً روی داده‌های خود برای کار مورد نظر کوک کردن کنید. مشروط بر اینکه پیکره مورد استفاده برای پیش‌تعلیم خیلی متفاوت از پیکره مورد استفاده برای کوک کردن نباشد، یادگیری انتقالی معمولاً نتایج خوبی به همراه خواهد داشت.

با این حال، چند مورد وجود دارد که قبل از آموزش یک سربرگ مختص به وظیفه، ابتدا باید مدل‌های زبانی را روی داده‌های خود کوک کردن کنید. به عنوان مثال، اگر دیتاسِت‌های شما شامل قراردادهای حقوقی یا مقالات علمی باشد، یک مدل ترنسفورمر معمولی مانند BERT معمولاً کلمات مختص به دامنه را در مجموعه شما به عنوان توکن‌های نادر در نظر می‌گیرد و عملکرد حاصل ممکن است چندان رضایت‌بخش نباشد. با کوک کردن مدل زبان روی داده‌های درون دامنه می‌توانید عملکرد بسیاری از وظایف پایین‌دستی را افزایش دهید، به این معنی که معمولاً فقط باید این مرحله را یک بار انجام دهید!

این فرآیند کوک کردن یک مدل زبانی از پیش آموزش دیده روی داده‌های درون دامنه، معمولاً _انطباق دامنه_ نامیده می‌شود. این روش در سال ۲۰۱۸ توسط [ULMFiT](https://arxiv.org/abs/1801.06146) رواج یافت، که یکی از اولین معماری‌های عصبی (مبتنی بر LSTMها) بود که یادگیری انتقالی را برای پردازش زبان طبیعی (NLP) واقعاً کارآمد می‌کرد. نمونه‌ای از انطباق دامنه با ULMFiT در تصویر زیر نشان داده شده است؛ در این بخش، کاری مشابه انجام خواهیم داد، اما با یک ترنسفورمر به جای LSTM!

## انتخاب یک مدل از پیش آموزش دیده برای مدل سازی زبان ماسک شده[[picking-a-pretrained-model-for-masked-language-modeling]]

برای شروع، بیایید یک مدل از پیش تعلیم‌دیده مناسب برای مدل‌سازی زبان ماسک‌شده انتخاب کنیم. همانطور که در تصویر زیر نشان داده شده است، می‌توانید با اعمال فیلتر "Fill-Mask" در [هاگینگ‌فِیس هاب](https://huggingface.co/models?pipeline_tag=fill-mask&sort=downloads) لیستی از کاندیداها را پیدا کنید:

اگرچه خانواده مدل‌های BERT و RoBERTa بیشترین دانلود را دارند، ما از مدلی به نام [DistilBERT](https://huggingface.co/distilbert-base-uncased) استفاده خواهیم کرد.
که می‌تواند خیلی سریع‌تر و با کمترین یا بدون هیچ افتی در عملکرد پایین‌دستی تعلیم داده شود. این مدل با استفاده از تکنیک خاصی به نام [_knowledge distillation_](https://en.wikipedia.org/wiki/Knowledge_distillation) تعلیم داده شده است، که در آن از یک "مدل معلم" بزرگ مانند BERT برای هدایت آموزش یک "مدل دانش‌آموز" که پارامترهای بسیار کمتری دارد استفاده می‌شود. توضیح جزئیات تقطیر دانش ما را در این بخش خیلی از بحث اصلی دور می‌کند، اما اگر علاقه‌مند هستید می‌توانید می‌توانید همه چیز را در مورد آن در [_پردازش زبان طبیعی با ترنسفورمرها_](https://www.oreilly.com/library/view/natural-language-processing/9781098136789/) (که به صورت محاوره‌ای به عنوان کتاب درسی ترنسفورمرها شناخته می‌شود) بخوانید.

با حدود ۶۷ میلیون پارامتر، DistilBERT تقریباً دو برابر کوچکتر از مدل پایه BERT است، که تقریباً به معنای افزایش دو برابری سرعت آموزش است -- عالی! حال بیایید ببینیم این مدل چه نوع توکن‌هایی را پیش‌بینی می‌کند که محتمل‌ترین تکمیل‌های یک نمونه کوچک از متن هستند:

```python
text = "This is a great [MASK]."
```

ما به عنوان انسان، می‌توانیم احتمالات زیادی را برای توکن `[MASK]` تصور کنیم، مانند "روز"، "سوار شدن" یا "نقاشی". برای مدل‌های از پیش تعلیم‌دیده، پیش‌بینی‌ها به پیکره‌ای که مدل بر اساس آن آموزش دیده است بستگی دارد، زیرا یاد می‌گیرد الگوهای آماری موجود در داده‌ها را انتخاب کند. مانند BERT، DistilBERT نیز بر روی دیتاسِت‌های [ویکی‌پدیای انگلیسی](https://huggingface.co/datasets/wikipedia) و [BookCorpus](https://huggingface.co/datasets/bookcorpus) از پیش آموزش دیده است، بنابراین انتظار داریم پیش‌بینی‌های `[MASK]` بازتاب‌دهنده‌ی این حوزه‌ها باشند. برای پیش‌بینی ماسک، به توکن‌ساز DistilBERT نیاز داریم تا ورودی‌های مدل را تولید کند، بنابراین بیایید آن را نیز از هاب دانلود کنیم:

```python
from transformers import AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained(model_checkpoint)
```

با یک توکن‌ساز و یک مدل، اکنون می‌توانیم مثال متنی خود را به مدل ارسال کنیم، لوجیت‌ها را استخراج کنیم و ۵ کاندید برتر را چاپ کنیم:

{#if fw === 'pt'}

```python
import torch

inputs = tokenizer(text, return_tensors="pt")
token_logits = model(**inputs).logits
# Find the location of [MASK] and extract its logits
mask_token_index = torch.where(inputs["input_ids"] == tokenizer.mask_token_id)[1]
mask_token_logits = token_logits[0, mask_token_index, :]
# Pick the [MASK] candidates with the highest logits
top_5_tokens = torch.topk(mask_token_logits, 5, dim=1).indices[0].tolist()

for token in top_5_tokens:
    print(f"'>>> {text.replace(tokenizer.mask_token, tokenizer.decode([token]))}'")
```

## پیش‌پردازش داده‌ها[[preprocessing-the-data]]

<Youtube id="8PmhEIXhBvI"/>

برای هر دو مدل‌سازی زبان خودرگرسیون و ماسک‌شده، یک مرحله پیش‌پردازش رایج، الحاق همه مثال‌ها و سپس تقسیم کل مجموعه به قطعاتی با اندازه مساوی است. این کاملاً با رویکرد معمول ما که در آن صرفاً مثال‌های منفرد را توکنیزه می‌کنیم، متفاوت است. چرا همه چیز را با هم الحاق کنیم؟ دلیلش این است که اگر مثال‌های منفرد خیلی طولانی باشند، ممکن است کوتاه شوند و این منجر به از دست رفتن ... می‌شود. اطلاعاتی که ممکن است برای کار مدل‌سازی زبان مفید باشد!

بنابراین برای شروع، ابتدا طبق معمول، دیتاسِت‌های خود را توکنیزه می‌کنیم، اما _بدون_ تنظیم گزینه `truncation=True` در توکن‌ساز خود. همچنین شناسه‌های کلمات را در صورت موجود بودن، دریافت خواهیم کرد ((که اگر از یک توکن‌ساز سریع استفاده کنیم، همانطور که در [فصل 6](/course/chapter6/3) توضیح داده شده است، این کار را انجام خواهیم داد)، زیرا بعداً برای انجام پوشش کامل کلمه به آنها نیاز خواهیم داشت. این را در یک تابع ساده قرار می‌دهیم و در حین انجام این کار، `text` و `label` را حذف می‌کنیم. ستون‌ها، چون دیگر به آنها نیازی نداریم:

```python
def tokenize_function(examples):
    result = tokenizer(examples["text"])
    if tokenizer.is_fast:
        result["word_ids"] = [result.word_ids(i) for i in range(len(result["input_ids"]))]
    return result


# Use batched=True to activate fast multithreading!
tokenized_datasets = imdb_dataset.map(
```

* اگر آخرین تکه کوچکتر از `chunk_size` است، آن را حذف کن.
* آخرین تکه را تا زمانی که طول آن برابر با `chunk_size` شود، لایه گذاری کنید.

ما در اینجا رویکرد اول را در پیش می‌گیریم، بنابراین بیایید تمام منطق فوق را در یک تابع واحد که می‌توانیم روی دیتاسِت‌های توکن‌شده خود اعمال کنیم، قرار دهیم:

```python
def group_texts(examples):
    # Concatenate all texts
    concatenated_examples = {k: sum(examples[k], []) for k in examples.keys()}
    # Compute length of concatenated texts
    total_length = len(concatenated_examples[list(examples.keys())[0]])
    # We drop the last chunk if it's smaller than chunk_size
    total_length = (total_length // chunk_size) * chunk_size
    # Split by chunks of max_len
    result = {
        k: [t[i : i + chunk_size] for i in range(0, total_length, chunk_size)]
        for k, t in concatenated_examples.items()
    }
    # Create a new labels column
    result["labels"] = result["input_ids"].copy()
    return result
```

توجه داشته باشید که در آخرین مرحله از `group_texts()`، یک ستون جدید `labels` ایجاد می‌کنیم که یک کپی از ستون `input_ids` است. همانطور که به زودی خواهیم دید، دلیل این امر آن است که در مدل‌سازی زبان ماسک‌شده، هدف پیش‌بینی توکن‌های ماسک‌شده تصادفی در دسته ورودی است و با ایجاد یک ستون `labels`، حقیقت پایه را برای مدل زبانی خود فراهم می‌کنیم تا از آن یاد بگیرد.

```py
import collections
import numpy as np

from transformers import default_data_collator

wwm_probability = 0.2


def whole_word_masking_data_collator(features):
    for feature in features:
        word_ids = feature.pop("word_ids")

        # Create a map between words and corresponding token indices
        mapping = collections.defaultdict(list)
        current_word_index = -1
        current_word = None
        for idx, word_id in enumerate(word_ids):
            if word_id is not None:
                if word_id != current_word:
                    current_word = word_id
                    current_word_index += 1
                mapping[current_word_index].append(idx)

        # Randomly mask words
        mask = np.random.binomial(1, wwm_probability, (len(mapping),))
        input_ids = feature["input_ids"]
        labels = feature["labels"]
        new_labels = [-100] * len(labels)
        for word_id in np.where(mask)[0]:
            word_id = word_id.item()
            for idx in mapping[word_id]:
                new_labels[idx] = labels[idx]
                input_ids[idx] = tokenizer.mask_token_id
        feature["labels"] = new_labels

    return default_data_collator(features)
```

در مرحله بعد، ابرپارامترهای آموزشی خود را تنظیم کرده و مدل خود را کامپایل می‌کنیم. ما از تابع `create_optimizer()` از کتابخانه 🤗 ترنسفورمرs استفاده می‌کنیم که یک بهینه‌ساز `AdamW` با نرخ یادگیری خطی کاهشی به ما می‌دهد. ما همچنین از تابع زیان داخلی مدل استفاده می‌کنیم که در صورت عدم تعیین زیان به عنوان آرگومان برای `compile()`، پیش‌فرض است و دقت آموزش را روی `"mixed_float16"` تنظیم می‌کنیم. توجه داشته باشید که اگر از یک پردازنده گرافیکی Colab یا پردازنده گرافیکی دیگری که این تابع را ندارد استفاده می‌کنید، پشتیبانی از float16 شتاب‌یافته، احتمالاً باید آن خط را کامنت کنید.

علاوه بر این، ما یک `PushToHubCallback` راه‌اندازی کردیم که مدل را پس از هر دوره در هاب ذخیره می‌کند. می‌توانید نام مخزنی را که می‌خواهید به آن ارسال کنید با آرگومان `hub_model_id` مشخص کنید (به طور خاص، برای ارسال به یک سازمان باید از این آرگومان استفاده کنید). به عنوان مثال، برای ارسال مدل به سازمان [`huggingface-course`](https://huggingface.co/huggingface-course)، ما `hub_model_id="huggingface-course/distilbert-finetuned-imdb"` را اضافه کردیم. به طور پیش‌فرض، مخزن مورد استفاده در فضای نام شما قرار خواهد گرفت و نام آن از ... گرفته می‌شود. دایرکتوری خروجی که شما تنظیم کرده‌اید، بنابراین در مورد ما `"lewtun/distilbert-finetuned-imdb"` خواهد بود.

```python
from transformers import create_optimizer
from transformers.keras_callbacks import PushToHubCallback
import tensorflow as tf

num_train_steps = len(tf_train_dataset)
optimizer, schedule = create_optimizer(
    init_lr=2e-5,
    num_warmup_steps=1_000,
    num_train_steps=num_train_steps,
    weight_decay_rate=0.01,
)
model.compile(optimizer=optimizer)

# Train in mixed-precision float16
tf.keras.mixed_precision.set_global_policy("mixed_float16")

model_name = model_checkpoint.split("/")[-1]
callback = PushToHubCallback(
    output_dir=f"{model_name}-finetuned-imdb", tokenizer=tokenizer
)
```

در اینجا ما چند گزینه پیش‌فرض، از جمله `logging_steps` را تغییر دادیم تا مطمئن شویم که با هر دوره، افت آموزش را ردیابی می‌کنیم. ما همچنین از `fp16=True` برای فعال کردن آموزش با دقت مختلط استفاده کرده‌ایم که باعث افزایش سرعت ما می‌شود. به طور پیش‌فرض، `Trainer` هر ستونی را که بخشی از روش `forward()` مدل نیست، حذف می‌کند. این بدان معناست که اگر از کل‌نگار پوشش‌دهنده کلمه استفاده می‌کنید، باید `remove_unused_columns=False` را نیز تنظیم کنید تا مطمئن شوید که این کار را انجام نمی‌دهیم. ستون `word_ids` را در طول آموزش از دست بدهید.

توجه داشته باشید که می‌توانید نام مخزنی را که می‌خواهید به آن ارسال کنید با آرگومان `hub_model_id` مشخص کنید (به طور خاص، برای ارسال به یک سازمان باید از این آرگومان استفاده کنید). برای مثال، وقتی مدل را به سازمان [`huggingface-course`](https://huggingface.co/huggingface-course) ارسال کردیم، `hub_model_id="huggingface-course/distilbert-finetuned-imdb"` را به `TrainingArguments` اضافه کردیم. به طور پیش‌فرض، مخزن مورد استفاده در فضای نام شما قرار خواهد گرفت و نام آن از دایرکتوری خروجی که تنظیم کرده‌اید گرفته می‌شود، بنابراین در مورد ما `"lewtun/distilbert-finetuned-imdb"` خواهد بود.

## کوک کردن DistilBERT با 🤗 Accelerate[[fine-tuning-distilbert-with-accelerate]]

همانطور که با `Trainer` دیدیم، کوک کردن یک مدل زبان پنهان بسیار شبیه به مثال طبقه‌بندی متن از [فصل 3](/course/chapter3) است. در واقع، تنها نکته ظریف، استفاده از یک گردآورنده داده ویژه است و ما قبلاً در این بخش به آن پرداخته‌ایم!

با این حال، دیدیم که `DataCollatorForLanguageModeling` در هر ارزیابی، پوشش تصادفی نیز اعمال می‌کند، بنابراین با هر اجرای آموزش، شاهد نوساناتی در نمرات گیجی خود خواهیم بود. یک راه برای از بین بردن این منبع تصادفی بودن، اعمال پوشش _once_ روی کل مجموعه تست و سپس استفاده از تلفیق‌کننده داده‌های پیش‌فرض در ترنسفورمرs🤗 برای جمع‌آوری دسته‌ها در طول ارزیابی است. برای دیدن نحوه عملکرد این روش، بیایید یک تابع ساده پیاده‌سازی کنیم که اعمال می‌شود پوشش روی یک دسته، مشابه اولین برخورد ما با `DataCollatorForLanguageModeling`:

```python
def insert_random_mask(batch):
    features = [dict(zip(batch, t)) for t in zip(*batch.values())]
    masked_inputs = data_collator(features)
    # Create a new "masked" column for each column in the dataset
    return {"masked_" + k: v.numpy() for k, v in masked_inputs.items()}
```

در مرحله بعد، این تابع را روی مجموعه تست خود اعمال می‌کنیم و ستون‌های بدون ماسک را حذف می‌کنیم تا بتوانیم آنها را با ستون‌های ماسک‌شده جایگزین کنیم. می‌توانید با جایگزینی `data_collator` بالا با `data_collator` مناسب، از ماسک کردن کل کلمه استفاده کنید، که در این صورت باید خط اول را در اینجا حذف کنید:

```py
downsampled_dataset = downsampled_dataset.remove_columns(["word_ids"])
eval_dataset = downsampled_dataset["test"].map(
    insert_random_mask,
    batched=True,
    remove_columns=downsampled_dataset["test"].column_names,
)
eval_dataset = eval_dataset.rename_columns(
    {
        "masked_input_ids": "input_ids",
        "masked_attention_mask": "attention_mask",
        "masked_labels": "labels",
    }
)
```

سپس می‌توانیم دیتالودرها را طبق معمول تنظیم کنیم، اما برای مجموعه ارزیابی از `default_data_collator` از ترنسفورمرs🤗 استفاده خواهیم کرد:

```python
from torch.utils.data import DataLoader
from transformers import default_data_collator

batch_size = 64
train_dataloader = DataLoader(
    downsampled_dataset["train"],
    shuffle=True,
    batch_size=batch_size,
    collate_fn=data_collator,
)
eval_dataloader = DataLoader(
    eval_dataset, batch_size=batch_size, collate_fn=default_data_collator
)
```

از اینجا، مراحل استاندارد را با 🤗 Accelerate دنبال می‌کنیم. اولین مرحله، بارگذاری یک نسخه جدید از مدل از پیش تعلیم‌دیده است:

```
model = AutoModelForMaskedLM.from_pretrained(model_checkpoint)
```

سپس باید بهینه‌ساز را مشخص کنیم؛ ما از استاندارد `AdamW` استفاده خواهیم کرد:

```python
from torch.optim import AdamW

optimizer = AdamW(model.parameters(), lr=5e-5)
```

با این اشیاء، اکنون می‌توانیم همه چیز را برای آموزش با شیء `Accelerator` آماده کنیم:

```python
from accelerate import Accelerator

accelerator = Accelerator()
model, optimizer, train_dataloader, eval_dataloader = accelerator.prepare(
    model, optimizer, train_dataloader, eval_dataloader
)
```

اکنون که مدل، بهینه‌ساز و بارگذارهای داده ما پیکربندی شده‌اند، می‌توانیم زمانبند نرخ یادگیری را به صورت زیر مشخص کنیم:

```python
from transformers import get_scheduler

num_train_epochs = 3
num_update_steps_per_epoch = len(train_dataloader)
num_training_steps = num_train_epochs * num_update_steps_per_epoch

lr_scheduler = get_scheduler(
    "linear",
    optimizer=optimizer,
    num_warmup_steps=0,
    num_training_steps=num_training_steps,
)
```

فقط یک کار دیگر قبل از آموزش باید انجام دهیم: یک مخزن مدل در هاگینگ‌فِیس هاب ایجاد کنید! می‌توانیم از کتابخانه 🤗 هاب برای تولید نام کامل مخزن خود استفاده کنیم:

با انجام این کار، فقط کافی است حلقه کامل آموزش و ارزیابی را بنویسید:

```python
from tqdm.auto import tqdm
import torch
import math

progress_bar = tqdm(range(num_training_steps))

for epoch in range(num_train_epochs):
    # Training
    model.train()
    for batch in train_dataloader:
        outputs = model(**batch)
        loss = outputs.loss
        accelerator.backward(loss)

        optimizer.step()
        lr_scheduler.step()
        optimizer.zero_grad()
        progress_bar.update(1)

    # Evaluation
    model.eval()
    losses = []
    for step, batch in enumerate(eval_dataloader):
        with torch.no_grad():
            outputs = model(**batch)

        loss = outputs.loss
        losses.append(accelerator.gather(loss.repeat(batch_size)))

    losses = torch.cat(losses)
    losses = losses[: len(eval_dataset)]
    try:
        perplexity = math.exp(torch.mean(losses))
    except OverflowError:
        perplexity = float("inf")

    print(f">>> Epoch {epoch}: Perplexity: {perplexity}")

    # Save and upload
    accelerator.wait_for_everyone()
    unwrapped_model = accelerator.unwrap_model(model)
    unwrapped_model.save_pretrained(output_dir, save_function=accelerator.save)
    if accelerator.is_main_process:
        tokenizer.save_pretrained(output_dir)
        repo.push_to_hub(
            commit_message=f"Training in progress epoch {epoch}", blocking=False
        )
```
