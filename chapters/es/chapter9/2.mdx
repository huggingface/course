¡Comencemos instalando Gradio! Dado que es un paquete de Python, simplemente ejecuta:

`$ pip install gradio `

Puedes ejecutar Gradio en cualquier lugar, ya sea desde tu IDE favorito de Python, en notebooks de Jupyter o incluso en Google Colab 🤯.
¡Así que instala Gradio donde sea que ejecutes Python!

Empecemos con un ejemplo simple de "Hola Mundo" para familiarizarnos con la sintaxis de Gradio:

```py
import gradio as gr


def greet(name):
    return "Hello " + name


demo = gr.Interface(fn=greet, inputs="text", outputs="text")

demo.launch()
```

Repasemos el código anterior:

- Primero, definimos una función llamada `greet()`. En este caso, es una función simple que agrega "Hello " antes de tu nombre, pero en general puede ser *cualquier* función de Python. Por ejemplo, en aplicaciones de aprendizaje automático, esta función *llamaría a un modelo para hacer una predicción* sobre una entrada y devolvería la salida.
- Luego, creamos una `Interface` de Gradio con tres argumentos: `fn`, `inputs` y `outputs`. Estos argumentos definen la función de predicción, así como el _tipo_ de componentes de entrada y salida que nos gustaría tener. En nuestro caso, ambos componentes son cuadros de texto simples.
- Luego llamamos al método `launch()` en la `Interface` que creamos.

Si ejecutas este código, la interfaz que se muestra a continuación aparecerá automáticamente dentro de un notebook de Jupyter/Colab, o se abrirá en un navegador en **[http://localhost:7860](http://localhost:7860/)** si se ejecuta desde un script.

Notarás que en esta GUI, Gradio infirió automáticamente el nombre del parámetro de entrada (`name`) y lo aplicó como una etiqueta en la parte superior del cuadro de texto. ¿Qué pasa si quieres cambiar eso? ¿O si quieres personalizar el cuadro de texto de alguna otra manera? En ese caso, puedes instanciar un objeto de clase que represente el componente de entrada.

Echa un vistazo al siguiente ejemplo:

```py
import gradio as gr


def greet(name):
    return "Hello " + name


# Instanciamos la clase Textbox
textbox = gr.Textbox(label="Type your name here:", placeholder="John Doe", lines=2)

gr.Interface(fn=greet, inputs=textbox, outputs="text").launch()
```

## 🤖 Incluyendo predicciones del modelo[[including-model-predictions]]

Construyamos ahora una interfaz simple que te permita hacer una demostración de un modelo de **generación de texto** como GPT-2.

Cargaremos nuestro modelo utilizando la función `pipeline()` de 🤗 Transformers. Si necesitas un repaso rápido, puedes regresar a [esa sección en el Capítulo 1](/course/chapter1/3#text-generation).

Primero, definimos una función de predicción que toma un texto de entrada (*prompt*) y devuelve la compleción del texto:

```py
from transformers import pipeline

model = pipeline("text-generation")


def predict(prompt):
    completion = model(prompt)[0]["generated_text"]
    return completion
```

Esta función completa los prompts que proporcionas, y puedes ejecutarla con tus propios prompts de entrada para ver cómo funciona. Aquí tienes un ejemplo (es posible que obtengas una compleción diferente):

```
predict("My favorite programming language is")
```

```
>> My favorite programming language is Haskell. I really enjoyed the Haskell language, but it doesn't have all the features that can be applied to any other language. For example, all it does is compile to a byte array.
```

Ahora que tenemos una función para generar predicciones, podemos crear y lanzar una `Interface` de la misma manera que lo hicimos antes:

```py
import gradio as gr

gr.Interface(fn=predict, inputs="text", outputs="text").launch()
```

¡Eso es todo! Ahora puedes usar esta interfaz para generar texto usando el modelo GPT-2 como se muestra a continuación 🤯.
