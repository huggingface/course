Para facilitarte aún más la vida, Gradio se integra directamente con Hugging Face Hub y Hugging Face Spaces.
Puedes cargar demos desde Hub y Spaces con solo *una línea de código*.

### Cargando modelos desde Hugging Face Hub[[loading-models-from-the-hugging-face-hub]]

Para comenzar, elige uno de los miles de modelos que Hugging Face ofrece a través del Hub, como se describe en el [Capítulo 4](/course/chapter4/2).

Usando el método especial `Interface.load()`, pasas `"model/"` (o, de manera equivalente, `"huggingface/"`) seguido del nombre del modelo.
Por ejemplo, aquí tienes el código para construir una demo para [GPT-J](https://huggingface.co/EleutherAI/gpt-j-6B), un modelo de lenguaje grande, y agregar un par de ejemplos de entrada:

```py
import gradio as gr

title = "GPT-J-6B"
description = "Gradio Demo for GPT-J 6B, a transformer model trained using Ben Wang's Mesh Transformer JAX. 'GPT-J' refers to the class of model, while '6B' represents the number of trainable parameters. To use it, simply add your text, or click one of the examples to load them. Read more at the links below."
article = "<p style='text-align: center'><a href='https://github.com/kingoflolz/mesh-transformer-jax' target='_blank'>GPT-J-6B: A 6 Billion Parameter Autoregressive Language Model</a></p>"

gr.Interface.load(
    "huggingface/EleutherAI/gpt-j-6B",
    inputs=gr.Textbox(lines=5, label="Input Text"),
    title=title,
    description=description,
    article=article,
).launch()
```

El código anterior producirá la interfaz a continuación:

Cargar un modelo de esta manera utiliza la [API de Inferencia](https://huggingface.co/inference-api) de Hugging Face, en lugar de cargar el modelo en memoria. Esto es ideal para modelos gigantes como GPT-J o T0pp que requieren mucha memoria RAM.

### Cargando desde Hugging Face Spaces[[loading-from-hugging-face-spaces]]

Para cargar cualquier Space desde Hugging Face Hub y recrearlo localmente, puedes pasar `spaces/` a la `Interface`, seguido del nombre del Space.

¿Recuerdas la demo de la sección 1 que elimina el fondo de una imagen? Vamos a cargarla desde Hugging Face Spaces:

```py
gr.Interface.load("spaces/abidlabs/remove-bg").launch()
```

Una de las cosas geniales de cargar demos desde Hub o Spaces es que puedes personalizarlas sobrescribiendo cualquiera de los parámetros. Aquí añadimos un título y hacemos que funcione con una cámara web en su lugar:

```py
gr.Interface.load(
    "spaces/abidlabs/remove-bg", inputs="webcam", title="Remove your webcam background!"
).launch()
```
