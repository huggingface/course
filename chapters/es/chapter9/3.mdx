En esta sección examinaremos más de cerca la clase `Interface` y comprenderemos los parámetros principales utilizados para crear una.

## Cómo crear una Interface[[how-to-create-an-interface]]

Notarás que la clase `Interface` tiene 3 parámetros obligatorios:

`Interface(fn, inputs, outputs, ...)`

Estos parámetros son:

  - `fn`: la función de predicción que envuelve la interfaz de Gradio. Esta función puede tomar uno o más parámetros y devolver uno o más valores.
  - `inputs`: el tipo o tipos de componentes de entrada. Gradio proporciona muchos componentes prediseñados como `"image"` o `"mic"`.
  - `outputs`: el tipo o tipos de componentes de salida. De nuevo, Gradio proporciona muchos componentes prediseñados, por ejemplo `"image"` o `"label"`.

Para obtener una lista completa de componentes, [consulta la documentación de Gradio](https://gradio.app/docs). Cada componente prediseñado se puede personalizar instanciando la clase correspondiente al componente.

Por ejemplo, como vimos en la [sección anterior](/course/chapter9/2), en lugar de pasar `"textbox"` al parámetro `inputs`, puedes pasar un componente `Textbox(lines=7, label="Prompt")` para crear un cuadro de texto con 7 líneas y una etiqueta.

Veamos otro ejemplo, esta vez con un componente `Audio`.

## Un ejemplo sencillo con audio[[a-simple-example-with-audio]]

Como mencionamos anteriormente, Gradio ofrece muchas entradas y salidas diferentes.
Así que construyamos una `Interface` que trabaje con audio.

En este ejemplo, construiremos una función de audio a audio que toma un archivo de audio y simplemente lo invierte.

Utilizaremos el componente `Audio` para la entrada. Al usar el componente `Audio`, puedes especificar si deseas que la fuente (`source`) del audio sea un archivo que el usuario suba o un micrófono con el que el usuario grabe su voz. En este caso, configurémoslo como `"microphone"`. Por diversión, añadiremos una etiqueta a nuestro `Audio` que diga "Speak here...".

Además, nos gustaría recibir el audio como un arreglo de NumPy para poder "invertirlo" fácilmente. Por lo tanto, estableceremos el `"type"` en `"numpy"`, lo que pasa los datos de entrada como una tupla de (`sample_rate`, `data`) a nuestra función.

También utilizaremos el componente de salida `Audio`, que puede renderizar automáticamente una tupla con una tasa de muestreo y un arreglo de NumPy como un archivo de audio reproducible. En este caso, no necesitamos hacer ninguna personalización, por lo que usaremos el atajo de cadena `"audio"`.


```py
import numpy as np
import gradio as gr


def reverse_audio(audio):
    sr, data = audio
    reversed_audio = (sr, np.flipud(data))
    return reversed_audio


mic = gr.Audio(source="microphone", type="numpy", label="Speak here...")
gr.Interface(reverse_audio, mic, "audio").launch()
```

## Manejo de múltiples entradas y salidas[[handling-multiple-inputs-and-outputs]]

Supongamos que tenemos una función más compleja, con múltiples entradas y salidas.
En el siguiente ejemplo, tenemos una función que toma un índice desplegable, un valor de control deslizante y un número, y devuelve una muestra de audio de un tono musical.

Observa cómo pasamos una lista de componentes de entrada y salida, y comprueba si puedes seguir lo que está sucediendo.

La clave aquí es que cuando pasas:
* una lista de componentes de entrada, cada componente corresponde a un parámetro en orden.
* una lista de componentes de salida, cada componente corresponde a un valor retornado.

El siguiente fragmento de código muestra cómo se alinean tres componentes de entrada con los tres argumentos de la función `generate_tone()`:

```py
import numpy as np
import gradio as gr

notes = ["C", "C#", "D", "D#", "E", "F", "F#", "G", "G#", "A", "A#", "B"]


def generate_tone(note, octave, duration):
    sr = 48000
    a4_freq, tones_from_a4 = 440, 12 * (octave - 4) + (note - 9)
    frequency = a4_freq * 2 ** (tones_from_a4 / 12)
    duration = int(duration)
    audio = np.linspace(0, duration, duration * sr)
    audio = (20000 * np.sin(audio * (2 * np.pi * frequency))).astype(np.int16)
    return (sr, audio)


gr.Interface(
    generate_tone,
    [
        gr.Dropdown(notes, type="index"),
        gr.Slider(minimum=4, maximum=6, step=1),
        gr.Number(value=1, label="Duration in seconds"),
    ],
    "audio",
).launch()
```

### El método `launch()`[[the-launch-method]]

Hasta ahora, hemos utilizado el método `launch()` para iniciar la interfaz, pero no hemos profundizado en lo que hace realmente.

Por defecto, el método `launch()` iniciará la demo en un servidor web que se ejecuta localmente. Si estás ejecutando tu código en un notebook de Jupyter o Colab, Gradio incrustará la GUI de la demo en el notebook para que puedas usarla fácilmente.

Puedes personalizar el comportamiento de `launch()` mediante diferentes parámetros:

  - `inline` - si se debe mostrar la interfaz integrada en notebooks de Python.
  - `inbrowser` - si se debe abrir automáticamente la interfaz en una nueva pestaña del navegador predeterminado.
  - `share` - si se debe crear un enlace públicamente compartible desde tu computadora para la interfaz. ¡Algo así como un enlace de Google Drive!

¡Cubriremos el parámetro `share` con mucho más detalle en la siguiente sección!

## ✏️ ¡Apliquémoslo![[lets-apply-it]]

Construyamos una interfaz que te permita hacer una demo de un modelo de **reconocimiento de voz** (*speech recognition*).
Para hacerlo interesante, aceptaremos *tanto* una entrada de micrófono como un archivo subido.

Como de costumbre, cargaremos nuestro modelo de reconocimiento de voz utilizando la función `pipeline()` de 🤗 Transformers.
Si necesitas un repaso rápido, puedes volver a [esa sección en el Capítulo 1](/course/chapter1/3). A continuación, implementaremos una función `transcribe_audio()` que procese el audio y devuelva la transcripción. Finalmente, envolveremos esta función en una `Interface` con el componente `Audio` para las entradas y simplemente texto para la salida. En conjunto, el código para esta aplicación es el siguiente:

```py
from transformers import pipeline
import gradio as gr

model = pipeline("automatic-speech-recognition")


def transcribe_audio(audio):
    transcription = model(audio)["text"]
    return transcription


gr.Interface(
    fn=transcribe_audio,
    inputs=gr.Audio(type="filepath"),
    outputs="text",
).launch()
```
