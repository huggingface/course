Para comenzar a usar Argilla, primero deberás configurar tu propia instancia de Argilla. Luego deberás instalar el SDK de Python para poder administrar Argilla mediante código de Python.

## Desplegar la interfaz de Argilla

La forma más sencilla de configurar tu instancia de Argilla es a través de Hugging Face Spaces. Para crear tu Argilla Space, simplemente sigue [este formulario](https://huggingface.co/new-space?template=argilla%2Fargilla-template-space). Si necesitas más orientación, consulta el [inicio rápido de Argilla](https://docs.argilla.io/latest/getting_started/quickstart/).
<img src="https://huggingface.co/datasets/huggingface-course/documentation-images/resolve/main/en/chapter10/space_config.png" alt="Space configuration form."/>

>[!WARNING]
> ⚠️ Es posible que desees habilitar el **Almacenamiento persistente** (*Persistent storage*) para que los datos no se pierdan si el Space se pausa o reinicia.
> Puedes hacerlo desde los Ajustes (*Settings*) de tu Space.

Una vez que Argilla esté funcionando, puedes iniciar sesión con tus credenciales.

## Instalar y conectar el SDK de Python

Ahora puedes ir a tu entorno de Python o notebook e instalar la biblioteca argilla:

`!pip install argilla`

Conectémonos con nuestra instancia de Argilla. Para hacerlo, necesitarás la siguiente información:

- **Tu URL de la API**: Esta es la URL donde se está ejecutando Argilla. Si estás usando un Space, puedes abrir el Space, hacer clic en los tres puntos en la esquina superior derecha, luego en "Embed this Space" y copiar la **Direct URL**. Debería verse algo como `https://<tu-nombre-de-usuario>.<nombre-del-space>.hf.space`.
- **Tu clave de API**: Para obtener tu clave, inicia sesión en tu instancia de Argilla y ve a "My Settings", luego copia la clave de API.
- **Tu token de HF**: Si tu Space es privado, necesitarás un token de acceso en tu cuenta de Hugging Face Hub con permisos de escritura.

```python
import argilla as rg

HF_TOKEN = "..."  # solo para spaces privados

client = rg.Argilla(
    api_url="...",
    api_key="...",
    headers={"Authorization": f"Bearer {HF_TOKEN}"},  # solo para spaces privados
)
```

Para verificar que todo funciona correctamente, llamaremos a `me`. Esto debería devolver nuestro usuario:

```python
client.me
```

Si esto funcionó, ¡tu instancia de Argilla está en funcionamiento y estás conectado a ella! ¡Felicitaciones!
