En el Capítulo 5 aprendiste a crear un dataset utilizando la biblioteca 🤗 Datasets y en el Capítulo 6 exploraste cómo ajustar finamente modelos para algunas tareas comunes de PLN. En este capítulo, aprenderás a usar [Argilla](https://argilla.io) para **anotar y curar datasets** que puedes usar para entrenar y evaluar tus modelos.

La clave para entrenar modelos que funcionen bien es disponer de datos de alta calidad. Aunque existen algunos buenos datasets en el Hub que podrías usar para entrenar y evaluar tus modelos, es posible que no sean relevantes para tu aplicación o caso de uso específico. En este escenario, es posible que desees crear y curar un dataset propio. Argilla te ayudará a hacerlo de manera eficiente.

<img src="https://huggingface.co/datasets/huggingface-course/documentation-images/resolve/main/en/chapter10/signin-hf-page.png" alt="Argilla sign in page."/>

Con Argilla puedes:

- transformar datos no estructurados en **datos estructurados** para su uso en tareas de PLN.
- curar un dataset para pasar de un conjunto de datos de baja calidad a un **dataset de alta calidad**.
- recopilar **retroalimentación humana** para LLMs y modelos multimodales.
- ¡invitar a expertos a colaborar contigo en Argilla o realizar anotaciones mediante crowdsourcing!

Estas son algunas de las cosas que aprenderás en este capítulo:

- Cómo configurar tu propia instancia de Argilla.
- Cómo cargar un dataset y configurarlo en función de algunas tareas populares de PLN.
- Cómo utilizar la interfaz de usuario de Argilla para anotar tu dataset.
- Cómo utilizar tu dataset curado y exportarlo al Hub.
