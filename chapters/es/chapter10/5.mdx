Aprenderemos ahora cómo exportar y utilizar los datos anotados que tenemos en Argilla.

## Cargar el dataset

Primero, deberemos asegurarnos de estar conectados a nuestra instancia de Argilla como en los pasos anteriores:

```python
import argilla as rg

HF_TOKEN = "..."  # solo para spaces privados

client = rg.Argilla(
    api_url="...",
    api_key="...",
    headers={"Authorization": f"Bearer {HF_TOKEN}"},  # solo para spaces privados
)
```

Y ahora, cargaremos el dataset con el que trabajaremos:

```python
dataset = client.datasets(name="ag_news")
```

Cargar el dataset y llamar a sus registros con `dataset.records` es suficiente para comenzar a usar tu dataset y registros para tus propios propósitos y canalizaciones (*pipelines*). Sin embargo, también aprenderemos cómo realizar algunas operaciones opcionales, como filtrar los registros y exportar tu dataset a Hugging Face Hub.

## Filtrar el dataset

A veces solo deseas utilizar los registros que se han completado, por lo que primero filtraremos los registros en nuestro dataset según su estado:

```python
status_filter = rg.Query(filter=rg.Filter([("status", "==", "completed")]))

filtered_records = dataset.records(status_filter)
```

>[!TIP]
>⚠️ Ten en cuenta que los registros con estado `completed` (es decir, registros que cumplen con el número mínimo de respuestas enviadas configurado en los ajustes de distribución de tareas) podrían tener más de una respuesta y cada respuesta puede tener cualquier estado entre `submitted`, `draft` o `discarded`.

Obtén más información sobre cómo consultar y filtrar registros en la [documentación de Argilla](https://docs.argilla.io/latest/how_to_guides/query/).

## Exportar al Hub

Ahora podemos exportar nuestras anotaciones a Hugging Face Hub para compartirlas con otros. Para hacer esto, necesitaremos convertir los registros en un 🤗 Dataset y luego enviarlo (*push*) al Hub:

```python
filtered_records.to_datasets().push_to_hub("argilla/ag_news_annotated")
```

Alternativamente, podemos exportar directamente el dataset completo de Argilla (incluidos los registros pendientes) de la siguiente manera:

```python
dataset.to_hub(repo_id="argilla/ag_news_annotated")
```

Esta es una opción muy interesante en caso de que otros quieran abrir el dataset en sus instancias de Argilla, ya que las configuraciones se guardan automáticamente y pueden simplemente importar el dataset completo usando una sola línea de código:

```python
dataset = rg.Dataset.from_hub(repo_id="argilla/ag_news_annotated")
```
