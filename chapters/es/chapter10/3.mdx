Es posible importar datasets desde el Hub usando la interfaz de usuario de Argilla directamente, pero usaremos el SDK para aprender cómo podemos realizar modificaciones adicionales a los datos si es necesario.

## Configura tu dataset

El primer paso es conectarse a nuestra instancia de Argilla como hicimos en la sección anterior:

```python
import argilla as rg

HF_TOKEN = "..."  # solo para spaces privados

client = rg.Argilla(
    api_url="...",
    api_key="...",
    headers={"Authorization": f"Bearer {HF_TOKEN}"},  # solo para spaces privados
)
```

Ahora podemos pensar en la configuración de nuestro dataset en Argilla. Esto representa la tarea de anotación que haremos sobre nuestros datos. Primero, podemos cargar el dataset desde el Hub e inspeccionar sus características, para asegurarnos de configurarlo correctamente.

```python
from datasets import load_dataset

data = load_dataset("SetFit/ag_news", split="train")
data.features
```

Estas son las características de nuestro dataset:

```python out
{'text': Value(dtype='string', id=None),
 'label': Value(dtype='int64', id=None),
 'label_text': Value(dtype='string', id=None)}
```

Contiene un `text` y también algunas etiquetas iniciales para la clasificación de texto. Las agregaremos a la configuración de nuestro dataset junto con una pregunta de tipo `spans` para las entidades nombradas:

```python
settings = rg.Settings(
    fields=[rg.TextField(name="text")],
    questions=[
        rg.LabelQuestion(
            name="label", title="Classify the text:", labels=data.unique("label_text")
        ),
        rg.SpanQuestion(
            name="entities",
            title="Highlight all the entities in the text:",
            labels=["PERSON", "ORG", "LOC", "EVENT"],
            field="text",
        ),
    ],
)
```

Profundicemos un poco más en lo que significan estas configuraciones. Primero, hemos definido los **campos** (*fields*), estos incluyen la información que anotaremos. En este caso, solo tenemos un campo y se presenta en forma de texto, por lo que hemos elegido un `TextField`.

Luego, definimos las **preguntas** (*questions*) que representan las tareas que deseamos realizar sobre nuestros datos:

- Para la tarea de clasificación de texto hemos elegido un `LabelQuestion` y usamos los valores únicos de la columna `label_text` como nuestras etiquetas, para asegurarnos de que la pregunta sea compatible con las etiquetas que ya existen en el dataset.
- Para la tarea de clasificación de tokens, necesitaremos un `SpanQuestion`. Hemos definido un conjunto de etiquetas que utilizaremos para esa tarea, más el campo en el que dibujaremos los intervalos (*spans*).

Para obtener más información sobre todos los tipos disponibles de campos y preguntas y otras configuraciones avanzadas, como metadatos y vectores, consulta la [documentación de Argilla](https://docs.argilla.io/latest/how_to_guides/dataset/#define-dataset-settings).

## Subir el dataset

Ahora que hemos definido algunas configuraciones, podemos crear el dataset:

```python
dataset = rg.Dataset(name="ag_news", settings=settings)

dataset.create()
```

El dataset ahora aparece en nuestra instancia de Argilla, pero verás que está vacío:

<img src="https://huggingface.co/datasets/huggingface-course/documentation-images/resolve/main/en/chapter10/empty_dataset.png" alt="Screenshot of the empty dataset."/>

Ahora necesitamos agregar los registros que anotaremos, es decir, las filas de nuestro dataset. Para hacer eso, simplemente necesitaremos registrar los datos como registros y proporcionar un mapeo para aquellos elementos que no tienen el mismo nombre en el Hub y en los datasets de Argilla:

```python
dataset.records.log(data, mapping={"label_text": "label"})
```

En nuestro mapeo, especificamos que la columna `label_text` en el dataset debe mapearse a la pregunta con el nombre `label`. De esta manera, usaremos las etiquetas existentes en el dataset como preanotaciones para poder anotar más rápido.

Mientras los registros continúan cargándose, ya puedes comenzar a trabajar con tu dataset en la interfaz de usuario de Argilla. En este punto, debería verse así:

<img src="https://huggingface.co/datasets/huggingface-course/documentation-images/resolve/main/en/chapter10/argilla_initial_dataset.png" alt="Screenshot of the dataset in Argilla."/>

¡Ahora nuestro dataset está listo para comenzar a anotar!
