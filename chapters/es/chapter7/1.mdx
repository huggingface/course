En el [Capítulo 3](/course/chapter3), viste cómo ajustar un modelo para la clasificación de textos. En este capítulo, abordaremos las siguientes tareas comunes del lenguaje que son esenciales para trabajar tanto con modelos tradicionales de PLN como con LLMs modernos:

- Clasificación de tokens
- Modelado de lenguaje enmascarado (como BERT)
- Resumen de textos
- Traducción
- Preentrenamiento de modelado de lenguaje causal (como GPT-2)
- Respuesta a preguntas

Estas tareas fundamentales constituyen la base de cómo funcionan los Modelos de Lenguaje Grandes (LLMs, por sus siglas en inglés) y comprenderlas es crucial para trabajar eficazmente con los modelos de lenguaje más avanzados de hoy en día.

Para lograr esto, necesitarás aprovechar todo lo que aprendiste sobre la API `Trainer` y la biblioteca 🤗 Accelerate en el [Capítulo 3](/course/chapter3), la biblioteca 🤗 Datasets en el [Capítulo 5](/course/chapter5) y la biblioteca 🤗 Tokenizers en el [Capítulo 6](/course/chapter6). También subiremos nuestros resultados al Model Hub, como hicimos en el [Capítulo 4](/course/chapter4), ¡así que este es realmente el capítulo donde todo encaja!

Cada sección se puede leer de forma independiente y te mostrará cómo entrenar un modelo con la API `Trainer` o con tu propio bucle de entrenamiento, utilizando 🤗 Accelerate. Siéntete libre de saltar cualquiera de las partes y concentrarte en la que más te interese: la API `Trainer` es genial para ajustar o entrenar tu modelo sin preocuparte por lo que sucede detrás de escena, mientras que el bucle de entrenamiento con `Accelerate` te permitirá personalizar cualquier parte que desees más fácilmente.
