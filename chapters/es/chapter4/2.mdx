El Model Hub facilita la selección del modelo adecuado, de modo que utilizarlo en cualquier librería derivada (*downstream library*) requiere únicamente unas pocas líneas de código. Veamos cómo utilizar realmente uno de estos modelos y cómo retribuir a la comunidad.

Supongamos que estamos buscando un modelo basado en francés que pueda realizar el llenado de máscaras (*mask filling*).

<div class="flex justify-center">
<img src="https://huggingface.co/datasets/huggingface-course/documentation-images/resolve/main/en/chapter4/camembert.gif" alt="Seleccionando el modelo Camembert." width="80%"/>
</div>

Seleccionamos el checkpoint `camembert-base` para probarlo. ¡El identificador `camembert-base` es todo lo que necesitamos para comenzar a utilizarlo! Como has visto en capítulos anteriores, podemos instanciarlo utilizando la función `pipeline()`:

```py
from transformers import pipeline

camembert_fill_mask = pipeline("fill-mask", model="camembert-base")
results = camembert_fill_mask("Le camembert est <mask> :)")
```

Como puedes ver, cargar un modelo dentro de un pipeline es sumamente simple. Lo único a lo que debes prestar atención es que el checkpoint elegido sea adecuado para la tarea en la que se va a utilizar. Por ejemplo, aquí estamos cargando el checkpoint `camembert-base` en el pipeline `fill-mask`, lo cual es completamente correcto. Pero si cargáramos este checkpoint en el pipeline `text-classification`, los resultados no tendrían ningún sentido porque la cabeza (*head*) de `camembert-base` no es apta para esa tarea. Recomendamos utilizar el selector de tareas en la interfaz del Hugging Face Hub para elegir los checkpoints adecuados:

<div class="flex justify-center">
<img src="https://huggingface.co/datasets/huggingface-course/documentation-images/resolve/main/en/chapter4/tasks.png" alt="El selector de tareas en la interfaz web." width="80%"/>
</div>

También puedes instanciar el checkpoint utilizando la arquitectura del modelo directamente:

{#if fw === 'pt'}
```py
from transformers import CamembertTokenizer, CamembertForMaskedLM

tokenizer = CamembertTokenizer.from_pretrained("camembert-base")
model = CamembertForMaskedLM.from_pretrained("camembert-base")
```

Sin embargo, recomendamos usar las [clases `Auto*`](https://huggingface.co/transformers/model_doc/auto?highlight=auto#auto-classes) en su lugar, ya que por diseño son agnósticas a la arquitectura. Mientras que el ejemplo de código anterior limita a los usuarios a checkpoints cargables en la arquitectura CamemBERT, utilizar las clases `Auto*` facilita enormemente cambiar entre diferentes checkpoints:

```py
from transformers import AutoTokenizer, AutoModelForMaskedLM

tokenizer = AutoTokenizer.from_pretrained("camembert-base")
model = AutoModelForMaskedLM.from_pretrained("camembert-base")
```

> [!TIP]
> Al utilizar un modelo preentrenado, asegúrate de revisar cómo fue entrenado, en qué conjuntos de datos, sus límites y sus sesgos. Toda esta información debe indicarse en su tarjeta de modelo (*model card*).
