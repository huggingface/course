## Cargar el modelo

Ahora, carguemos el modelo.

Para este ejercicio, utilizaremos el modelo [`SmolLM2-135M`](https://huggingface.co/HuggingFaceTB/SmolLM2-135M).

Este es un modelo pequeño de 135M de parámetros que se ejecuta en hardware limitado. Esto lo hace ideal para el aprendizaje, aunque no es el modelo más potente del mercado. Si tienes acceso a hardware más potente, puedes intentar ajustar un modelo más grande como [`SmolLM2-1.7B`](https://huggingface.co/HuggingFaceTB/SmolLM2-1.7B).

model_id = "HuggingFaceTB/SmolLM-135M-Instruct"
model = AutoModelForCausalLM.from_pretrained(
    model_id,
    torch_dtype="auto",
    device_map="auto",
    attn_implementation="flash_attention_2",

## Cargar LoRA

Ahora, carguemos la configuración de LoRA. Aprovecharemos LoRA para reducir la cantidad de parámetros entrenables y, a su vez, la huella de memoria necesaria para ajustar el modelo.

Si no estás familiarizado con LoRA, puedes leer más al respecto en el [Capítulo 11](https://huggingface.co/learn/course/en/chapter11/3).

```python
# Cargar LoRA
lora_config = LoraConfig(
    task_type="CAUSAL_LM",
    r=16,
    lora_alpha=32,
    target_modules="all-linear",
)
model = get_peft_model(model, lora_config)
print(model.print_trainable_parameters())
```

## Definir la función de recompensa

Como se mencionó en la sección anterior, GRPO puede utilizar cualquier función de recompensa para mejorar el modelo. En este caso, utilizaremos una función de recompensa simple que anima al modelo a generar texto de 50 tokens de longitud.

```python
# Función de recompensa
ideal_length = 50


def reward_len(completions, **kwargs):
    return [-abs(ideal_length - len(completion)) for completion in completions]
```

## Definir los argumentos de entrenamiento

Ahora definamos los argumentos de entrenamiento. Usaremos la clase `GRPOConfig` para definir los argumentos de entrenamiento en el estilo típico de `transformers`.

Si es la primera vez que defines argumentos de entrenamiento, puedes consultar la clase [TrainingArguments](https://huggingface.co/docs/transformers/en/main_classes/trainer#trainingarguments) para más información, o el [Capítulo 2](https://huggingface.co/learn/course/en/chapter2/1) para una introducción detallada.

```python
# Argumentos de entrenamiento
training_args = GRPOConfig(
    output_dir="GRPO",
    learning_rate=2e-5,
    per_device_train_batch_size=8,
    gradient_accumulation_steps=2,
    max_prompt_length=512,
    max_completion_length=96,
    num_generations=8,
    optim="adamw_8bit",
    num_train_epochs=1,
    bf16=True,
    report_to=["wandb"],
    remove_unused_columns=False,
    logging_steps=1,
)
```

Ahora podemos inicializar el entrenador con el modelo, el conjunto de datos y los argumentos de entrenamiento, y comenzar el entrenamiento.

```python
# Entrenador
trainer = GRPOTrainer(
    model=model,
    reward_funcs=[reward_len],
    args=training_args,
    train_dataset=dataset["train"],
)

# Entrenar modelo
wandb.init(project="GRPO")
trainer.train()
```

El entrenamiento toma alrededor de 1 hora en una sola GPU A10G, disponible en Google Colab o a través de Hugging Face Spaces.

## Interpretar los resultados del entrenamiento

`GRPOTrainer` registra la recompensa de tu función de recompensa, la pérdida y una serie de otras métricas.

Nos centraremos en la recompensa de la función de recompensa y en la pérdida.

Como puedes ver, la recompensa de la función de recompensa se acerca a 0 a medida que el modelo aprende. Esta es una buena señal de que el modelo está aprendiendo a generar texto con la longitud correcta.

![Recompensa de la función de recompensa](https://huggingface.co/reasoning-course/images/resolve/main/grpo/13.png)

Podrías notar que la pérdida comienza en cero y luego aumenta durante el entrenamiento, lo que puede parecer contradictorio. Este comportamiento es el esperado en GRPO y está directamente relacionado con la formulación matemática del algoritmo. La pérdida en GRPO es proporcional a la divergencia KL (el límite relativo a la política original). A medida que avanza el entrenamiento, el modelo aprende a generar texto que coincide mejor con la función de recompensa, lo que hace que diverja más de su política inicial. Esta divergencia creciente se refleja en el valor ascendente de la pérdida, lo que realmente indica que el modelo se está adaptando exitosamente para optimizar la función de recompensa.

![Pérdida](https://huggingface.co/reasoning-course/images/resolve/main/grpo/14.png)

```python
prompt = """
# A long document about the Cat

The cat (Felis catus), also referred to as the domestic cat or house cat, is a small 
domesticated carnivorous mammal. It is the only domesticated species of the family Felidae.
Advances in archaeology and genetics have shown that the domestication of the cat occurred
in the Near East around 7500 BC. It is commonly kept as a pet and farm cat, but also ranges
freely as a feral cat avoiding human contact. It is valued by humans for companionship and
its ability to kill vermin. Its retractable claws are adapted to killing small prey species
such as mice and rats. It has a strong, flexible body, quick reflexes, and sharp teeth,
and its night vision and sense of smell are well developed. It is a social species,
but a solitary hunter and a crepuscular predator. Cat communication includes
vocalizations—including meowing, purring, trilling, hissing, growling, and grunting—as
well as body language. It can hear sounds too faint or too high in frequency for human ears,
such as those made by small mammals. It secretes and perceives pheromones.
"""

messages = [
    {"role": "user", "content": prompt},
]
```

Ahora podemos generar texto con el modelo:

```python
# Generar texto
from transformers import pipeline

generator = pipeline("text-generation", model="SmolGRPO-135M")

## O usar el modelo y tokenizador que definimos anteriormente
# generator = pipeline("text-generation", model=model, tokenizer=tokenizer)

generate_kwargs = {
    "max_new_tokens": 256,
    "do_sample": True,
    "temperature": 0.5,
    "min_p": 0.1,
}

generated_text = generator(messages, generate_kwargs=generate_kwargs)

print(generated_text)
```
