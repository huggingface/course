## Menggunakan pipeline[[working-with-pipelines]]

<Youtube id="tiZFewofSLM" />

Fungsi `pipeline()` ialah antara alat paling mudah digunakan dalam pustaka 🤗 Transformers. Fungsi ini menyambungkan model dengan langkah pre-processing dan post-processing yang diperlukan, jadi kita boleh memasukkan teks dan mendapatkan hasil yang mudah ditafsir:

```python
from transformers import pipeline

classifier = pipeline("sentiment-analysis")
classifier("I've been waiting for a HuggingFace course my whole life.")
```

```python out
[{'label': 'POSITIVE', 'score': 0.9598047137260437}]
```

Kita juga boleh memasukkan beberapa ayat sekali gus!

```python
classifier(
    ["I've been waiting for a HuggingFace course my whole life.", "I hate this so much!"]
)
```

```python out
[{'label': 'POSITIVE', 'score': 0.9598047137260437},
 {'label': 'NEGATIVE', 'score': 0.9994558095932007}]
```

Secara lalai, pipeline ini memilih model pralatih yang telah ditala halus untuk analisis sentimen dalam bahasa Inggeris. Model itu dimuat turun dan disimpan dalam cache apabila objek `classifier` dicipta. Jika anda menjalankan arahan itu sekali lagi, model dalam cache akan digunakan dan tidak perlu dimuat turun semula.

Apabila teks diberikan kepada pipeline, tiga langkah utama berlaku:

1. Teks dipraproses kepada format yang boleh difahami oleh model.
2. Input yang telah dipraproses diberikan kepada model.
3. Ramalan model diproses semula supaya mudah difahami.

## Pipeline yang tersedia untuk pelbagai modaliti

Fungsi `pipeline()` menyokong pelbagai modaliti, termasuk teks, imej, audio dan tugasan multimodal. Kursus ini berfokus pada tugasan teks, tetapi kita akan meninjau secara ringkas potensi seni bina Transformer dalam modaliti lain. 

Berikut ialah gambaran keseluruhan pipeline yang tersedia:

> [!TIP]
> Untuk senarai pipeline yang lengkap dan terkini, rujuk [dokumentasi 🤗 Transformers](https://huggingface.co/docs/hub/en/models-tasks).

### Pipeline teks

- `text-generation`: Menjana teks daripada prompt
- `text-classification`: Mengelaskan teks kepada kategori yang ditetapkan
- `summarization`: Memendekkan teks sambil mengekalkan maklumat penting
- `translation`: Menterjemahkan teks daripada satu bahasa kepada bahasa lain
- `zero-shot-classification`: Mengelaskan teks tanpa latihan terdahulu pada label tertentu
- `feature-extraction`: Mengekstrak perwakilan vektor teks

### Pipeline imej

- `image-to-text`: Menjana penerangan teks bagi imej
- `image-classification`: Mengenal pasti objek dalam imej
- `object-detection`: Mengesan lokasi dan mengenal pasti objek dalam imej

### Pipeline audio

- `automatic-speech-recognition`: Menukar pertuturan kepada teks
- `audio-classification`: Mengelaskan audio kepada kategori
- `text-to-speech`: Menukar teks kepada pertuturan

### Pipeline multimodal

- `image-text-to-text`: Menjawab tentang imej berdasarkan prompt teks

Mari kita teliti beberapa pipeline ini dengan lebih lanjut!

## Pengelasan zero-shot[[zero-shot-classification]]

Kita mulakan dengan tugasan yang lebih mencabar: mengelaskan teks yang belum dilabel. Situasi ini lazim dalam projek sebenar kerana anotasi teks biasanya memakan masa dan memerlukan kepakaran bidang. Pipeline `zero-shot-classification` amat berguna untuk tugasan ini: anda boleh menentukan label pengelasan sendiri tanpa bergantung pada label model pralatih. Model boleh mengelaskan ayat sebagai positif atau negatif, tetapi juga boleh menggunakan set label lain yang anda tentukan.

```python
from transformers import pipeline

classifier = pipeline("zero-shot-classification")
classifier(
    "This is a course about the Transformers library",
    candidate_labels=["education", "politics", "business"],
)
```

```python out
{'sequence': 'This is a course about the Transformers library',
 'labels': ['education', 'business', 'politics'],
 'scores': [0.8445963859558105, 0.111976258456707, 0.043427448719739914]}
```

Pipeline ini dipanggil _zero-shot_ kerana anda tidak perlu menala halus model menggunakan data sendiri. Pipeline ini boleh terus memberikan skor kebarangkalian bagi sebarang senarai label!

> [!TIP]
> ✏️ **Cuba sendiri!** Uji jujukan dan label anda dan perhatikan tindak balas model.


## Penjanaan teks[[text-generation]]

Sekarang mari gunakan pipeline untuk menjana teks. Anda memberikan prompt dan model melengkapkannya dengan menjana teks seterusnya. Cara ini serupa dengan ciri teks ramalan pada telefon. Penjanaan teks melibatkan unsur rawak, jadi hasil anda mungkin berbeza daripada contoh di bawah.

```python
from transformers import pipeline

generator = pipeline("text-generation")
generator("In this course, we will teach you how to")
```

```python out
[{'generated_text': 'In this course, we will teach you how to understand and use '
                    'data flow and data interchange when handling user data. We '
                    'will be working with one or more of the most commonly used '
                    'data flows — data flows of various types, as seen by the '
                    'HTTP'}]
```

Anda boleh menetapkan bilangan jujukan yang dijana dengan argumen `num_return_sequences` dan panjang keseluruhan teks output dengan argumen `max_length`.

> [!TIP]
> ✏️ **Cuba sendiri!** Gunakan argumen `num_return_sequences` dan `max_length` untuk menjana dua ayat yang masing-masing mengandungi 15 perkataan.

## Menggunakan mana-mana model Hub dalam pipeline[[using-any-model-from-the-hub-in-a-pipeline]]

Contoh sebelum ini menggunakan model lalai bagi tugasan tersebut, tetapi anda juga boleh memilih model tertentu daripada Hub untuk tugasan khusus, seperti penjanaan teks. Pergi ke [Model Hub](https://huggingface.co/models) dan klik tag yang sepadan di sebelah kiri untuk memaparkan model yang menyokong tugasan itu. Anda akan melihat halaman seperti [ini](https://huggingface.co/models?pipeline_tag=text-generation).

Mari cuba model [`HuggingFaceTB/SmolLM2-360M`](https://huggingface.co/HuggingFaceTB/SmolLM2-360M)! Berikut cara memuatkannya dalam pipeline yang sama:

```python
from transformers import pipeline

generator = pipeline("text-generation", model="HuggingFaceTB/SmolLM2-360M")
generator(
    "In this course, we will teach you how to",
    max_length=30,
    num_return_sequences=2,
)
```

```python out
[{'generated_text': 'In this course, we will teach you how to manipulate the world and '
                    'move your mental and physical capabilities to your advantage.'},
 {'generated_text': 'In this course, we will teach you how to become an expert and '
                    'practice realtime, and with a hands on experience on both real '
                    'time and real'}]
```

Anda boleh menapis carian model menggunakan tag bahasa dan memilih model yang menjana teks dalam bahasa lain. Model Hub turut menyediakan checkpoint model berbilang bahasa.

Selepas memilih model, anda akan melihat widget untuk mencubanya terus dalam talian. Dengan cara ini, anda boleh menguji keupayaan model dengan cepat sebelum memuat turunnya.

> [!TIP]
> ✏️ **Cuba sendiri!** Gunakan penapis untuk mencari model penjanaan teks dalam bahasa lain. Cuba widget itu dan gunakan model dalam pipeline!

## Pengisian mask[[mask-filling]]

Pipeline seterusnya ialah `fill-mask`, yang mengisi ruang kosong dalam teks:

```python
from transformers import pipeline

unmasker = pipeline("fill-mask")
unmasker("This course will teach you all about <mask> models.", top_k=2)
```

```python out
[{'sequence': 'This course will teach you all about mathematical models.',
  'score': 0.19619831442832947,
  'token': 30412,
  'token_str': ' mathematical'},
 {'sequence': 'This course will teach you all about computational models.',
  'score': 0.04052725434303284,
  'token': 38163,
  'token_str': ' computational'}]
```

Argumen `top_k` menentukan bilangan pilihan yang dipaparkan. Model di sini mengisi token khas `<mask>`, yang dipanggil *token mask*. Model pengisian mask lain mungkin menggunakan token mask yang berbeza, jadi semak token yang betul apabila mencuba model lain. Anda boleh melihat token itu pada widget.

> [!TIP]
> ✏️ **Cuba sendiri!** Cari model `bert-base-cased` di Hub dan kenal pasti token masknya dalam widget Inference API. Apakah ramalan model ini untuk ayat dalam contoh `pipeline` di atas?

## Pengecaman entiti bernama[[named-entity-recognition]]

Pengecaman entiti bernama (NER) ialah tugasan mengenal pasti bahagian teks input yang merujuk kepada entiti seperti orang, lokasi atau organisasi. Mari lihat contoh:

```python
from transformers import pipeline

ner = pipeline("ner", aggregation_strategy="simple")
ner("My name is Sylvain and I work at Hugging Face in Brooklyn.")
```

```python out
[{'entity_group': 'PER', 'score': 0.99816, 'word': 'Sylvain', 'start': 11, 'end': 18}, 
 {'entity_group': 'ORG', 'score': 0.97960, 'word': 'Hugging Face', 'start': 33, 'end': 45}, 
 {'entity_group': 'LOC', 'score': 0.99321, 'word': 'Brooklyn', 'start': 49, 'end': 57}
]
```

Model mengenal pasti Sylvain sebagai orang (PER), Hugging Face sebagai organisasi (ORG) dan Brooklyn sebagai lokasi (LOC).

Kita memberikan pilihan `aggregation_strategy="simple"` semasa mencipta pipeline supaya bahagian ayat yang merujuk kepada entiti sama digabungkan. Di sini, model menggabungkan "Hugging" dan "Face" sebagai satu organisasi walaupun namanya terdiri daripada beberapa perkataan. Seperti yang akan kita lihat dalam bab seterusnya, pre-processing turut memecahkan sesetengah perkataan kepada bahagian lebih kecil. Contohnya, `Sylvain` dipecahkan kepada `S`, `##yl`, `##va` dan `##in`. Pipeline menggabungkan semula bahagian tersebut semasa post-processing.

> [!TIP]
> ✏️ **Cuba sendiri!** Cari model di Model Hub yang boleh menandai golongan kata (biasanya disingkatkan sebagai POS) dalam bahasa Inggeris. Apakah ramalan model untuk ayat dalam contoh di atas?

## Penjawab soalan[[question-answering]]

Pipeline `question-answering` menjawab soalan menggunakan maklumat daripada konteks yang diberikan:

```python
from transformers import pipeline

question_answerer = pipeline("question-answering")
question_answerer(
    question="Where do I work?",
    context="My name is Sylvain and I work at Hugging Face in Brooklyn",
)
```

```python out
{'score': 0.6385916471481323, 'start': 33, 'end': 45, 'answer': 'Hugging Face'}
```

Pipeline ini mengekstrak maklumat daripada konteks yang diberikan; pipeline ini tidak menjana jawapan baharu.

## Peringkasan[[summarization]]

Peringkasan memendekkan teks sambil mengekalkan semua (atau kebanyakan) maklumat penting yang terkandung di dalamnya. Berikut contoh:

```python
from transformers import pipeline

summarizer = pipeline("summarization")
summarizer("""
    America has changed dramatically during recent years. Not only has the number of 
    graduates in traditional engineering disciplines such as mechanical, civil, 
    electrical, chemical, and aeronautical engineering declined, but in most of 
    the premier American universities engineering curricula now concentrate on 
    and encourage largely the study of engineering science. As a result, there 
    are declining offerings in engineering subjects dealing with infrastructure, 
    the environment, and related issues, and greater concentration on high 
    technology subjects, largely supporting increasingly complex scientific 
    developments. While the latter is important, it should not be at the expense 
    of more traditional engineering.

    Rapidly developing economies such as China and India, as well as other 
    industrial countries in Europe and Asia, continue to encourage and advance 
    the teaching of engineering. Both China and India, respectively, graduate 
    six and eight times as many traditional engineers as does the United States. 
    Other industrial countries at minimum maintain their output, while America 
    suffers an increasingly serious decline in the number of engineering graduates 
    and a lack of well-educated engineers.
""")
```

```python out
[{'summary_text': ' America has changed dramatically during recent years . The '
                  'number of engineering graduates in the U.S. has declined in '
                  'traditional engineering disciplines such as mechanical, civil '
                  ', electrical, chemical, and aeronautical engineering . Rapidly '
                  'developing economies such as China and India, as well as other '
                  'industrial countries in Europe and Asia, continue to encourage '
                  'and advance engineering .'}]
```

Seperti penjanaan teks, anda boleh menetapkan `max_length` atau `min_length` bagi hasilnya.


## Terjemahan[[translation]]

Untuk terjemahan, anda boleh menggunakan model lalai dengan menyatakan pasangan bahasa dalam nama tugasan (contohnya `"translation_en_to_fr"`). Namun, cara paling mudah ialah memilih model daripada [Model Hub](https://huggingface.co/models). Di sini kita akan menterjemahkan bahasa Perancis kepada bahasa Inggeris:

```python
from transformers import pipeline

translator = pipeline("translation", model="Helsinki-NLP/opus-mt-fr-en")
translator("Ce cours est produit par Hugging Face.")
```

```python out
[{'translation_text': 'This course is produced by Hugging Face.'}]
```

Seperti penjanaan teks dan peringkasan, anda boleh menetapkan `max_length` atau `min_length` bagi hasilnya.

> [!TIP]
> ✏️ **Cuba sendiri!** Cari model terjemahan bagi bahasa lain dan cuba terjemahkan ayat sebelumnya ke dalam beberapa bahasa.

## Pipeline imej dan audio

Selain teks, model Transformer juga boleh memproses imej dan audio. Berikut beberapa contoh:

### Pengelasan imej

```python
from transformers import pipeline

image_classifier = pipeline(
    task="image-classification", model="google/vit-base-patch16-224"
)
result = image_classifier(
    "https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/pipeline-cat-chonk.jpeg"
)
print(result)
```

```python out
[{'label': 'lynx, catamount', 'score': 0.43350091576576233},
 {'label': 'cougar, puma, catamount, mountain lion, painter, panther, Felis concolor',
  'score': 0.034796204417943954},
 {'label': 'snow leopard, ounce, Panthera uncia',
  'score': 0.03240183740854263},
 {'label': 'Egyptian cat', 'score': 0.02394474856555462},
 {'label': 'tiger cat', 'score': 0.02288915030658245}]
```

### Pengecaman pertuturan automatik

```python
from transformers import pipeline

transcriber = pipeline(
    task="automatic-speech-recognition", model="openai/whisper-large-v3"
)
result = transcriber(
    "https://huggingface.co/datasets/Narsil/asr_dummy/resolve/main/mlk.flac"
)
print(result)
```

```python out
{'text': ' I have a dream that one day this nation will rise up and live out the true meaning of its creed.'}
```

## Menggabungkan data daripada pelbagai sumber

Satu kegunaan berkuasa model Transformer ialah keupayaannya menggabungkan dan memproses data daripada pelbagai sumber. Keupayaan ini amat berguna apabila anda perlu:

1. Membuat carian merentas berbilang pangkalan data atau repo
2. Menggabungkan maklumat daripada pelbagai format (teks, imej, audio)
3. Membina paparan bersepadu bagi maklumat berkaitan

Contohnya, anda boleh membina sistem yang:
- Mencari maklumat dalam pangkalan data merentas modaliti seperti teks dan imej.
- Menggabungkan hasil daripada sumber berbeza menjadi satu jawapan yang koheren, contohnya daripada fail audio dan penerangan teks.
- Memaparkan maklumat paling relevan daripada pangkalan data dokumen dan metadata.
