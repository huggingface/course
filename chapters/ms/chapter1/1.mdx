## Memahami NLP dan LLM[[understanding-nlp-and-llms]]

Pada asalnya, kursus ini berfokus pada NLP (Natural Language Processing). Kini, kursus ini turut membincangkan LLM (Large Language Models), antara perkembangan terbaharu dalam bidang tersebut.

**Apakah perbezaannya?**
- **NLP (Natural Language Processing)** ialah bidang luas yang membolehkan komputer memproses, mentafsir dan menjana bahasa manusia. Bidang ini merangkumi pelbagai teknik dan tugasan, termasuk analisis sentimen, pengecaman entiti bernama dan terjemahan mesin.
- **LLM (Large Language Models)** ialah sejenis model NLP berskala besar yang dilatih menggunakan data yang banyak. Model ini boleh melaksanakan pelbagai tugasan bahasa tanpa banyak latihan khusus untuk setiap tugasan. Siri Llama, GPT dan Claude ialah contoh LLM yang memperluas keupayaan NLP.

Sepanjang kursus ini, anda akan mempelajari konsep NLP tradisional dan teknik LLM terkini. Memahami asas NLP penting untuk menggunakan LLM dengan berkesan.

## Soalan lazim[[faq]]

Berikut jawapan kepada beberapa soalan lazim:

- **Adakah kursus ini memberikan sijil?**
Pada masa ini, kursus ini tidak menawarkan sijil. Namun, kami sedang membangunkan program pensijilan untuk ekosistem Hugging Face — nantikannya!

- **Berapa banyak masa yang perlu saya luangkan untuk kursus ini?**
Peruntukkan kira-kira 6–8 jam seminggu untuk setiap bab. Anda boleh melaraskan tempoh ini mengikut kesesuaian.

- **Di manakah saya boleh bertanya soalan?**
Jika anda mempunyai soalan tentang mana-mana bahagian kursus, klik sepanduk "*Ask a question*" di bahagian atas halaman untuk dibawa ke bahagian yang betul dalam [forum Hugging Face](https://discuss.huggingface.co/):

<img src="https://huggingface.co/datasets/huggingface-course/documentation-images/resolve/main/en/chapter1/forum-button.png" alt="Pautan ke forum Hugging Face" width="75%">

Forum ini juga menyediakan senarai [idea projek](https://discuss.huggingface.co/c/course/course-event/25) untuk latihan selepas anda menamatkan kursus.

- **Di manakah saya boleh mendapatkan kod kursus?**
Untuk setiap bahagian, klik sepanduk di bahagian atas halaman untuk menjalankan kod dalam Google Colab atau Amazon SageMaker Studio Lab:

<img src="https://huggingface.co/datasets/huggingface-course/documentation-images/resolve/main/en/chapter1/notebook-buttons.png" alt="Pautan ke notebook kursus Hugging Face" width="75%">

Notebook Jupyter yang mengandungi kod kursus dihoskan dalam repo [`huggingface/notebooks`](https://github.com/huggingface/notebooks). Untuk menjana notebook secara setempat, ikuti arahan dalam repo [`course`](https://github.com/huggingface/course#-jupyter-notebooks) di GitHub.

- **Bagaimanakah saya boleh menyumbang kepada kursus ini?**
Terdapat banyak cara untuk menyumbang. Jika anda menemui kesilapan taip atau pepijat, buka isu dalam repo [`course`](https://github.com/huggingface/course). Untuk membantu menterjemahkan kursus ke bahasa ibunda anda, ikuti arahan [di sini](https://github.com/huggingface/course#translating-the-course-into-your-language).

- **Apakah pilihan istilah yang dibuat bagi setiap terjemahan?**
Setiap terjemahan mempunyai glosari dan fail `TRANSLATING.txt` yang menerangkan pilihan istilah jargon pembelajaran mesin. Lihat contoh bahasa Jerman [di sini](https://github.com/huggingface/course/blob/main/chapters/de/TRANSLATING.txt).
