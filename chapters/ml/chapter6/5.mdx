Byte-Pair Encoding (BPE) തുടക്കത്തിൽ ടെക്‌സ്‌റ്റുകൾ കംപ്രസ് ചെയ്യാനുള്ള ഒരു അൽഗോരിതമായാണ് വികസിപ്പിച്ചത്; പിന്നീട് GPT മോഡൽ പ്രീട്രെയിൻ ചെയ്യുമ്പോൾ ടോക്കണൈസേഷനായി OpenAI ഇത് ഉപയോഗിച്ചു. GPT, GPT-2, RoBERTa, BART, DeBERTa എന്നിവയുൾപ്പെടെ ധാരാളം Transformer മോഡലുകൾ ഇത് ഉപയോഗിക്കുന്നു.

> [!TIP]
> 💡 ഒരു പൂർണ്ണമായ ഇംപ്ലിമെന്റേഷൻ (implementation) കാണിക്കുന്നത് വരെ പോകുന്ന തരത്തിൽ, ഈ ഭാഗം BPE-യെ ആഴത്തിൽ പരിശോധിക്കുന്നു. ടോക്കണൈസേഷൻ അൽഗോരിതത്തിന്റെ ഒരു പൊതുവായ അവലോകനം മാത്രമാണ് നിങ്ങൾക്ക് വേണ്ടതെങ്കിൽ, നിങ്ങൾക്ക് നേരെ അവസാനത്തേക്ക് പോകാം.

## ട്രെയിനിംഗ് അൽഗോരിതം[[training-algorithm]]

കോർപ്പസിൽ (corpus) ഉപയോഗിച്ചിരിക്കുന്ന വാക്കുകളുടെ അനന്യമായ (unique) ഗണം കണക്കാക്കിക്കൊണ്ടാണ് BPE ട്രെയിനിംഗ് ആരംഭിക്കുന്നത് (നോർമലൈസേഷൻ, പ്രീ-ടോക്കണൈസേഷൻ ഘട്ടങ്ങൾ പൂർത്തിയായതിന് ശേഷം); പിന്നീട് ആ വാക്കുകൾ എഴുതാൻ ഉപയോഗിച്ചിരിക്കുന്ന എല്ലാ അക്ഷരങ്ങളും (symbols) എടുത്ത് വൊക്കാബുലറി (vocabulary) നിർമ്മിക്കുന്നു. വളരെ ലളിതമായ ഒരു ഉദാഹരണമായി, നമ്മുടെ കോർപ്പസ് ഈ അഞ്ച് വാക്കുകൾ ഉപയോഗിക്കുന്നു എന്ന് കരുതുക:

```
"hug", "pug", "pun", "bun", "hugs"
```

അപ്പോൾ അടിസ്ഥാന വൊക്കാബുലറി `["b", "g", "h", "n", "p", "s", "u"]` ആയിരിക്കും. യഥാർത്ഥ ലോകത്തിലെ സാഹചര്യങ്ങളിൽ, ആ അടിസ്ഥാന വൊക്കാബുലറിയിൽ ഏറ്റവും കുറഞ്ഞത് എല്ലാ ASCII അക്ഷരങ്ങളും, ഒരുപക്ഷേ ചില Unicode അക്ഷരങ്ങളും ഉണ്ടായിരിക്കും. നിങ്ങൾ ടോക്കണൈസ് ചെയ്യുന്ന ഒരു ഉദാഹരണത്തിൽ ട്രെയിനിംഗ് കോർപ്പസിൽ ഇല്ലാത്ത ഒരു അക്ഷരം ഉപയോഗിച്ചിട്ടുണ്ടെങ്കിൽ, ആ അക്ഷരം unknown ടോക്കണിലേക്ക് മാറ്റപ്പെടും. ഉദാഹരണത്തിന്, ഇമോജികൾ ഉള്ള ഉള്ളടക്കം വിശകലനം ചെയ്യുന്നതിൽ ധാരാളം NLP മോഡലുകൾ വളരെ മോശമായിരിക്കുന്നതിന്റെ ഒരു കാരണം ഇതാണ്.

> [!TIP]
> GPT-2, RoBERTa ടോക്കണൈസറുകൾക്ക് (ഇവ ഏറെക്കുറെ സമാനമാണ്) ഇത് കൈകാര്യം ചെയ്യാൻ ഒരു ബുദ്ധിപൂർവ്വമായ മാർഗമുണ്ട്: വാക്കുകളെ Unicode അക്ഷരങ്ങൾ കൊണ്ട് എഴുതിയവയായല്ല, ബൈറ്റുകൾ (bytes) കൊണ്ട് എഴുതിയവയായാണ് അവ കാണുന്നത്. ഇങ്ങനെ അടിസ്ഥാന വൊക്കാബുലറിക്ക് ചെറിയ വലുപ്പമാണ് (256) ഉള്ളത്, എന്നാൽ നിങ്ങൾക്ക് ചിന്തിക്കാൻ കഴിയുന്ന ഏത് അക്ഷരവും അതിൽ ഉൾപ്പെട്ടിരിക്കും, unknown ടോക്കണിലേക്ക് മാറ്റപ്പെടുകയുമില്ല. ഈ തന്ത്രത്തെ *byte-level BPE* എന്ന് വിളിക്കുന്നു.

ഈ അടിസ്ഥാന വൊക്കാബുലറി ലഭിച്ചതിന് ശേഷം, *മെർജുകൾ* (merges) പഠിച്ചുകൊണ്ട്, ആവശ്യമുള്ള വൊക്കാബുലറി വലുപ്പം എത്തുന്നത് വരെ നമ്മൾ പുതിയ ടോക്കണുകൾ ചേർക്കുന്നു; നിലവിലുള്ള വൊക്കാബുലറിയിലെ രണ്ട് ഘടകങ്ങളെ ഒന്നിച്ചുചേർത്ത് ഒരു പുതിയ ഘടകമാക്കാനുള്ള നിയമങ്ങളാണ് മെർജുകൾ. അതിനാൽ, തുടക്കത്തിൽ ഈ മെർജുകൾ രണ്ട് അക്ഷരങ്ങളുള്ള ടോക്കണുകൾ സൃഷ്ടിക്കും; പിന്നീട്, ട്രെയിനിംഗ് പുരോഗമിക്കുമ്പോൾ, കൂടുതൽ നീളമുള്ള സബ്‌വേഡുകളും.

ടോക്കണൈസർ ട്രെയിനിംഗിലെ ഏത് ഘട്ടത്തിലും, നിലവിലുള്ള ടോക്കണുകളുടെ ഏറ്റവും കൂടുതൽ തവണ വരുന്ന (most frequent) ജോഡിക്കായി BPE അൽഗോരിതം തിരയും ("ജോഡി" എന്നതുകൊണ്ട് ഇവിടെ നമ്മൾ അർത്ഥമാക്കുന്നത് ഒരു വാക്കിലെ തുടർച്ചയായ രണ്ട് ടോക്കണുകളാണ്). ഏറ്റവും കൂടുതൽ തവണ വരുന്ന ആ ജോഡിയാണ് മെർജ് ചെയ്യപ്പെടുന്നത്; അടുത്ത ഘട്ടത്തിനായി നമ്മൾ ഇത് വീണ്ടും ആവർത്തിക്കുന്നു.

നമ്മുടെ മുൻ ഉദാഹരണത്തിലേക്ക് തിരിച്ചുപോയാൽ, വാക്കുകൾക്ക് താഴെ പറയുന്ന ആവൃത്തികൾ (frequencies) ഉണ്ടായിരുന്നു എന്ന് കരുതുക:

```
("hug", 10), ("pug", 5), ("pun", 12), ("bun", 4), ("hugs", 5)
```

അതായത് `"hug"` കോർപ്പസിൽ 10 തവണയും, `"pug"` 5 തവണയും, `"pun"` 12 തവണയും, `"bun"` 4 തവണയും, `"hugs"` 5 തവണയും ഉണ്ടായിരുന്നു. ഓരോ വാക്കിനെയും അക്ഷരങ്ങളായി (നമ്മുടെ പ്രാരംഭ വൊക്കാബുലറി രൂപപ്പെടുത്തുന്നവ) വിഭജിച്ചുകൊണ്ടാണ് നമ്മൾ ട്രെയിനിംഗ് ആരംഭിക്കുന്നത്; അങ്ങനെ ഓരോ വാക്കിനെയും ടോക്കണുകളുടെ ഒരു ലിസ്‌റ്റായി നമുക്ക് കാണാൻ കഴിയും:

```
("h" "u" "g", 10), ("p" "u" "g", 5), ("p" "u" "n", 12), ("b" "u" "n", 4), ("h" "u" "g" "s", 5)
```

പിന്നീട് നമ്മൾ ജോഡികളെ നോക്കുന്നു. `("h", "u")` എന്ന ജോഡി `"hug"`, `"hugs"` എന്ന വാക്കുകളിൽ ഉണ്ട്, അതായത് കോർപ്പസിൽ മൊത്തം 15 തവണ. എന്നാൽ, ഇത് ഏറ്റവും കൂടുതൽ തവണ വരുന്ന ജോഡിയല്ല: ആ ബഹുമതി `("u", "g")`-ന് അവകാശപ്പെട്ടതാണ്; ഇത് `"hug"`, `"pug"`, `"hugs"` എന്നിവയിൽ ഉണ്ട്, വൊക്കാബുലറിയിൽ ആകെ 20 തവണ.

അതിനാൽ, ടോക്കണൈസർ പഠിക്കുന്ന ആദ്യ മെർജ് നിയമം `("u", "g") -> "ug"` ആണ്; അതായത് `"ug"` വൊക്കാബുലറിയിലേക്ക് ചേർക്കപ്പെടും, കൂടാതെ കോർപ്പസിലെ എല്ലാ വാക്കുകളിലും ഈ ജോഡി മെർജ് ചെയ്യപ്പെടണം. ഈ ഘട്ടത്തിന്റെ അവസാനം, വൊക്കാബുലറിയും കോർപ്പസും ഇങ്ങനെയായിരിക്കും:

```
Vocabulary: ["b", "g", "h", "n", "p", "s", "u", "ug"]
Corpus: ("h" "ug", 10), ("p" "ug", 5), ("p" "u" "n", 12), ("b" "u" "n", 4), ("h" "ug" "s", 5)
```

ഇപ്പോൾ രണ്ട് അക്ഷരങ്ങളിൽ കൂടുതൽ നീളമുള്ള ഒരു ടോക്കണിൽ കലാശിക്കുന്ന ചില ജോഡികൾ നമുക്കുണ്ട്: ഉദാഹരണത്തിന്, `("h", "ug")` എന്ന ജോഡി (കോർപ്പസിൽ 15 തവണ ഉണ്ട്). എന്നാൽ, ഈ ഘട്ടത്തിൽ ഏറ്റവും കൂടുതൽ തവണ വരുന്ന ജോഡി `("u", "n")` ആണ്, കോർപ്പസിൽ 16 തവണ ഉണ്ട്; അതിനാൽ പഠിക്കുന്ന രണ്ടാമത്തെ മെർജ് നിയമം `("u", "n") -> "un"` ആണ്. അത് വൊക്കാബുലറിയിലേക്ക് ചേർക്കുകയും നിലവിലുള്ള എല്ലാ സന്ദർഭങ്ങളും (occurrences) മെർജ് ചെയ്യുകയും ചെയ്യുമ്പോൾ നമുക്ക് ലഭിക്കുന്നത്:

```
Vocabulary: ["b", "g", "h", "n", "p", "s", "u", "ug", "un"]
Corpus: ("h" "ug", 10), ("p" "ug", 5), ("p" "un", 12), ("b" "un", 4), ("h" "ug" "s", 5)
```

ഇപ്പോൾ ഏറ്റവും കൂടുതൽ തവണ വരുന്ന ജോഡി `("h", "ug")` ആണ്, അതിനാൽ `("h", "ug") -> "hug"` എന്ന മെർജ് നിയമം നമ്മൾ പഠിക്കുന്നു; ഇത് നമുക്ക് നമ്മുടെ ആദ്യത്തെ മൂന്നക്ഷര ടോക്കൺ നൽകുന്നു. മെർജിന് ശേഷം, കോർപ്പസ് ഇങ്ങനെയായിരിക്കും:

```
Vocabulary: ["b", "g", "h", "n", "p", "s", "u", "ug", "un", "hug"]
Corpus: ("hug", 10), ("p" "ug", 5), ("p" "un", 12), ("b" "un", 4), ("hug" "s", 5)
```

ആവശ്യമുള്ള വൊക്കാബുലറി വലുപ്പത്തിൽ എത്തുന്നത് വരെ നമ്മൾ ഇങ്ങനെ തുടരുന്നു.

> [!TIP]
> ✏️ **ഇനി നിങ്ങളുടെ ഊഴം!** അടുത്ത മെർജ് നിയമം എന്തായിരിക്കും എന്നാണ് നിങ്ങൾ കരുതുന്നത്?

## ടോക്കണൈസേഷൻ അൽഗോരിതം[[tokenization-algorithm]]

ടോക്കണൈസേഷൻ ട്രെയിനിംഗ് പ്രക്രിയയെ അടുത്ത് പിന്തുടരുന്നു; അതായത്, താഴെ പറയുന്ന ഘട്ടങ്ങൾ പ്രയോഗിച്ചുകൊണ്ടാണ് പുതിയ ഇൻപുട്ടുകൾ ടോക്കണൈസ് ചെയ്യപ്പെടുന്നത്:

1. നോർമലൈസേഷൻ
2. പ്രീ-ടോക്കണൈസേഷൻ
3. വാക്കുകളെ ഓരോ അക്ഷരങ്ങളായി വിഭജിക്കുക
4. പഠിച്ച മെർജ് നിയമങ്ങൾ ക്രമത്തിൽ ആ വിഭജനങ്ങളിൽ (splits) പ്രയോഗിക്കുക

ട്രെയിനിംഗ് സമയത്ത് നമ്മൾ ഉപയോഗിച്ച ഉദാഹരണം, പഠിച്ച മൂന്ന് മെർജ് നിയമങ്ങളോടൊപ്പം എടുക്കാം:

```
("u", "g") -> "ug"
("u", "n") -> "un"
("h", "ug") -> "hug"
```

`"bug"` എന്ന വാക്ക് `["b", "ug"]` എന്ന് ടോക്കണൈസ് ചെയ്യപ്പെടും. എന്നാൽ, `"m"` എന്ന അക്ഷരം അടിസ്ഥാന വൊക്കാബുലറിയിൽ ഇല്ലാതിരുന്നതിനാൽ `"mug"` എന്നത് `["[UNK]", "ug"]` എന്ന് ടോക്കണൈസ് ചെയ്യപ്പെടും. അതുപോലെ, `"thug"` എന്ന വാക്ക് `["[UNK]", "hug"]` എന്ന് ടോക്കണൈസ് ചെയ്യപ്പെടും: `"t"` എന്ന അക്ഷരം അടിസ്ഥാന വൊക്കാബുലറിയിൽ ഇല്ല, കൂടാതെ മെർജ് നിയമങ്ങൾ പ്രയോഗിക്കുമ്പോൾ ആദ്യം `"u"`-ഉം `"g"`-ഉം മെർജ് ചെയ്യപ്പെടുകയും പിന്നീട് `"h"`-ഉം `"ug"`-ഉം മെർജ് ചെയ്യപ്പെടുകയും ചെയ്യുന്നു.

> [!TIP]
> ✏️ **ഇനി നിങ്ങളുടെ ഊഴം!** `"unhug"` എന്ന വാക്ക് എങ്ങനെ ടോക്കണൈസ് ചെയ്യപ്പെടും എന്നാണ് നിങ്ങൾ കരുതുന്നത്?

## BPE ഇംപ്ലിമെന്റ് ചെയ്യുന്നു[[implementing-bpe]]

ഇനി BPE അൽഗോരിതത്തിന്റെ ഒരു ഇംപ്ലിമെന്റേഷൻ നമുക്ക് ഒന്ന് നോക്കാം. ഒരു വലിയ കോർപ്പസിൽ നിങ്ങൾക്ക് യഥാർത്ഥത്തിൽ ഉപയോഗിക്കാൻ കഴിയുന്ന ഒരു ഒപ്‌റ്റിമൈസ് ചെയ്ത പതിപ്പായിരിക്കില്ല ഇത്; അൽഗോരിതം കുറച്ചുകൂടി നന്നായി മനസ്സിലാക്കാൻ നിങ്ങളെ സഹായിക്കുന്നതിനായി കോഡ് കാണിച്ചുതരാൻ മാത്രമാണ് ഞങ്ങൾ ഉദ്ദേശിക്കുന്നത്.

ആദ്യം നമുക്ക് ഒരു കോർപ്പസ് ആവശ്യമാണ്, അതിനാൽ ഏതാനും വാക്യങ്ങളുള്ള ലളിതമായ ഒന്ന് നമുക്ക് സൃഷ്ടിക്കാം:

```python
corpus = [
    "This is the Hugging Face Course.",
    "This chapter is about tokenization.",
    "This section shows several tokenizer algorithms.",
    "Hopefully, you will be able to understand how they are trained and generate tokens.",
]
```

അടുത്തതായി, ആ കോർപ്പസിനെ വാക്കുകളായി പ്രീ-ടോക്കണൈസ് ചെയ്യേണ്ടതുണ്ട്. നമ്മൾ ഒരു BPE ടോക്കണൈസറിനെ (GPT-2 പോലുള്ളത്) പുനഃസൃഷ്ടിക്കുന്നതിനാൽ, പ്രീ-ടോക്കണൈസേഷനായി `gpt2` ടോക്കണൈസർ നമ്മൾ ഉപയോഗിക്കും:

```python
from transformers import AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained("gpt2")
```

പിന്നീട്, പ്രീ-ടോക്കണൈസേഷൻ ചെയ്യുന്നതിനോടൊപ്പം കോർപ്പസിലെ ഓരോ വാക്കിന്റെയും ആവൃത്തി നമ്മൾ കണക്കാക്കുന്നു:

```python
from collections import defaultdict

word_freqs = defaultdict(int)

for text in corpus:
    words_with_offsets = tokenizer.backend_tokenizer.pre_tokenizer.pre_tokenize_str(text)
    new_words = [word for word, offset in words_with_offsets]
    for word in new_words:
        word_freqs[word] += 1

print(word_freqs)
```

മോഡൽ ഉപയോഗിക്കുന്ന പ്രത്യേക ടോക്കണുകളും (special tokens) ആ വൊക്കാബുലറിയുടെ തുടക്കത്തിൽ നമ്മൾ ചേർക്കുന്നു. GPT-2-ന്റെ കാര്യത്തിൽ, ഒരേയൊരു പ്രത്യേക ടോക്കൺ `"<|endoftext|>"` ആണ്:

```python
vocab = ["<|endoftext|>"] + alphabet.copy()
```

ട്രെയിനിംഗ് ആരംഭിക്കാൻ കഴിയുന്നതിനായി, ഇപ്പോൾ ഓരോ വാക്കിനെയും ഓരോ അക്ഷരങ്ങളായി നമ്മൾ വിഭജിക്കേണ്ടതുണ്ട്:

```python
splits = {word: [c for c in word] for word in word_freqs.keys()}
```

ഇപ്പോൾ നമ്മൾ ട്രെയിനിംഗിന് തയ്യാറായ സ്ഥിതിക്ക്, ഓരോ ജോഡിയുടെയും ആവൃത്തി കണക്കാക്കുന്ന ഒരു ഫംഗ്‌ഷൻ എഴുതാം. ട്രെയിനിംഗിന്റെ ഓരോ ഘട്ടത്തിലും നമുക്ക് ഇത് ഉപയോഗിക്കേണ്ടിവരും:

```python
def compute_pair_freqs(splits):
    pair_freqs = defaultdict(int)
    for word, freq in word_freqs.items():
        split = splits[word]
        if len(split) == 1:
            continue
        for i in range(len(split) - 1):
            pair = (split[i], split[i + 1])
            pair_freqs[pair] += freq
    return pair_freqs
```

പ്രാരംഭ വിഭജനങ്ങൾക്ക് ശേഷം ഈ ഡിക്‌ഷണറിയുടെ ഒരു ഭാഗം നമുക്ക് ഒന്ന് നോക്കാം:

```python
pair_freqs = compute_pair_freqs(splits)

for i, key in enumerate(pair_freqs.keys()):
    print(f"{key}: {pair_freqs[key]}")
    if i >= 5:
        break
```

```python
merges = {("Ġ", "t"): "Ġt"}

തുടരാൻ, ആ മെർജ് നമ്മുടെ `splits` ഡിക്‌ഷണറിയിൽ പ്രയോഗിക്കേണ്ടതുണ്ട്. ഇതിനായി മറ്റൊരു ഫംഗ്‌ഷൻ എഴുതാം:

```python
def merge_pair(a, b, splits):
    for word in word_freqs:
        split = splits[word]
        if len(split) == 1:
            continue

        i = 0
        while i < len(split) - 1:
            if split[i] == a and split[i + 1] == b:
                split = split[:i] + [a + b] + split[i + 2 :]
            else:
                i += 1
        splits[word] = split
    return splits
```

ആദ്യ മെർജിന്റെ ഫലം നമുക്ക് ഒന്ന് നോക്കാം:

```py
splits = merge_pair("Ġ", "t", splits)
print(splits["Ġtrained"])
```

> [!TIP]
> 💡 അതേ കോർപ്പസിൽ `train_new_from_iterator()` ഉപയോഗിച്ചാൽ കൃത്യമായി ഇതേ വൊക്കാബുലറി ലഭിക്കില്ല. ഏറ്റവും കൂടുതൽ തവണ വരുന്ന ജോഡി തിരഞ്ഞെടുക്കാൻ ഒന്നിലധികം സാധ്യതകൾ ഉള്ളപ്പോൾ, നമ്മൾ ആദ്യം കണ്ടുമുട്ടിയതിനെ തിരഞ്ഞെടുത്തു, അതേസമയം 🤗 Tokenizers ലൈബ്രറി അതിന്റെ ആന്തരിക ID-കൾ അടിസ്ഥാനമാക്കി ആദ്യത്തേതിനെ തിരഞ്ഞെടുക്കുന്നു എന്നതാണ് ഇതിന് കാരണം.

ഒരു പുതിയ ടെക്‌സ്‌റ്റ് ടോക്കണൈസ് ചെയ്യാൻ, നമ്മൾ അതിനെ പ്രീ-ടോക്കണൈസ് ചെയ്യുകയും, വിഭജിക്കുകയും, പിന്നീട് പഠിച്ച എല്ലാ മെർജ് നിയമങ്ങളും പ്രയോഗിക്കുകയും ചെയ്യുന്നു:

```python
def tokenize(text):
    pre_tokenize_result = tokenizer._tokenizer.pre_tokenizer.pre_tokenize_str(text)
    pre_tokenized_text = [word for word, offset in pre_tokenize_result]
    splits = [[l for l in word] for word in pre_tokenized_text]
    for pair, merge in merges.items():
        for idx, split in enumerate(splits):
            i = 0
            while i < len(split) - 1:
                if split[i] == pair[0] and split[i + 1] == pair[1]:
                    split = split[:i] + [merge] + split[i + 2 :]
                else:
                    i += 1
            splits[idx] = split

    return sum(splits, [])
```

ആൽഫബെറ്റിലെ അക്ഷരങ്ങൾ കൊണ്ട് രചിച്ച ഏത് ടെക്‌സ്‌റ്റിലും നമുക്ക് ഇത് പരീക്ഷിക്കാം:

```py
tokenize("This is not a token.")

BPE-യുടെ ഈ വശം ഈ ഭാഗത്തിന്റെ പരിധിക്ക് പുറത്താണ്, അതിനാൽ വിശദാംശങ്ങൾ ഞങ്ങൾ ഒഴിവാക്കിയിരിക്കുന്നു.
