BERT പ്രീട്രെയിൻ ചെയ്യാൻ Google വികസിപ്പിച്ച ടോക്കണൈസേഷൻ അൽഗോരിതമാണ് WordPiece. അതിനുശേഷം, DistilBERT, MobileBERT, Funnel Transformers, MPNET തുടങ്ങിയ, BERT അടിസ്ഥാനമാക്കിയുള്ള നിരവധി Transformer മോഡലുകളിൽ ഇത് വീണ്ടും ഉപയോഗിക്കപ്പെട്ടിട്ടുണ്ട്. ട്രെയിനിംഗിന്റെ കാര്യത്തിൽ ഇത് BPE-യോട് വളരെ സാമ്യമുള്ളതാണ്, എന്നാൽ യഥാർത്ഥ ടോക്കണൈസേഷൻ വ്യത്യസ്തമായ രീതിയിലാണ് ചെയ്യുന്നത്.

## ട്രെയിനിംഗ് അൽഗോരിതം[[training-algorithm]]

> [!WARNING]
> ⚠️ WordPiece-ന്റെ ട്രെയിനിംഗ് അൽഗോരിതത്തിന്റെ ഇംപ്ലിമെന്റേഷൻ Google ഒരിക്കലും ഓപ്പൻ-സോഴ്‌സ് ചെയ്തിട്ടില്ല, അതിനാൽ താഴെ പറയുന്നത് പ്രസിദ്ധീകരിക്കപ്പെട്ട ഗവേഷണ പ്രബന്ധങ്ങളെ അടിസ്ഥാനമാക്കിയുള്ള ഞങ്ങളുടെ ഏറ്റവും മികച്ച ഊഹമാണ്. ഇത് 100% കൃത്യമായിരിക്കണമെന്നില്ല.

BPE പോലെ, മോഡൽ ഉപയോഗിക്കുന്ന സ്‌പെഷ്യൽ ടോക്കണുകളും പ്രാരംഭ അക്ഷരമാലയും (alphabet) ഉൾപ്പെടുന്ന ഒരു ചെറിയ വൊക്കാബുലറിയിൽ നിന്നാണ് WordPiece ആരംഭിക്കുന്നത്. ഒരു പ്രിഫിക്‌സ് (BERT-ന്റെ കാര്യത്തിൽ `##` പോലെ) ചേർത്താണ് ഇത് സബ്‌വേഡുകളെ തിരിച്ചറിയുന്നത് എന്നതിനാൽ, വാക്കിനുള്ളിലെ എല്ലാ ക്യാരക്‌ടറുകൾക്കും ആ പ്രിഫിക്‌സ് ചേർത്താണ് ഓരോ വാക്കും തുടക്കത്തിൽ വിഭജിക്കപ്പെടുന്നത്. അതിനാൽ, ഉദാഹരണത്തിന്, `"word"` ഇങ്ങനെ വിഭജിക്കപ്പെടുന്നു:

```
w ##o ##r ##d
```

അങ്ങനെ, ഒരു വാക്കിന്റെ തുടക്കത്തിൽ വരുന്ന എല്ലാ ക്യാരക്‌ടറുകളും, WordPiece പ്രിഫിക്‌സ് മുന്നിൽ ചേർത്ത നിലയിൽ വാക്കിനുള്ളിൽ വരുന്ന ക്യാരക്‌ടറുകളും പ്രാരംഭ അക്ഷരമാലയിൽ അടങ്ങിയിരിക്കുന്നു.

തുടർന്ന്, വീണ്ടും BPE പോലെ, WordPiece മെർജ് നിയമങ്ങൾ (merge rules) പഠിക്കുന്നു. മെർജ് ചെയ്യേണ്ട ജോഡി തിരഞ്ഞെടുക്കുന്ന രീതിയാണ് പ്രധാന വ്യത്യാസം. ഏറ്റവും കൂടുതൽ തവണ വരുന്ന ജോഡി തിരഞ്ഞെടുക്കുന്നതിന് പകരം, താഴെ പറയുന്ന ഫോർമുല ഉപയോഗിച്ച് WordPiece ഓരോ ജോഡിക്കും ഒരു സ്‌കോർ കണക്കാക്കുന്നു:

$$\mathrm{score} = (\mathrm{freq\_of\_pair}) / (\mathrm{freq\_of\_first\_element} \times \mathrm{freq\_of\_second\_element})$$

ജോഡിയുടെ ഫ്രീക്വൻസിയെ (frequency) അതിന്റെ ഓരോ ഭാഗത്തിന്റെയും ഫ്രീക്വൻസികളുടെ ഗുണനഫലം കൊണ്ട് ഹരിക്കുന്നതിലൂടെ, ഒറ്റയ്ക്കുള്ള ഭാഗങ്ങൾ വൊക്കാബുലറിയിൽ കുറവ് തവണ വരുന്ന ജോഡികളെ മെർജ് ചെയ്യുന്നതിന് അൽഗോരിതം മുൻഗണന നൽകുന്നു. ഉദാഹരണത്തിന്, `("un", "##able")` എന്ന ജോഡി വൊക്കാബുലറിയിൽ വളരെ കൂടുതൽ തവണ വന്നാലും അത് നിർബന്ധമായും മെർജ് ചെയ്യപ്പെടണമെന്നില്ല, കാരണം `"un"`, `"##able"` എന്നീ രണ്ട് ഭാഗങ്ങളും വേറെ ധാരാളം വാക്കുകളിൽ പ്രത്യക്ഷപ്പെടാനും ഉയർന്ന ഫ്രീക്വൻസി ഉണ്ടാകാനും സാധ്യതയുണ്ട്. അതിന് വിപരീതമായി, `("hu", "##gging")` പോലുള്ള ഒരു ജോഡി ഒരുപക്ഷേ വേഗത്തിൽ മെർജ് ചെയ്യപ്പെടും ("hugging" എന്ന വാക്ക് വൊക്കാബുലറിയിൽ പതിവായി വരുന്നു എന്ന് കരുതിയാൽ), കാരണം `"hu"`, `"##gging"` എന്നിവ ഒറ്റയ്ക്ക് കുറവ് തവണയേ വരാൻ സാധ്യതയുള്ളൂ.

BPE ട്രെയിനിംഗ് ഉദാഹരണത്തിൽ നമ്മൾ ഉപയോഗിച്ച അതേ വൊക്കാബുലറി നോക്കാം:

```
("hug", 10), ("pug", 5), ("pun", 12), ("bun", 4), ("hugs", 5)
```

ഇവിടെ വിഭജനങ്ങൾ (splits) ഇങ്ങനെയായിരിക്കും:

```
("h" "##u" "##g", 10), ("p" "##u" "##g", 5), ("p" "##u" "##n", 12), ("b" "##u" "##n", 4), ("h" "##u" "##g" "##s", 5)
```

അതിനാൽ പ്രാരംഭ വൊക്കാബുലറി `["b", "h", "p", "##g", "##n", "##s", "##u"]` ആയിരിക്കും (സ്‌പെഷ്യൽ ടോക്കണുകളെ തൽക്കാലം മറന്നാൽ). ഏറ്റവും കൂടുതൽ തവണ വരുന്ന ജോഡി `("##u", "##g")` ആണ് (20 തവണ വരുന്നു), എന്നാൽ `"##u"`-ന്റെ ഒറ്റയ്ക്കുള്ള ഫ്രീക്വൻസി വളരെ ഉയർന്നതാണ്, അതിനാൽ അതിന്റെ സ്‌കോർ ഏറ്റവും ഉയർന്നതല്ല (അത് 1 / 36 ആണ്). `"##u"` ഉള്ള എല്ലാ ജോഡികൾക്കും യഥാർത്ഥത്തിൽ അതേ സ്‌കോർ (1 / 36) ആണ്, അതിനാൽ ഏറ്റവും മികച്ച സ്‌കോർ `("##g", "##s")` എന്ന ജോഡിക്ക് ലഭിക്കുന്നു -- `"##u"` ഇല്ലാത്ത ഒരേയൊരു ജോഡി -- 1 / 20 എന്ന സ്‌കോറോടെ; പഠിക്കപ്പെടുന്ന ആദ്യത്തെ മെർജ് `("##g", "##s") -> ("##gs")` ആണ്.

മെർജ് ചെയ്യുമ്പോൾ, രണ്ട് ടോക്കണുകൾക്കിടയിലുള്ള `##` നമ്മൾ നീക്കം ചെയ്യുന്നു എന്നത് ശ്രദ്ധിക്കുക; അതിനാൽ `"##gs"` വൊക്കാബുലറിയിൽ ചേർത്ത്, കോർപ്പസിലെ വാക്കുകളിൽ ആ മെർജ് പ്രയോഗിക്കുന്നു:

```
Vocabulary: ["b", "h", "p", "##g", "##n", "##s", "##u", "##gs"]
Corpus: ("h" "##u" "##g", 10), ("p" "##u" "##g", 5), ("p" "##u" "##n", 12), ("b" "##u" "##n", 4), ("h" "##u" "##gs", 5)
```

ഈ ഘട്ടത്തിൽ, സാധ്യമായ എല്ലാ ജോഡികളിലും `"##u"` ഉണ്ട്, അതിനാൽ അവയ്‌ക്കെല്ലാം ഒരേ സ്‌കോർ ലഭിക്കുന്നു. ഈ സാഹചര്യത്തിൽ ആദ്യത്തെ ജോഡി മെർജ് ചെയ്യപ്പെടുന്നു എന്ന് കരുതാം, അതായത് `("h", "##u") -> "hu"`. ഇത് നമ്മളെ ഇവിടേക്ക് എത്തിക്കുന്നു:

```
Vocabulary: ["b", "h", "p", "##g", "##n", "##s", "##u", "##gs", "hu"]
Corpus: ("hu" "##g", 10), ("p" "##u" "##g", 5), ("p" "##u" "##n", 12), ("b" "##u" "##n", 4), ("hu" "##gs", 5)
```

തുടർന്ന്, അടുത്ത മികച്ച സ്‌കോർ `("hu", "##g")`, `("hu", "##gs")` എന്നിവ പങ്കിടുന്നു (മറ്റെല്ലാ ജോഡികൾക്കും 1/21 ആയിരിക്കുമ്പോൾ ഇവയ്ക്ക് 1/15), അതിനാൽ ഏറ്റവും വലിയ സ്‌കോറുള്ള ആദ്യത്തെ ജോഡി മെർജ് ചെയ്യപ്പെടുന്നു:

```
Vocabulary: ["b", "h", "p", "##g", "##n", "##s", "##u", "##gs", "hu", "hug"]
Corpus: ("hug", 10), ("p" "##u" "##g", 5), ("p" "##u" "##n", 12), ("b" "##u" "##n", 4), ("hu" "##gs", 5)
```

ആവശ്യമുള്ള വൊക്കാബുലറി വലിപ്പത്തിൽ എത്തുന്നതുവരെ നമ്മൾ ഇങ്ങനെ തുടരുന്നു.

## ടോക്കണൈസേഷൻ അൽഗോരിതം[[tokenization-algorithm]]

പഠിച്ച മെർജ് നിയമങ്ങളല്ല, അന്തിമ വൊക്കാബുലറി മാത്രമാണ് WordPiece സേവ് ചെയ്യുന്നത് എന്നതിലാണ് WordPiece-ലെയും BPE-യിലെയും ടോക്കണൈസേഷൻ വ്യത്യാസപ്പെടുന്നത്. ടോക്കണൈസ് ചെയ്യേണ്ട വാക്കിൽ നിന്ന് ആരംഭിച്ച്, വൊക്കാബുലറിയിലുള്ള ഏറ്റവും നീളമുള്ള സബ്‌വേഡ് WordPiece കണ്ടെത്തുന്നു, തുടർന്ന് അവിടെ വിഭജിക്കുന്നു. ഉദാഹരണത്തിന്, മുകളിലെ ഉദാഹരണത്തിൽ പഠിച്ച വൊക്കാബുലറി ഉപയോഗിക്കുകയാണെങ്കിൽ, `"hugs"` എന്ന വാക്കിന്, തുടക്കത്തിൽ നിന്ന് ആരംഭിക്കുന്ന, വൊക്കാബുലറിയിലുള്ള ഏറ്റവും നീളമുള്ള സബ്‌വേഡ് `"hug"` ആണ്; അതിനാൽ നമ്മൾ അവിടെ വിഭജിച്ച് `["hug", "##s"]` നേടുന്നു. തുടർന്ന് നമ്മൾ `"##s"`-ഉമായി മുന്നോട്ട് പോകുന്നു; അത് വൊക്കാബുലറിയിലുണ്ട്, അതിനാൽ `"hugs"`-ന്റെ ടോക്കണൈസേഷൻ `["hug", "##s"]` ആണ്.

BPE ഉപയോഗിച്ചായിരുന്നെങ്കിൽ, പഠിച്ച മെർജുകൾ ക്രമത്തിൽ പ്രയോഗിച്ച് ഇതിനെ `["hu", "##gs"]` എന്ന് ടോക്കണൈസ് ചെയ്യുമായിരുന്നു, അതിനാൽ എൻകോഡിംഗ് വ്യത്യസ്തമാണ്.

മറ്റൊരു ഉദാഹരണമായി, `"bugs"` എന്ന വാക്ക് എങ്ങനെ ടോക്കണൈസ് ചെയ്യപ്പെടും എന്ന് നോക്കാം. വാക്കിന്റെ തുടക്കത്തിൽ നിന്ന് ആരംഭിക്കുന്ന, വൊക്കാബുലറിയിലുള്ള ഏറ്റവും നീളമുള്ള സബ്‌വേഡ് `"b"` ആണ്, അതിനാൽ നമ്മൾ അവിടെ വിഭജിച്ച് `["b", "##ugs"]` നേടുന്നു. തുടർന്ന്, `"##ugs"`-ന്റെ തുടക്കത്തിൽ നിന്ന് ആരംഭിക്കുന്ന, വൊക്കാബുലറിയിലുള്ള ഏറ്റവും നീളമുള്ള സബ്‌വേഡ് `"##u"` ആണ്, അതിനാൽ നമ്മൾ അവിടെ വിഭജിച്ച് `["b", "##u, "##gs"]` നേടുന്നു. അവസാനമായി, `"##gs"` വൊക്കാബുലറിയിലുണ്ട്, അതിനാൽ ഈ അവസാന ലിസ്‌റ്റാണ് `"bugs"`-ന്റെ ടോക്കണൈസേഷൻ.

വൊക്കാബുലറിയിൽ ഒരു സബ്‌വേഡ് കണ്ടെത്താൻ കഴിയാത്ത ഒരു ഘട്ടത്തിൽ ടോക്കണൈസേഷൻ എത്തുമ്പോൾ, വാക്ക് മുഴുവനും അജ്ഞാതം (unknown) എന്ന് ടോക്കണൈസ് ചെയ്യപ്പെടുന്നു -- അതിനാൽ, ഉദാഹരണത്തിന്, `"mug"` `["[UNK]"]` എന്ന് ടോക്കണൈസ് ചെയ്യപ്പെടും, `"bum"`-ഉം അങ്ങനെതന്നെ (`"b"`, `"##u"` എന്നിവയോടെ നമുക്ക് തുടങ്ങാൻ കഴിയുമെങ്കിലും, `"##m"` വൊക്കാബുലറിയിലില്ല, അതിനാൽ ഫലമായുള്ള ടോക്കണൈസേഷൻ `["b", "##u", "[UNK]"]` അല്ല, വെറും `["[UNK]"]` ആയിരിക്കും). BPE-യിൽ നിന്നുള്ള മറ്റൊരു വ്യത്യാസമാണിത്; BPE വൊക്കാബുലറിയിലില്ലാത്ത ഒറ്റയ്ക്കുള്ള ക്യാരക്‌ടറുകളെ മാത്രമേ അജ്ഞാതമായി തരംതിരിക്കുകയുള്ളൂ.

> [!TIP]
> ✏️ **ഇനി നിങ്ങളുടെ ഊഴം!** `"pugs"` എന്ന വാക്ക് എങ്ങനെ ടോക്കണൈസ് ചെയ്യപ്പെടും?

## WordPiece ഇംപ്ലിമെന്റ് ചെയ്യുന്നു[[implementing-wordpiece]]

ഇനി WordPiece അൽഗോരിതത്തിന്റെ ഒരു ഇംപ്ലിമെന്റേഷൻ നോക്കാം. BPE-യുടെ കാര്യത്തിലേതുപോലെ, ഇത് പഠനാവശ്യത്തിന് മാത്രമുള്ളതാണ്; ഒരു വലിയ കോർപ്പസിൽ ഇത് ഉപയോഗിക്കാൻ നിങ്ങൾക്ക് കഴിയില്ല.

BPE ഉദാഹരണത്തിലെ അതേ കോർപ്പസ് നമ്മൾ ഉപയോഗിക്കും:

```python
corpus = [
    "This is the Hugging Face Course.",
    "This chapter is about tokenization.",
    "This section shows several tokenizer algorithms.",
    "Hopefully, you will be able to understand how they are trained and generate tokens.",
]
```

ആദ്യം, കോർപ്പസിനെ വാക്കുകളായി പ്രീ-ടോക്കണൈസ് ചെയ്യേണ്ടതുണ്ട്. നമ്മൾ ഒരു WordPiece ടോക്കണൈസർ (BERT പോലെ) പുനഃസൃഷ്ടിക്കുകയാണ് എന്നതിനാൽ, പ്രീ-ടോക്കണൈസേഷന് `bert-base-cased` ടോക്കണൈസർ ഉപയോഗിക്കും:

```python
from transformers import AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained("bert-base-cased")
```

തുടർന്ന്, പ്രീ-ടോക്കണൈസേഷൻ ചെയ്യുന്നതോടൊപ്പം കോർപ്പസിലെ ഓരോ വാക്കിന്റെയും ഫ്രീക്വൻസികൾ നമ്മൾ കണക്കാക്കുന്നു:

```python
from collections import defaultdict

word_freqs = defaultdict(int)
for text in corpus:
    words_with_offsets = tokenizer.backend_tokenizer.pre_tokenizer.pre_tokenize_str(text)
    new_words = [word for word, offset in words_with_offsets]
    for word in new_words:
        word_freqs[word] += 1

word_freqs
```

മോഡൽ ഉപയോഗിക്കുന്ന സ്‌പെഷ്യൽ ടോക്കണുകളും ആ വൊക്കാബുലറിയുടെ തുടക്കത്തിൽ നമ്മൾ ചേർക്കുന്നു. BERT-ന്റെ കാര്യത്തിൽ, അത് `["[PAD]", "[UNK]", "[CLS]", "[SEP]", "[MASK]"]` എന്ന ലിസ്‌റ്റാണ്:

```python
vocab = ["[PAD]", "[UNK]", "[CLS]", "[SEP]", "[MASK]"] + alphabet.copy()
```

അടുത്തതായി, ആദ്യത്തേതല്ലാത്ത എല്ലാ അക്ഷരങ്ങൾക്കും `##` പ്രിഫിക്‌സ് ചേർത്ത്, ഓരോ വാക്കും നമ്മൾ വിഭജിക്കേണ്ടതുണ്ട്:

```python
splits = {
    word: [c if i == 0 else f"##{c}" for i, c in enumerate(word)]
    for word in word_freqs.keys()
}
```

ഇപ്പോൾ ട്രെയിനിംഗിന് നമ്മൾ തയ്യാറായതിനാൽ, ഓരോ ജോഡിയുടെയും സ്‌കോർ കണക്കാക്കുന്ന ഒരു ഫംഗ്‌ഷൻ എഴുതാം. ട്രെയിനിംഗിന്റെ ഓരോ ഘട്ടത്തിലും ഇത് നമുക്ക് ഉപയോഗിക്കേണ്ടിവരും:

```python
def compute_pair_scores(splits):
    letter_freqs = defaultdict(int)
    pair_freqs = defaultdict(int)
    for word, freq in word_freqs.items():
        split = splits[word]
        if len(split) == 1:
            letter_freqs[split[0]] += freq
            continue
        for i in range(len(split) - 1):
            pair = (split[i], split[i + 1])
            letter_freqs[split[i]] += freq
            pair_freqs[pair] += freq
        letter_freqs[split[-1]] += freq

    scores = {
        pair: freq / (letter_freqs[pair[0]] * letter_freqs[pair[1]])
        for pair, freq in pair_freqs.items()
    }
    return scores
```

പ്രാരംഭ വിഭജനങ്ങൾക്ക് ശേഷമുള്ള ഈ ഡിക്‌ഷണറിയുടെ ഒരു ഭാഗം നോക്കാം:



അതിനാൽ പഠിക്കേണ്ട ആദ്യത്തെ മെർജ് `('a', '##b') -> 'ab'` ആണ്, നമ്മൾ `'ab'` വൊക്കാബുലറിയിൽ ചേർക്കുന്നു:

തുടരാൻ, നമ്മുടെ `splits` ഡിക്‌ഷണറിയിൽ ആ മെർജ് പ്രയോഗിക്കേണ്ടതുണ്ട്. ഇതിനായി മറ്റൊരു ഫംഗ്‌ഷൻ എഴുതാം:

```python
def merge_pair(a, b, splits):
    for word in word_freqs:
        split = splits[word]
        if len(split) == 1:
            continue
        i = 0
        while i < len(split) - 1:
            if split[i] == a and split[i + 1] == b:
                merge = a + b[2:] if b.startswith("##") else a + b
                split = split[:i] + [merge] + split[i + 2 :]
            else:
                i += 1
        splits[word] = split
    return splits
```

ആദ്യത്തെ മെർജിന്റെ ഫലം നമുക്ക് നോക്കാം:

```py
splits = merge_pair("a", "##b", splits)
splits["about"]
```

```python
vocab_size = 70
while len(vocab) < vocab_size:
    scores = compute_pair_scores(splits)
    best_pair, max_score = "", None
    for pair, score in scores.items():
        if max_score is None or max_score < score:
            best_pair = pair
            max_score = score
    splits = merge_pair(*best_pair, splits)
    new_token = (
        best_pair[0] + best_pair[1][2:]
        if best_pair[1].startswith("##")
        else best_pair[0] + best_pair[1]
    )
    vocab.append(new_token)
```

> 💡 അതേ കോർപ്പസിൽ `train_new_from_iterator()` ഉപയോഗിച്ചാൽ കൃത്യമായി ഇതേ വൊക്കാബുലറി ലഭിക്കില്ല. 🤗 Tokenizers ലൈബ്രറി ട്രെയിനിംഗിനായി WordPiece ഇംപ്ലിമെന്റ് ചെയ്യുന്നില്ല (അതിന്റെ ആന്തരിക പ്രവർത്തനങ്ങളെക്കുറിച്ച് നമുക്ക് പൂർണ്ണമായി ഉറപ്പില്ലാത്തതിനാൽ), പകരം BPE ഉപയോഗിക്കുന്നു എന്നതാണ് ഇതിന് കാരണം.

ഒരു പുതിയ ടെക്‌സ്‌റ്റ് ടോക്കണൈസ് ചെയ്യാൻ, നമ്മൾ അതിനെ പ്രീ-ടോക്കണൈസ് ചെയ്യുന്നു, വിഭജിക്കുന്നു, തുടർന്ന് ഓരോ വാക്കിലും ടോക്കണൈസേഷൻ അൽഗോരിതം പ്രയോഗിക്കുന്നു. അതായത്, ആദ്യ വാക്കിന്റെ തുടക്കത്തിൽ നിന്ന് ആരംഭിക്കുന്ന ഏറ്റവും വലിയ സബ്‌വേഡ് നമ്മൾ തിരഞ്ഞ് അതിനെ വിഭജിക്കുന്നു, തുടർന്ന് രണ്ടാമത്തെ ഭാഗത്തിൽ ഈ പ്രക്രിയ ആവർത്തിക്കുന്നു; അങ്ങനെ ആ വാക്കിന്റെ ബാക്കി ഭാഗത്തിനും ടെക്‌സ്‌റ്റിലെ തുടർന്നുള്ള വാക്കുകൾക്കും ഇത് തുടരുന്നു:

```python
def encode_word(word):
    tokens = []
    while len(word) > 0:
        i = len(word)
        while i > 0 and word[:i] not in vocab:
            i -= 1
        if i == 0:
            return ["[UNK]"]
        tokens.append(word[:i])
        word = word[i:]
        if len(word) > 0:
            word = f"##{word}"
    return tokens
```

വൊക്കാബുലറിയിലുള്ള ഒരു വാക്കിലും അതിൽ ഇല്ലാത്ത മറ്റൊന്നിലും ഇത് പരീക്ഷിച്ചുനോക്കാം:

```python
print(encode_word("Hugging"))
print(encode_word("HOgging"))
```

```python out
['Hugg', '##i', '##n', '##g']
['[UNK]']
```

ഇനി, ഒരു ടെക്‌സ്‌റ്റ് ടോക്കണൈസ് ചെയ്യുന്ന ഒരു ഫംഗ്‌ഷൻ എഴുതാം:

```python
def tokenize(text):
    pre_tokenize_result = tokenizer._tokenizer.pre_tokenizer.pre_tokenize_str(text)
    pre_tokenized_text = [word for word, offset in pre_tokenize_result]
    encoded_words = [encode_word(word) for word in pre_tokenized_text]
    return sum(encoded_words, [])
```

ഏത് ടെക്‌സ്‌റ്റിലും നമുക്ക് ഇത് പരീക്ഷിക്കാം:

```python
tokenize("This is the Hugging Face course!")
```

```python out
 '##e', '[UNK]']
```
