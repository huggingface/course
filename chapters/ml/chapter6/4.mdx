ഒരു ടെക്‌സ്‌റ്റിനെ (അതിന്റെ മോഡലിന് അനുസരിച്ച്) സബ്‌ടോക്കണുകളായി വിഭജിക്കുന്നതിന് മുമ്പ്, ടോക്കണൈസർ രണ്ട് ഘട്ടങ്ങൾ നിർവഹിക്കുന്നു: _നോർമലൈസേഷൻ_ (normalization), _പ്രീ-ടോക്കണൈസേഷൻ_ (pre-tokenization).

## നോർമലൈസേഷൻ[[normalization]]

<Youtube id="4IIC2jI9CaU"/>

അനാവശ്യമായ വൈറ്റ്‌സ്‌പേസ് (whitespace) നീക്കം ചെയ്യുക, അക്ഷരങ്ങളെ ചെറിയക്ഷരങ്ങളാക്കുക (lowercasing), ആക്‌സന്റുകൾ (accents) നീക്കം ചെയ്യുക തുടങ്ങിയ പൊതുവായ ചില ശുദ്ധീകരണ ജോലികളാണ് നോർമലൈസേഷൻ ഘട്ടത്തിൽ ഉൾപ്പെടുന്നത്. [Unicode നോർമലൈസേഷൻ](http://www.unicode.org/reports/tr15/) (NFC അല്ലെങ്കിൽ NFKC പോലുള്ളവ) നിങ്ങൾക്ക് പരിചിതമാണെങ്കിൽ, അതും ടോക്കണൈസർ പ്രയോഗിക്കാൻ സാധ്യതയുള്ള ഒരു കാര്യമാണ്.

🤗 Transformers-ലെ `tokenizer`-ന് `backend_tokenizer` എന്ന ഒരു ആട്രിബ്യൂട്ട് ഉണ്ട്; 🤗 Tokenizers ലൈബ്രറിയിൽ നിന്നുള്ള അടിസ്ഥാന ടോക്കണൈസറിലേക്ക് ഇത് ആക്‌സസ് നൽകുന്നു:

```py
from transformers import AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained("bert-base-uncased")
print(type(tokenizer.backend_tokenizer))
```

```python out
<class 'tokenizers.Tokenizer'>
```

`tokenizer` ഒബ്‌ജക്റ്റിന്റെ `normalizer` ആട്രിബ്യൂട്ടിന് ഒരു `normalize_str()` മെത്തേഡ് ഉണ്ട്; നോർമലൈസേഷൻ എങ്ങനെയാണ് നടക്കുന്നത് എന്ന് കാണാൻ നമുക്ക് ഇത് ഉപയോഗിക്കാം:

```py
print(tokenizer.backend_tokenizer.normalizer.normalize_str("Héllò hôw are ü?"))
```

```python out
'hello how are u?'
```

ഈ ഉദാഹരണത്തിൽ, നമ്മൾ `bert-base-uncased` ചെക്ക്‌പോയിന്റ് തിരഞ്ഞെടുത്തതിനാൽ, നോർമലൈസേഷൻ അക്ഷരങ്ങളെ ചെറിയക്ഷരങ്ങളാക്കുകയും ആക്‌സന്റുകൾ നീക്കം ചെയ്യുകയും ചെയ്തു.

> [!TIP]
> ✏️ **സ്വയം പരീക്ഷിക്കുക!** `bert-base-cased` ചെക്ക്‌പോയിന്റിൽ നിന്ന് ഒരു ടോക്കണൈസർ ലോഡ് ചെയ്ത്, അതേ ഉദാഹരണം അതിന് നൽകുക. ടോക്കണൈസറിന്റെ cased, uncased പതിപ്പുകൾക്കിടയിൽ നിങ്ങൾക്ക് കാണാൻ കഴിയുന്ന പ്രധാന വ്യത്യാസങ്ങൾ എന്തൊക്കെയാണ്?

## പ്രീ-ടോക്കണൈസേഷൻ[[pre-tokenization]]

<Youtube id="grlLV8AIXug"/>

അടുത്ത ഭാഗങ്ങളിൽ നമ്മൾ കാണാൻ പോകുന്നതുപോലെ, ഒരു ടോക്കണൈസറിനെ റോ ടെക്‌സ്‌റ്റിൽ (raw text) മാത്രം ട്രെയിൻ ചെയ്യാൻ കഴിയില്ല. പകരം, ടെക്‌സ്‌റ്റുകളെ വാക്കുകൾ പോലുള്ള ചെറിയ ഘടകങ്ങളായി നമ്മൾ ആദ്യം വിഭജിക്കേണ്ടതുണ്ട്. അവിടെയാണ് പ്രീ-ടോക്കണൈസേഷൻ ഘട്ടം കടന്നുവരുന്നത്. [അധ്യായം 2](/course/chapter2)-ൽ നമ്മൾ കണ്ടതുപോലെ, ഒരു വേഡ്-ബേസ്ഡ് ടോക്കണൈസറിന് (word-based tokenizer) റോ ടെക്‌സ്‌റ്റിനെ വൈറ്റ്‌സ്‌പേസും ചിഹ്നങ്ങളും (punctuation) അടിസ്ഥാനമാക്കി ലളിതമായി വാക്കുകളായി വിഭജിക്കാൻ കഴിയും. ട്രെയിനിംഗ് സമയത്ത് ടോക്കണൈസറിന് പഠിക്കാൻ കഴിയുന്ന സബ്‌ടോക്കണുകളുടെ അതിരുകളായിരിക്കും ആ വാക്കുകൾ.

ഒരു ഫാസ്‌റ്റ് ടോക്കണൈസർ പ്രീ-ടോക്കണൈസേഷൻ എങ്ങനെ നടത്തുന്നു എന്ന് കാണാൻ, `tokenizer` ഒബ്‌ജക്റ്റിന്റെ `pre_tokenizer` ആട്രിബ്യൂട്ടിന്റെ `pre_tokenize_str()` മെത്തേഡ് നമുക്ക് ഉപയോഗിക്കാം:

```py
tokenizer.backend_tokenizer.pre_tokenizer.pre_tokenize_str("Hello, how are  you?")
```

```python out
[('Hello', (0, 5)), (',', (5, 6)), ('how', (7, 10)), ('are', (11, 14)), ('you', (16, 19)), ('?', (19, 20))]
```

ടോക്കണൈസർ ഇപ്പോൾത്തന്നെ ഓഫ്‌സെറ്റുകൾ (offsets) ട്രാക്ക് ചെയ്യുന്നത് ശ്രദ്ധിക്കുക; മുൻ ഭാഗത്തിൽ നമ്മൾ ഉപയോഗിച്ച ഓഫ്‌സെറ്റ് മാപ്പിംഗ് നമുക്ക് നൽകാൻ അതിന് കഴിയുന്നത് ഇങ്ങനെയാണ്. ഇവിടെ ടോക്കണൈസർ രണ്ട് സ്‌പേസുകളെ അവഗണിച്ച് അവയെ ഒരെണ്ണം കൊണ്ട് മാറ്റുന്നു, എന്നാൽ അത് കണക്കിലെടുക്കാൻ `are`-നും `you`-വിനും ഇടയിൽ ഓഫ്‌സെറ്റ് ചാടുന്നു.

നമ്മൾ ഒരു BERT ടോക്കണൈസർ ഉപയോഗിക്കുന്നതിനാൽ, വൈറ്റ്‌സ്‌പേസും ചിഹ്നങ്ങളും അടിസ്ഥാനമാക്കി വിഭജിക്കുന്നതാണ് പ്രീ-ടോക്കണൈസേഷനിൽ ഉൾപ്പെടുന്നത്. മറ്റ് ടോക്കണൈസറുകൾക്ക് ഈ ഘട്ടത്തിന് വ്യത്യസ്ത നിയമങ്ങളുണ്ടാകാം. ഉദാഹരണത്തിന്, GPT-2 ടോക്കണൈസർ ഉപയോഗിച്ചാൽ:

```py
tokenizer = AutoTokenizer.from_pretrained("gpt2")
tokenizer.backend_tokenizer.pre_tokenizer.pre_tokenize_str("Hello, how are  you?")
```

അതും വൈറ്റ്‌സ്‌പേസും ചിഹ്നങ്ങളും അടിസ്ഥാനമാക്കി വിഭജിക്കും, എന്നാൽ അത് സ്‌പേസുകളെ നിലനിർത്തി അവയെ ഒരു `Ġ` ചിഹ്നം കൊണ്ട് മാറ്റും; ടോക്കണുകൾ ഡീകോഡ് ചെയ്യുമ്പോൾ യഥാർത്ഥ സ്‌പേസുകൾ വീണ്ടെടുക്കാൻ ഇത് അതിനെ പ്രാപ്‌തമാക്കുന്നു:

```python out
[('Hello', (0, 5)), (',', (5, 6)), ('Ġhow', (6, 10)), ('Ġare', (10, 14)), ('Ġ', (14, 15)), ('Ġyou', (15, 19)),
 ('?', (19, 20))]
```

BERT ടോക്കണൈസറിൽ നിന്ന് വ്യത്യസ്തമായി, ഈ ടോക്കണൈസർ ഇരട്ട സ്‌പേസിനെ അവഗണിക്കുന്നില്ല എന്നതും ശ്രദ്ധിക്കുക.

അവസാന ഉദാഹരണമായി, SentencePiece അൽഗോരിതം അടിസ്ഥാനമാക്കിയുള്ള T5 ടോക്കണൈസർ നമുക്ക് ഒന്ന് നോക്കാം:

```py
tokenizer = AutoTokenizer.from_pretrained("t5-small")
tokenizer.backend_tokenizer.pre_tokenizer.pre_tokenize_str("Hello, how are  you?")
```

```python out
[('▁Hello,', (0, 6)), ('▁how', (7, 10)), ('▁are', (11, 14)), ('▁you?', (16, 20))]
```

GPT-2 ടോക്കണൈസർ പോലെ, ഇതും സ്‌പേസുകളെ നിലനിർത്തി അവയെ ഒരു പ്രത്യേക ടോക്കൺ (`_`) കൊണ്ട് മാറ്റുന്നു, എന്നാൽ T5 ടോക്കണൈസർ വൈറ്റ്‌സ്‌പേസ് അടിസ്ഥാനമാക്കി മാത്രമേ വിഭജിക്കുന്നുള്ളൂ, ചിഹ്നങ്ങൾ അടിസ്ഥാനമാക്കിയല്ല. വാക്യത്തിന്റെ തുടക്കത്തിൽ (`Hello`-യുടെ മുമ്പ്) അത് ഡിഫോൾട്ടായി ഒരു സ്‌പേസ് ചേർത്തു എന്നതും `are`-നും `you`-വിനും ഇടയിലുള്ള ഇരട്ട സ്‌പേസിനെ അവഗണിച്ചു എന്നതും ശ്രദ്ധിക്കുക.

വ്യത്യസ്ത ടോക്കണൈസറുകൾ ടെക്‌സ്‌റ്റ് എങ്ങനെ പ്രോസസ്സ് ചെയ്യുന്നു എന്ന് കുറച്ചൊക്കെ കണ്ടുകഴിഞ്ഞ സ്ഥിതിക്ക്, അടിസ്ഥാന അൽഗോരിതങ്ങളെത്തന്നെ പരിശോധിക്കാൻ നമുക്ക് തുടങ്ങാം. വ്യാപകമായി ഉപയോഗിക്കാവുന്ന SentencePiece-നെ വേഗത്തിൽ ഒന്ന് നോക്കിക്കൊണ്ടാണ് നമ്മൾ ആരംഭിക്കുന്നത്; പിന്നീട്, അടുത്ത മൂന്ന് ഭാഗങ്ങളിലായി, സബ്‌വേഡ് ടോക്കണൈസേഷന് ഉപയോഗിക്കുന്ന മൂന്ന് പ്രധാന അൽഗോരിതങ്ങൾ എങ്ങനെ പ്രവർത്തിക്കുന്നു എന്ന് നമ്മൾ പരിശോധിക്കും.

## SentencePiece[[sentencepiece]]

[SentencePiece](https://github.com/google/sentencepiece) എന്നത് ടെക്‌സ്‌റ്റിന്റെ പ്രീപ്രോസസ്സിംഗിനുള്ള ഒരു ടോക്കണൈസേഷൻ അൽഗോരിതമാണ്; അടുത്ത മൂന്ന് ഭാഗങ്ങളിൽ നമ്മൾ കാണാൻ പോകുന്ന ഏത് മോഡലിനോടൊപ്പവും നിങ്ങൾക്ക് ഇത് ഉപയോഗിക്കാം. ഇത് ടെക്‌സ്‌റ്റിനെ Unicode അക്ഷരങ്ങളുടെ (characters) ഒരു ശ്രേണിയായി പരിഗണിക്കുകയും, സ്‌പേസുകളെ `▁` എന്ന ഒരു പ്രത്യേക അക്ഷരം കൊണ്ട് മാറ്റുകയും ചെയ്യുന്നു. Unigram അൽഗോരിതത്തോടൊപ്പം ഉപയോഗിക്കുമ്പോൾ ([ഭാഗം 7](/course/chapter6/7) കാണുക), ഇതിന് ഒരു പ്രീ-ടോക്കണൈസേഷൻ ഘട്ടം പോലും ആവശ്യമില്ല; സ്‌പേസ് അക്ഷരം ഉപയോഗിക്കാത്ത ഭാഷകൾക്ക് (ചൈനീസ് അല്ലെങ്കിൽ ജാപ്പനീസ് പോലുള്ളവ) ഇത് വളരെ ഉപകാരപ്രദമാണ്.

SentencePiece-ന്റെ മറ്റൊരു പ്രധാന സവിശേഷത *റിവേഴ്‌സിബിൾ ടോക്കണൈസേഷൻ* (reversible tokenization) ആണ്: സ്‌പേസുകൾക്ക് പ്രത്യേക പരിഗണനയൊന്നും ഇല്ലാത്തതിനാൽ, ടോക്കണുകളെ കൂട്ടിച്ചേർത്ത് `_`-കളെ സ്‌പേസുകൾ കൊണ്ട് മാറ്റുന്നതിലൂടെ മാത്രം ടോക്കണുകളുടെ ഡീകോഡിംഗ് നടക്കുന്നു -- ഇത് നോർമലൈസ് ചെയ്ത ടെക്‌സ്‌റ്റിലേക്ക് നയിക്കുന്നു. നമ്മൾ മുമ്പ് കണ്ടതുപോലെ, BERT ടോക്കണൈസർ ആവർത്തിക്കുന്ന സ്‌പേസുകളെ നീക്കം ചെയ്യുന്നു, അതിനാൽ അതിന്റെ ടോക്കണൈസേഷൻ റിവേഴ്‌സിബിൾ അല്ല.

## അൽഗോരിതങ്ങളുടെ അവലോകനം[[algorithm-overview]]

തുടർന്നുള്ള ഭാഗങ്ങളിൽ, മൂന്ന് പ്രധാന സബ്‌വേഡ് ടോക്കണൈസേഷൻ അൽഗോരിതങ്ങളിലേക്ക് നമ്മൾ ആഴത്തിൽ കടക്കും: BPE (GPT-2-ഉം മറ്റുള്ളവയും ഉപയോഗിക്കുന്നത്), WordPiece (ഉദാഹരണത്തിന് BERT ഉപയോഗിക്കുന്നത്), Unigram (T5-ഉം മറ്റുള്ളവയും ഉപയോഗിക്കുന്നത്). തുടങ്ങുന്നതിന് മുമ്പ്, ഇവ ഓരോന്നും എങ്ങനെ പ്രവർത്തിക്കുന്നു എന്നതിന്റെ ഒരു ഹ്രസ്വ അവലോകനം ഇതാ. ഇത് നിങ്ങൾക്ക് ഇപ്പോൾ മനസ്സിലാകുന്നില്ലെങ്കിൽ, അടുത്ത ഓരോ ഭാഗവും വായിച്ചതിന് ശേഷം ഈ ടേബിളിലേക്ക് തിരിച്ചുവരാൻ മടിക്കേണ്ട.
