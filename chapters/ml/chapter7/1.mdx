[അധ്യായം 3](/course/chapter3)-ൽ, ടെക്‌സ്‌റ്റ് ക്ലാസിഫിക്കേഷനായി ഒരു മോഡൽ എങ്ങനെ ഫൈൻ-ട്യൂൻ ചെയ്യാമെന്ന് നിങ്ങൾ കണ്ടു. ഈ അധ്യായത്തിൽ, പരമ്പരാഗത NLP മോഡലുകളുമായും ആധുനിക LLM-കളുമായും പ്രവർത്തിക്കാൻ അത്യാവശ്യമായ, താഴെ പറയുന്ന സാധാരണ ഭാഷാ ടാസ്‌ക്കുകൾ നമ്മൾ കൈകാര്യം ചെയ്യും:

- ടോക്കൺ ക്ലാസിഫിക്കേഷൻ (Token classification)
- മാസ്‌ക്ഡ് ലാംഗ്വേജ് മോഡലിംഗ് (BERT പോലെ)
- സമ്മറൈസേഷൻ (Summarization)
- വിവർത്തനം (Translation)
- കോസൽ ലാംഗ്വേജ് മോഡലിംഗ് പ്രീട്രെയിനിംഗ് (GPT-2 പോലെ)
- ചോദ്യോത്തരം (Question answering)

ലാർജ് ലാംഗ്വേജ് മോഡലുകൾ (LLM-കൾ) എങ്ങനെ പ്രവർത്തിക്കുന്നു എന്നതിന്റെ അടിത്തറയാണ് ഈ അടിസ്ഥാന ടാസ്‌ക്കുകൾ; ഇന്നത്തെ ഏറ്റവും നൂതനമായ ലാംഗ്വേജ് മോഡലുകളുമായി ഫലപ്രദമായി പ്രവർത്തിക്കാൻ ഇവ മനസ്സിലാക്കുന്നത് നിർണ്ണായകമാണ്.

ഇതിനായി, [അധ്യായം 3](/course/chapter3)-ൽ `Trainer` API-യെയും 🤗 Accelerate ലൈബ്രറിയെയും കുറിച്ചും, [അധ്യായം 5](/course/chapter5)-ൽ 🤗 Datasets ലൈബ്രറിയെക്കുറിച്ചും, [അധ്യായം 6](/course/chapter6)-ൽ 🤗 Tokenizers ലൈബ്രറിയെക്കുറിച്ചും നിങ്ങൾ പഠിച്ചതെല്ലാം പ്രയോജനപ്പെടുത്തേണ്ടതുണ്ട്. [അധ്യായം 4](/course/chapter4)-ൽ ചെയ്തതുപോലെ, നമ്മുടെ ഫലങ്ങൾ Model Hub-ലേക്ക് അപ്‌ലോഡ് ചെയ്യുകയും ചെയ്യും; അതിനാൽ എല്ലാം ഒരുമിച്ചു ചേരുന്ന അധ്യായമാണ് യഥാർത്ഥത്തിൽ ഇത്!

ഓരോ ഭാഗവും സ്വതന്ത്രമായി വായിക്കാവുന്നതാണ്; `Trainer` API ഉപയോഗിച്ചോ, 🤗 Accelerate ഉപയോഗിച്ചുള്ള നിങ്ങളുടെ സ്വന്തം ട്രെയിനിംഗ് ലൂപ്പ് ഉപയോഗിച്ചോ ഒരു മോഡൽ എങ്ങനെ ട്രെയിൻ ചെയ്യാമെന്ന് അവ നിങ്ങൾക്ക് കാണിച്ചുതരും. ഇവയിൽ ഏതെങ്കിലും ഒരു ഭാഗം ഒഴിവാക്കി, നിങ്ങൾക്ക് ഏറ്റവും താൽപ്പര്യമുള്ളതിൽ ശ്രദ്ധ കേന്ദ്രീകരിക്കാൻ മടിക്കേണ്ട: തിരശ്ശീലയ്ക്ക് പിന്നിൽ എന്താണ് നടക്കുന്നത് എന്ന് ആശങ്കപ്പെടാതെ നിങ്ങളുടെ മോഡൽ ഫൈൻ-ട്യൂൻ ചെയ്യാനോ ട്രെയിൻ ചെയ്യാനോ `Trainer` API വളരെ മികച്ചതാണ്; അതേസമയം `Accelerate` ഉപയോഗിച്ചുള്ള ട്രെയിനിംഗ് ലൂപ്പ്, നിങ്ങൾക്ക് ആവശ്യമുള്ള ഏത് ഭാഗവും കൂടുതൽ എളുപ്പത്തിൽ ഇഷ്ടാനുസൃതമാക്കാൻ അനുവദിക്കും.

> ഈ ഭാഗങ്ങൾ ക്രമത്തിൽ വായിക്കുകയാണെങ്കിൽ, അവയിൽ കോഡും വിവരണവും ഒരുപാട് പൊതുവായി ഉണ്ടെന്ന് നിങ്ങൾ ശ്രദ്ധിക്കും. ഈ ആവർത്തനം മനഃപൂർവ്വമാണ് — നിങ്ങൾക്ക് താൽപ്പര്യമുള്ള ഏത് ടാസ്‌ക്കിലേക്കും നേരിട്ട് കടന്നുചെന്ന് (അല്ലെങ്കിൽ പിന്നീട് തിരികെ വന്ന്) പൂർണ്ണമായി പ്രവർത്തിക്കുന്ന ഒരു ഉദാഹരണം കണ്ടെത്താൻ നിങ്ങളെ അനുവദിക്കാനാണ് ഇത്.
