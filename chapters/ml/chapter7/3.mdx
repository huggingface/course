Transformer മോഡലുകൾ ഉൾപ്പെടുന്ന പല NLP ആപ്ലിക്കേഷനുകൾക്കും, Hugging Face Hub-ൽ നിന്ന് ഒരു പ്രീട്രെയിൻഡ് മോഡൽ എടുത്ത്, നിങ്ങളുടെ ടാസ്‌ക്കിനായി നിങ്ങളുടെ ഡേറ്റയിൽ അത് നേരിട്ട് ഫൈൻ-ട്യൂൻ ചെയ്താൽ മതി. പ്രീട്രെയിനിംഗിന് ഉപയോഗിച്ച കോർപ്പസ് (corpus) ഫൈൻ-ട്യൂണിംഗിന് ഉപയോഗിക്കുന്ന കോർപ്പസിൽ നിന്ന് വളരെ വ്യത്യസ്തമല്ലെങ്കിൽ, ട്രാൻസ്ഫർ ലേണിംഗ് (transfer learning) സാധാരണയായി നല്ല ഫലങ്ങൾ നൽകും.

എന്നാൽ, ടാസ്‌ക്-നിർദ്ദിഷ്ടമായ ഒരു ഹെഡ് (task-specific head) ട്രെയിൻ ചെയ്യുന്നതിന് മുമ്പ്, ലാംഗ്വേജ് മോഡലുകളെ ആദ്യം നിങ്ങളുടെ ഡേറ്റയിൽ ഫൈൻ-ട്യൂൻ ചെയ്യേണ്ടി വരുന്ന ചില സാഹചര്യങ്ങളുണ്ട്. ഉദാഹരണത്തിന്, നിങ്ങളുടെ ഡേറ്റാസെറ്റിൽ നിയമപരമായ കരാറുകളോ ശാസ്ത്രലേഖനങ്ങളോ ആണുള്ളതെങ്കിൽ, BERT പോലുള്ള ഒരു സാധാരണ Transformer മോഡൽ നിങ്ങളുടെ കോർപ്പസിലെ ഡൊമെയ്ൻ-നിർദ്ദിഷ്ട വാക്കുകളെ സാധാരണയായി അപൂർവ ടോക്കണുകളായി (rare tokens) പരിഗണിക്കും, അതിന്റെ ഫലമായി ലഭിക്കുന്ന പ്രകടനം അത്ര തൃപ്തികരമായിരിക്കില്ല. ഇൻ-ഡൊമെയ്ൻ ഡേറ്റയിൽ ലാംഗ്വേജ് മോഡൽ ഫൈൻ-ട്യൂൻ ചെയ്യുന്നതിലൂടെ പല ഡൗൺസ്ട്രീം ടാസ്‌ക്കുകളുടെയും പ്രകടനം നിങ്ങൾക്ക് മെച്ചപ്പെടുത്താം; അതായത്, ഈ ഘട്ടം സാധാരണയായി ഒരിക്കൽ മാത്രം ചെയ്താൽ മതി!

ഒരു പ്രീട്രെയിൻഡ് ലാംഗ്വേജ് മോഡൽ ഇൻ-ഡൊമെയ്ൻ ഡേറ്റയിൽ ഫൈൻ-ട്യൂൻ ചെയ്യുന്ന ഈ പ്രക്രിയയെ സാധാരണയായി _ഡൊമെയ്ൻ അഡാപ്‌റ്റേഷൻ_ (domain adaptation) എന്ന് വിളിക്കുന്നു. NLP-യിൽ ട്രാൻസ്ഫർ ലേണിംഗ് യഥാർത്ഥത്തിൽ പ്രവർത്തിക്കുന്നതാക്കിയ ആദ്യകാല ന്യൂറൽ ആർക്കിടെക്ചറുകളിൽ ഒന്നായ (LSTM-കളെ അടിസ്ഥാനമാക്കിയുള്ള) [ULMFiT](https://arxiv.org/abs/1801.06146) ആണ് 2018-ൽ ഇത് ജനപ്രിയമാക്കിയത്. ULMFiT ഉപയോഗിച്ചുള്ള ഡൊമെയ്ൻ അഡാപ്‌റ്റേഷന്റെ ഒരു ഉദാഹരണം താഴെയുള്ള ചിത്രത്തിൽ കാണിച്ചിരിക്കുന്നു; ഈ ഭാഗത്തിൽ നമ്മൾ സമാനമായ ഒന്ന് ചെയ്യും, എന്നാൽ LSTM-ന് പകരം ഒരു Transformer ഉപയോഗിച്ച്!

## മാസ്‌ക്‌ഡ് ലാംഗ്വേജ് മോഡലിംഗിനായി ഒരു പ്രീട്രെയിൻഡ് മോഡൽ തിരഞ്ഞെടുക്കുന്നു[[picking-a-pretrained-model-for-masked-language-modeling]]

തുടങ്ങാനായി, മാസ്‌ക്‌ഡ് ലാംഗ്വേജ് മോഡലിംഗിന് അനുയോജ്യമായ ഒരു പ്രീട്രെയിൻഡ് മോഡൽ തിരഞ്ഞെടുക്കാം. താഴെയുള്ള സ്‌ക്രീൻഷോട്ടിൽ കാണിച്ചിരിക്കുന്നതുപോലെ, [Hugging Face Hub](https://huggingface.co/models?pipeline_tag=fill-mask&sort=downloads)-ൽ "Fill-Mask" ഫിൽറ്റർ പ്രയോഗിച്ചാൽ സാധ്യതയുള്ള മോഡലുകളുടെ ഒരു ലിസ്‌റ്റ് നിങ്ങൾക്ക് കാണാം:

<div class="flex justify-center">
<img src="https://huggingface.co/datasets/huggingface-course/documentation-images/resolve/main/en/chapter7/mlm-models.png" alt="Hub മോഡലുകൾ." width="80%"/>
</div>

BERT, RoBERTa കുടുംബത്തിലെ മോഡലുകളാണ് ഏറ്റവുമധികം ഡൗൺലോഡ് ചെയ്യപ്പെടുന്നവയെങ്കിലും, [DistilBERT](https://huggingface.co/distilbert-base-uncased) എന്ന ഒരു മോഡലാണ് നമ്മൾ ഉപയോഗിക്കുക —
ഡൗൺസ്ട്രീം പ്രകടനത്തിൽ കാര്യമായ നഷ്ടമൊന്നുമില്ലാതെ, വളരെ വേഗത്തിൽ ട്രെയിൻ ചെയ്യാൻ കഴിയുന്ന ഒരു മോഡലാണിത്. [_നോളജ് ഡിസ്‌റ്റിലേഷൻ_](https://en.wikipedia.org/wiki/Knowledge_distillation) (knowledge distillation) എന്ന ഒരു പ്രത്യേക ടെക്‌നിക് ഉപയോഗിച്ചാണ് ഈ മോഡൽ ട്രെയിൻ ചെയ്തത്; ഇതിൽ BERT പോലുള്ള ഒരു വലിയ "ടീച്ചർ മോഡൽ" (teacher model), വളരെ കുറച്ച് പാരാമീറ്ററുകൾ മാത്രമുള്ള ഒരു "സ്‌റ്റുഡന്റ് മോഡലിന്റെ" (student model) ട്രെയിനിംഗിനെ നയിക്കാൻ ഉപയോഗിക്കുന്നു. നോളജ് ഡിസ്‌റ്റിലേഷന്റെ വിശദാംശങ്ങൾ വിവരിക്കുന്നത് ഈ ഭാഗത്തിന്റെ പരിധിക്ക് പുറത്താണ്, എന്നാൽ താൽപ്പര്യമുണ്ടെങ്കിൽ [_Natural Language Processing with Transformers_](https://www.oreilly.com/library/view/natural-language-processing/9781098136789/) (Transformers ടെക്‌സ്‌റ്റ്ബുക്ക് എന്ന് സാധാരണയായി അറിയപ്പെടുന്ന പുസ്തകം) എന്ന പുസ്തകത്തിൽ അതേക്കുറിച്ച് എല്ലാം നിങ്ങൾക്ക് വായിക്കാം.

{#if fw === 'pt'}

`AutoModelForMaskedLM` ക്ലാസ് ഉപയോഗിച്ച് DistilBERT ഡൗൺലോഡ് ചെയ്യാം:

```python
from transformers import AutoModelForMaskedLM

model_checkpoint = "distilbert-base-uncased"
model = AutoModelForMaskedLM.from_pretrained(model_checkpoint)
```

`num_parameters()` മെത്തേഡ് വിളിച്ചുകൊണ്ട് ഈ മോഡലിന് എത്ര പാരാമീറ്ററുകൾ ഉണ്ടെന്ന് നമുക്ക് കാണാം:

```python
distilbert_num_parameters = model.num_parameters() / 1_000_000
print(f"'>>> DistilBERT number of parameters: {round(distilbert_num_parameters)}M'")
print(f"'>>> BERT number of parameters: 110M'")
```

```python out
'>>> DistilBERT number of parameters: 67M'
'>>> BERT number of parameters: 110M'
```

{:else}

```python
from transformers import TFAutoModelForMaskedLM
```

ഏകദേശം 67 ദശലക്ഷം പാരാമീറ്ററുകളുള്ള DistilBERT, BERT ബേസ് മോഡലിനെക്കാൾ ഏകദേശം രണ്ട് മടങ്ങ് ചെറുതാണ്; അതായത് ട്രെയിനിംഗിൽ ഏതാണ്ട് ഇരട്ടി വേഗത -- കൊള്ളാം! ഒരു ചെറിയ സാമ്പിൾ ടെക്‌സ്‌റ്റിന്റെ ഏറ്റവും സാധ്യതയുള്ള പൂരണങ്ങളായി (completions) ഈ മോഡൽ ഏതുതരം ടോക്കണുകളാണ് പ്രവചിക്കുന്നത് എന്ന് ഇപ്പോൾ നോക്കാം:

```python
text = "This is a great [MASK]."
```

മനുഷ്യരായ നമുക്ക് `[MASK]` ടോക്കണിന് "day", "ride", "painting" എന്നിങ്ങനെ പല സാധ്യതകളും സങ്കൽപ്പിക്കാൻ കഴിയും. പ്രീട്രെയിൻഡ് മോഡലുകളുടെ കാര്യത്തിൽ, പ്രവചനങ്ങൾ മോഡൽ ട്രെയിൻ ചെയ്ത കോർപ്പസിനെ ആശ്രയിച്ചിരിക്കും, കാരണം ഡേറ്റയിലുള്ള സ്ഥിതിവിവര പാറ്റേണുകൾ (statistical patterns) തിരിച്ചറിയാനാണ് അത് പഠിക്കുന്നത്. BERT പോലെ, DistilBERT-ഉം [English Wikipedia](https://huggingface.co/datasets/wikipedia), [BookCorpus](https://huggingface.co/datasets/bookcorpus) ഡേറ്റാസെറ്റുകളിലാണ് പ്രീട്രെയിൻ ചെയ്തത്, അതിനാൽ `[MASK]`-നുള്ള പ്രവചനങ്ങൾ ഈ ഡൊമെയ്‌നുകളെ പ്രതിഫലിപ്പിക്കുമെന്ന് നമ്മൾ പ്രതീക്ഷിക്കുന്നു. മാസ്‌ക് പ്രവചിക്കാൻ, മോഡലിനുള്ള ഇൻപുട്ടുകൾ നിർമ്മിക്കാൻ DistilBERT-ന്റെ ടോക്കണൈസർ നമുക്ക് ആവശ്യമാണ്, അതിനാൽ അതും Hub-ൽ നിന്ന് ഡൗൺലോഡ് ചെയ്യാം:

```python
from transformers import AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained(model_checkpoint)
```

## ഡേറ്റ പ്രീപ്രോസസ്സ് ചെയ്യുന്നു[[preprocessing-the-data]]

<Youtube id="8PmhEIXhBvI"/>

ഓട്ടോ-റിഗ്രസ്സീവ് (auto-regressive) ലാംഗ്വേജ് മോഡലിംഗിനും മാസ്‌ക്‌ഡ് ലാംഗ്വേജ് മോഡലിംഗിനും പൊതുവായുള്ള ഒരു പ്രീപ്രോസസ്സിംഗ് ഘട്ടം, എല്ലാ ഉദാഹരണങ്ങളും കൂട്ടിച്ചേർത്ത (concatenate) ശേഷം മുഴുവൻ കോർപ്പസും തുല്യ വലുപ്പമുള്ള ചങ്കുകളായി (chunks) വിഭജിക്കുകയാണ്. ഓരോ ഉദാഹരണവും വെറുതെ ടോക്കണൈസ് ചെയ്യുന്ന നമ്മുടെ സാധാരണ രീതിയിൽ നിന്ന് ഇത് തികച്ചും വ്യത്യസ്തമാണ്. എന്തിനാണ് എല്ലാം ഒരുമിച്ച് കൂട്ടിച്ചേർക്കുന്നത്? ഓരോ ഉദാഹരണവും വളരെ നീണ്ടതാണെങ്കിൽ അവ ട്രങ്കേറ്റ് (truncate) ചെയ്യപ്പെട്ടേക്കാം, അത് ലാംഗ്വേജ് മോഡലിംഗ് ടാസ്‌ക്കിന് ഉപകാരപ്രദമായേക്കാവുന്ന വിവരങ്ങൾ നഷ്ടപ്പെടുന്നതിന് കാരണമാകും എന്നതാണ് കാരണം!

അതിനാൽ തുടങ്ങാനായി, നമ്മുടെ കോർപ്പസ് പതിവുപോലെ ആദ്യം ടോക്കണൈസ് ചെയ്യും, എന്നാൽ ടോക്കണൈസറിൽ `truncation=True` ഓപ്‌ഷൻ _സെറ്റ് ചെയ്യാതെ_. വേഡ് ID-കൾ ലഭ്യമാണെങ്കിൽ അവയും നമ്മൾ എടുക്കും ([അധ്യായം 6](/course/chapter6/3)-ൽ വിവരിച്ചതുപോലെ, ഒരു ഫാസ്‌റ്റ് ടോക്കണൈസർ ഉപയോഗിക്കുകയാണെങ്കിൽ അവ ലഭ്യമായിരിക്കും), കാരണം ഹോൾ വേഡ് മാസ്‌കിംഗ് (whole word masking) ചെയ്യാൻ പിന്നീട് അവ നമുക്ക് ആവശ്യമായി വരും. ഇത് ഒരു ലളിതമായ ഫംഗ്‌ഷനിൽ നമ്മൾ പൊതിയും, അതോടൊപ്പം ഇനി ആവശ്യമില്ലാത്തതിനാൽ `text`, `label` കോളങ്ങളും നീക്കം ചെയ്യും:

```python
def tokenize_function(examples):
    result = tokenizer(examples["text"])
    if tokenizer.is_fast:
        result["word_ids"] = [result.word_ids(i) for i in range(len(result["input_ids"]))]
    return result


# Use batched=True to activate fast multithreading!
tokenized_datasets = imdb_dataset.map(
    tokenize_function, batched=True, remove_columns=["text", "label"]
)
tokenized_datasets
```

ഒരു ചെക്ക്‌പോയിന്റുമായി ബന്ധപ്പെട്ട *tokenizer_config.json* ഫയലിൽ നിന്നാണ് ഈ മൂല്യം ലഭിക്കുന്നത്; ഈ സാഹചര്യത്തിൽ, BERT-ലേതുപോലെ തന്നെ, കോൺടെക്‌സ്‌റ്റ് സൈസ് 512 ടോക്കണുകളാണെന്ന് നമുക്ക് കാണാം.

ഈ ഉദാഹരണത്തിൽ കാണാവുന്നതുപോലെ, അവസാന ചങ്ക് സാധാരണയായി പരമാവധി ചങ്ക് സൈസിനെക്കാൾ ചെറുതായിരിക്കും. ഇത് കൈകാര്യം ചെയ്യാൻ രണ്ട് പ്രധാന തന്ത്രങ്ങളുണ്ട്:

* അവസാന ചങ്ക് `chunk_size`-നെക്കാൾ ചെറുതാണെങ്കിൽ അത് ഒഴിവാക്കുക.
* അവസാന ചങ്കിന്റെ ദൈർഘ്യം `chunk_size`-ന് തുല്യമാകുന്നതുവരെ അതിൽ പാഡിംഗ് ചേർക്കുക.

ഇവിടെ നമ്മൾ ആദ്യത്തെ രീതി സ്വീകരിക്കും; അതിനാൽ മുകളിലുള്ള ലോജിക് മുഴുവൻ, ടോക്കണൈസ് ചെയ്ത നമ്മുടെ ഡേറ്റാസെറ്റുകളിൽ പ്രയോഗിക്കാവുന്ന ഒരൊറ്റ ഫംഗ്‌ഷനിൽ പൊതിയാം:

```python
def group_texts(examples):
    # Concatenate all texts
    concatenated_examples = {k: sum(examples[k], []) for k in examples.keys()}
    # Compute length of concatenated texts
    total_length = len(concatenated_examples[list(examples.keys())[0]])
    # We drop the last chunk if it's smaller than chunk_size
    total_length = (total_length // chunk_size) * chunk_size
    # Split by chunks of max_len
    result = {
        k: [t[i : i + chunk_size] for i in range(0, total_length, chunk_size)]
        for k, t in concatenated_examples.items()
    }
    # Create a new labels column
    result["labels"] = result["input_ids"].copy()
    return result
```

`group_texts()`-ന്റെ അവസാന ഘട്ടത്തിൽ, `input_ids` കോളത്തിന്റെ ഒരു പകർപ്പായ `labels` എന്ന പുതിയ കോളം നമ്മൾ ഉണ്ടാക്കുന്നു എന്നത് ശ്രദ്ധിക്കുക. ഉടൻ കാണാൻ പോകുന്നതുപോലെ, മാസ്‌ക്‌ഡ് ലാംഗ്വേജ് മോഡലിംഗിൽ ഇൻപുട്ട് ബാച്ചിലെ ക്രമരഹിതമായി മാസ്‌ക് ചെയ്ത ടോക്കണുകൾ പ്രവചിക്കുകയാണ് ലക്ഷ്യം എന്നതാണ് ഇതിന് കാരണം; ഒരു `labels` കോളം ഉണ്ടാക്കുന്നതിലൂടെ, നമ്മുടെ ലാംഗ്വേജ് മോഡലിന് പഠിക്കാനുള്ള ഗ്രൗണ്ട് ട്രൂത്ത് (ground truth) നമ്മൾ നൽകുന്നു.

## `Trainer` API ഉപയോഗിച്ച് DistilBERT ഫൈൻ-ട്യൂൻ ചെയ്യുന്നു[[fine-tuning-distilbert-with-the-trainer-api]]

ഒരു മാസ്‌ക്‌ഡ് ലാംഗ്വേജ് മോഡൽ ഫൈൻ-ട്യൂൻ ചെയ്യുന്നത്, [അധ്യായം 3](/course/chapter3)-ൽ നമ്മൾ ചെയ്തതുപോലെ ഒരു സീക്വൻസ് ക്ലാസിഫിക്കേഷൻ മോഡൽ ഫൈൻ-ട്യൂൻ ചെയ്യുന്നതിന് ഏതാണ്ട് സമാനമാണ്. ഓരോ ടെക്‌സ്‌റ്റ് ബാച്ചിലെയും ചില ടോക്കണുകൾ ക്രമരഹിതമായി മാസ്‌ക് ചെയ്യാൻ കഴിയുന്ന ഒരു പ്രത്യേക ഡേറ്റാ കൊളേറ്റർ നമുക്ക് ആവശ്യമാണ് എന്നതാണ് ഒരേയൊരു വ്യത്യാസം. ഭാഗ്യവശാൽ, ഈ ടാസ്‌ക്കിനായി മാത്രമുള്ള ഒരു `DataCollatorForLanguageModeling` 🤗 Transformers-ൽ തയ്യാറായി ഉണ്ട്. ടോക്കണൈസറും, ടോക്കണുകളുടെ എത്ര ഭാഗം മാസ്‌ക് ചെയ്യണം എന്ന് വ്യക്തമാക്കുന്ന ഒരു `mlm_probability` ആർഗ്യുമെന്റും അതിന് നൽകിയാൽ മാത്രം മതി. BERT-ന് ഉപയോഗിച്ചതും ഗവേഷണ സാഹിത്യത്തിൽ സാധാരണമായ ഒരു തിരഞ്ഞെടുപ്പുമായ 15% നമ്മൾ തിരഞ്ഞെടുക്കും:

```python
from transformers import DataCollatorForLanguageModeling
```

```py
import collections
import numpy as np

from transformers import default_data_collator

wwm_probability = 0.2


def whole_word_masking_data_collator(features):
    for feature in features:
        word_ids = feature.pop("word_ids")

        # Create a map between words and corresponding token indices
        mapping = collections.defaultdict(list)
        current_word_index = -1
        current_word = None
        for idx, word_id in enumerate(word_ids):
            if word_id is not None:
                if word_id != current_word:
                    current_word = word_id
                    current_word_index += 1
                mapping[current_word_index].append(idx)

        # Randomly mask words
        mask = np.random.binomial(1, wwm_probability, (len(mapping),))
        input_ids = feature["input_ids"]
        labels = feature["labels"]
        new_labels = [-100] * len(labels)
        for word_id in np.where(mask)[0]:
            word_id = word_id.item()
            for idx in mapping[word_id]:
                new_labels[idx] = labels[idx]
                input_ids[idx] = tokenizer.mask_token_id
        feature["labels"] = new_labels

    return default_data_collator(features)
```

ലോഗിൻ ചെയ്തുകഴിഞ്ഞാൽ, നമ്മുടെ `tf.data` ഡേറ്റാസെറ്റുകൾ ഉണ്ടാക്കാം. അതിനായി, ഏതൊക്കെ കോളങ്ങൾ ഡേറ്റാസെറ്റിൽ ഉൾപ്പെടണം എന്ന് നമ്മുടെ മോഡൽ ഉപയോഗിച്ച് സ്വയമേവ അനുമാനിക്കുന്ന `prepare_tf_dataset()` മെത്തേഡ് നമ്മൾ ഉപയോഗിക്കും. ഏതൊക്കെ കോളങ്ങൾ ഉപയോഗിക്കണം എന്ന് കൃത്യമായി നിയന്ത്രിക്കണമെങ്കിൽ, പകരം `Dataset.to_tf_dataset()` മെത്തേഡ് നിങ്ങൾക്ക് ഉപയോഗിക്കാം. കാര്യങ്ങൾ ലളിതമാക്കാൻ, ഇവിടെ നമ്മൾ സാധാരണ ഡേറ്റാ കൊളേറ്റർ മാത്രം ഉപയോഗിക്കും, എന്നാൽ ഒരു അഭ്യാസമായി ഹോൾ വേഡ് മാസ്‌കിംഗ് കൊളേറ്ററും പരീക്ഷിച്ച് ഫലങ്ങൾ താരതമ്യം ചെയ്യാം:

```python
tf_train_dataset = model.prepare_tf_dataset(
    downsampled_dataset["train"],
    collate_fn=data_collator,
    shuffle=True,
    batch_size=32,
)

tf_eval_dataset = model.prepare_tf_dataset(
    downsampled_dataset["test"],
    collate_fn=data_collator,
    shuffle=False,
    batch_size=32,
)
```

അടുത്തതായി, നമ്മുടെ ട്രെയിനിംഗ് ഹൈപ്പർപാരാമീറ്ററുകൾ സെറ്റപ്പ് ചെയ്ത് മോഡൽ കംപൈൽ ചെയ്യുന്നു. ലീനിയർ ലേണിംഗ് റേറ്റ് ഡികേയോടെ (linear learning rate decay) ഒരു `AdamW` ഒപ്‌റ്റിമൈസർ നൽകുന്ന, 🤗 Transformers ലൈബ്രറിയിലെ `create_optimizer()` ഫംഗ്‌ഷൻ നമ്മൾ ഉപയോഗിക്കുന്നു. `compile()`-ന് ആർഗ്യുമെന്റായി ലോസ് ഒന്നും വ്യക്തമാക്കാത്തപ്പോൾ ഡിഫോൾട്ടായ, മോഡലിന്റെ ബിൽറ്റ്-ഇൻ ലോസും നമ്മൾ ഉപയോഗിക്കുന്നു, കൂടാതെ ട്രെയിനിംഗ് പ്രിസിഷൻ `"mixed_float16"` എന്ന് സെറ്റ് ചെയ്യുന്നു. ആക്‌സിലറേറ്റഡ് float16 പിന്തുണയില്ലാത്ത ഒരു Colab GPU-വോ മറ്റ് GPU-വോ ആണ് നിങ്ങൾ ഉപയോഗിക്കുന്നതെങ്കിൽ, ആ വരി കമന്റ് ഔട്ട് ചെയ്യുന്നതായിരിക്കും നല്ലത് എന്നത് ശ്രദ്ധിക്കുക.

കൂടാതെ, ഓരോ എപ്പോക്കിന് ശേഷവും മോഡൽ Hub-ലേക്ക് സേവ് ചെയ്യുന്ന ഒരു `PushToHubCallback` നമ്മൾ സെറ്റപ്പ് ചെയ്യുന്നു. നിങ്ങൾ പുഷ് ചെയ്യാൻ ആഗ്രഹിക്കുന്ന റിപ്പോസിറ്ററിയുടെ പേര് `hub_model_id` ആർഗ്യുമെന്റ് ഉപയോഗിച്ച് വ്യക്തമാക്കാം (പ്രത്യേകിച്ച്, ഒരു ഓർഗനൈസേഷനിലേക്ക് പുഷ് ചെയ്യാൻ ഈ ആർഗ്യുമെന്റ് നിങ്ങൾ ഉപയോഗിക്കേണ്ടി വരും). ഉദാഹരണത്തിന്, [`huggingface-course` ഓർഗനൈസേഷനിലേക്ക്](https://huggingface.co/huggingface-course) മോഡൽ പുഷ് ചെയ്യാൻ, ഞങ്ങൾ `hub_model_id="huggingface-course/distilbert-finetuned-imdb"` ചേർത്തു. ഡിഫോൾട്ടായി, ഉപയോഗിക്കുന്ന റിപ്പോസിറ്ററി നിങ്ങളുടെ നെയിംസ്‌പേസിലായിരിക്കും, നിങ്ങൾ സെറ്റ് ചെയ്ത ഔട്ട്‌പുട്ട് ഡയറക്ടറിയുടെ പേരിലായിരിക്കും അത്; അതിനാൽ നമ്മുടെ കാര്യത്തിൽ അത് `"lewtun/distilbert-finetuned-imdb"` ആയിരിക്കും.

```python
from transformers import create_optimizer
from transformers.keras_callbacks import PushToHubCallback
import tensorflow as tf

num_train_steps = len(tf_train_dataset)
optimizer, schedule = create_optimizer(
    init_lr=2e-5,
    num_warmup_steps=1_000,
    num_train_steps=num_train_steps,
    weight_decay_rate=0.01,
)
model.compile(optimizer=optimizer)

# Train in mixed-precision float16
tf.keras.mixed_precision.set_global_policy("mixed_float16")

model_name = model_checkpoint.split("/")[-1]
callback = PushToHubCallback(
    output_dir=f"{model_name}-finetuned-imdb", tokenizer=tokenizer
)
```

ഇപ്പോൾ `model.fit()` റൺ ചെയ്യാൻ നമ്മൾ തയ്യാറാണ് -- എന്നാൽ അതിന് മുമ്പ്, ലാംഗ്വേജ് മോഡലുകളുടെ പ്രകടനം ഇവാല്യുവേറ്റ് ചെയ്യാനുള്ള ഒരു സാധാരണ മെട്രിക്കായ _പെർപ്ലെക്‌സിറ്റി_ (perplexity) എന്താണെന്ന് ചുരുക്കത്തിൽ നോക്കാം.

{:else}

ലോഗിൻ ചെയ്തുകഴിഞ്ഞാൽ, `Trainer`-നുള്ള ആർഗ്യുമെന്റുകൾ നമുക്ക് വ്യക്തമാക്കാം:

```python
from transformers import TrainingArguments

batch_size = 64
# Show the training loss with every epoch
logging_steps = len(downsampled_dataset["train"]) // batch_size
model_name = model_checkpoint.split("/")[-1]

training_args = TrainingArguments(
    output_dir=f"{model_name}-finetuned-imdb",
    overwrite_output_dir=True,
    evaluation_strategy="epoch",
    learning_rate=2e-5,
    weight_decay=0.01,
    per_device_train_batch_size=batch_size,
    per_device_eval_batch_size=batch_size,
    push_to_hub=True,
    fp16=True,
    logging_steps=logging_steps,
)
```

ഓരോ എപ്പോക്കിലും ട്രെയിനിംഗ് ലോസ് ട്രാക്ക് ചെയ്യുന്നു എന്ന് ഉറപ്പാക്കാനുള്ള `logging_steps` ഉൾപ്പെടെ, ഡിഫോൾട്ട് ഓപ്‌ഷനുകളിൽ ചിലത് ഇവിടെ നമ്മൾ മാറ്റിയിട്ടുണ്ട്. മിക്‌സഡ്-പ്രിസിഷൻ ട്രെയിനിംഗ് പ്രവർത്തനക്ഷമമാക്കാൻ `fp16=True`-ഉം നമ്മൾ ഉപയോഗിച്ചിട്ടുണ്ട്; ഇത് വേഗതയിൽ മറ്റൊരു കുതിപ്പ് നൽകുന്നു. ഡിഫോൾട്ടായി, മോഡലിന്റെ `forward()` മെത്തേഡിന്റെ ഭാഗമല്ലാത്ത എല്ലാ കോളങ്ങളും `Trainer` നീക്കം ചെയ്യും. അതായത്, ഹോൾ വേഡ് മാസ്‌കിംഗ് കൊളേറ്ററാണ് നിങ്ങൾ ഉപയോഗിക്കുന്നതെങ്കിൽ, ട്രെയിനിംഗ് സമയത്ത് `word_ids` കോളം നഷ്ടപ്പെടാതിരിക്കാൻ `remove_unused_columns=False` എന്നും നിങ്ങൾ സെറ്റ് ചെയ്യേണ്ടി വരും.

നിങ്ങൾ പുഷ് ചെയ്യാൻ ആഗ്രഹിക്കുന്ന റിപ്പോസിറ്ററിയുടെ പേര് `hub_model_id` ആർഗ്യുമെന്റ് ഉപയോഗിച്ച് വ്യക്തമാക്കാം എന്നത് ശ്രദ്ധിക്കുക (പ്രത്യേകിച്ച്, ഒരു ഓർഗനൈസേഷനിലേക്ക് പുഷ് ചെയ്യാൻ ഈ ആർഗ്യുമെന്റ് നിങ്ങൾ ഉപയോഗിക്കേണ്ടി വരും). ഉദാഹരണത്തിന്, [`huggingface-course` ഓർഗനൈസേഷനിലേക്ക്](https://huggingface.co/huggingface-course) മോഡൽ പുഷ് ചെയ്തപ്പോൾ, ഞങ്ങൾ `TrainingArguments`-ൽ `hub_model_id="huggingface-course/distilbert-finetuned-imdb"` ചേർത്തു. ഡിഫോൾട്ടായി, ഉപയോഗിക്കുന്ന റിപ്പോസിറ്ററി നിങ്ങളുടെ നെയിംസ്‌പേസിലായിരിക്കും, നിങ്ങൾ സെറ്റ് ചെയ്ത ഔട്ട്‌പുട്ട് ഡയറക്ടറിയുടെ പേരിലായിരിക്കും അത്; അതിനാൽ നമ്മുടെ കാര്യത്തിൽ അത് `"lewtun/distilbert-finetuned-imdb"` ആയിരിക്കും.

`Trainer` ഇൻസ്‌റ്റാൻഷിയേറ്റ് ചെയ്യാനുള്ള എല്ലാ ചേരുവകളും ഇപ്പോൾ നമുക്കുണ്ട്. ഇവിടെ നമ്മൾ സാധാരണ `data_collator` മാത്രമേ ഉപയോഗിക്കുന്നുള്ളൂ, എന്നാൽ ഒരു അഭ്യാസമായി ഹോൾ വേഡ് മാസ്‌കിംഗ് കൊളേറ്റർ പരീക്ഷിച്ച് ഫലങ്ങൾ താരതമ്യം ചെയ്യാം:

```python
from transformers import Trainer

trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=downsampled_dataset["train"],
    eval_dataset=downsampled_dataset["test"],
    data_collator=data_collator,
    tokenizer=tokenizer,
)
```

ഇപ്പോൾ `trainer.train()` റൺ ചെയ്യാൻ നമ്മൾ തയ്യാറാണ് -- എന്നാൽ അതിന് മുമ്പ്, ലാംഗ്വേജ് മോഡലുകളുടെ പ്രകടനം ഇവാല്യുവേറ്റ് ചെയ്യാനുള്ള ഒരു സാധാരണ മെട്രിക്കായ _പെർപ്ലെക്‌സിറ്റി_ (perplexity) എന്താണെന്ന് ചുരുക്കത്തിൽ നോക്കാം.

### ലാംഗ്വേജ് മോഡലുകൾക്കുള്ള പെർപ്ലെക്‌സിറ്റി[[perplexity-for-language-models]]

<Youtube id="NURcDHhYe98"/>

ട്രെയിൻ ചെയ്യാൻ ലേബൽ ചെയ്ത ഒരു കോർപ്പസ് നമുക്ക് നൽകപ്പെടുന്ന ടെക്‌സ്‌റ്റ് ക്ലാസിഫിക്കേഷൻ, ക്വസ്‌റ്റ്യൻ ആൻസറിംഗ് പോലുള്ള മറ്റ് ടാസ്‌ക്കുകളിൽ നിന്ന് വ്യത്യസ്തമായി, ലാംഗ്വേജ് മോഡലിംഗിൽ നമുക്ക് വ്യക്തമായ ലേബലുകളൊന്നുമില്ല. അപ്പോൾ ഒരു ലാംഗ്വേജ് മോഡലിനെ നല്ലതാക്കുന്നത് എന്താണെന്ന് നമ്മൾ എങ്ങനെ നിർണ്ണയിക്കും? നിങ്ങളുടെ ഫോണിലെ ഓട്ടോകറക്റ്റ് സവിശേഷത പോലെ, വ്യാകരണപരമായി ശരിയായ വാക്യങ്ങൾക്ക് ഉയർന്ന പ്രോബബിലിറ്റികളും അർത്ഥമില്ലാത്ത വാക്യങ്ങൾക്ക് കുറഞ്ഞ പ്രോബബിലിറ്റികളും നൽകുന്ന ഒന്നാണ് ഒരു നല്ല ലാംഗ്വേജ് മോഡൽ. ഇത് എങ്ങനെയിരിക്കും എന്നതിനെക്കുറിച്ച് ഒരു മികച്ച ധാരണ ലഭിക്കാൻ, ഒരാളുടെ ഫോണിലെ മോഡൽ തമാശ നിറഞ്ഞ (പലപ്പോഴും അനുചിതമായ) പൂരണങ്ങൾ ഉണ്ടാക്കിയിട്ടുള്ള "ഓട്ടോകറക്റ്റ് പരാജയങ്ങളുടെ" (autocorrect fails) മുഴുവൻ ശേഖരങ്ങളും നിങ്ങൾക്ക് ഓൺലൈനിൽ കാണാം!

## 🤗 Accelerate ഉപയോഗിച്ച് DistilBERT ഫൈൻ-ട്യൂൻ ചെയ്യുന്നു[[fine-tuning-distilbert-with-accelerate]]

`Trainer`-ന്റെ കാര്യത്തിൽ കണ്ടതുപോലെ, ഒരു മാസ്‌ക്‌ഡ് ലാംഗ്വേജ് മോഡൽ ഫൈൻ-ട്യൂൻ ചെയ്യുന്നത് [അധ്യായം 3](/course/chapter3)-ലെ ടെക്‌സ്‌റ്റ് ക്ലാസിഫിക്കേഷൻ ഉദാഹരണത്തിന് വളരെ സമാനമാണ്. വാസ്തവത്തിൽ, ഒരു പ്രത്യേക ഡേറ്റാ കൊളേറ്ററിന്റെ ഉപയോഗം മാത്രമാണ് ഇവിടത്തെ ഒരേയൊരു സൂക്ഷ്മവ്യത്യാസം, അത് ഈ ഭാഗത്തിൽ നേരത്തെ തന്നെ നമ്മൾ പരിശോധിച്ചു കഴിഞ്ഞു!

എന്നാൽ, `DataCollatorForLanguageModeling` ഓരോ ഇവാല്യുവേഷനിലും ക്രമരഹിത മാസ്‌കിംഗ് പ്രയോഗിക്കുന്നു എന്ന് നമ്മൾ കണ്ടു, അതിനാൽ ഓരോ ട്രെയിനിംഗ് റണ്ണിലും നമ്മുടെ പെർപ്ലെക്‌സിറ്റി സ്‌കോറുകളിൽ ചില ചാഞ്ചാട്ടങ്ങൾ കാണാം. ക്രമരഹിതതയുടെ ഈ ഉറവിടം ഇല്ലാതാക്കാനുള്ള ഒരു മാർഗം, മുഴുവൻ ടെസ്‌റ്റ് സെറ്റിലും മാസ്‌കിംഗ് _ഒരിക്കൽ മാത്രം_ പ്രയോഗിച്ച ശേഷം, ഇവാല്യുവേഷൻ സമയത്ത് ബാച്ചുകൾ ശേഖരിക്കാൻ 🤗 Transformers-ലെ ഡിഫോൾട്ട് ഡേറ്റാ കൊളേറ്റർ ഉപയോഗിക്കുകയാണ്. ഇത് എങ്ങനെ പ്രവർത്തിക്കുന്നു എന്ന് കാണാൻ, `DataCollatorForLanguageModeling`-മായുള്ള നമ്മുടെ ആദ്യ പരിചയത്തിന് സമാനമായി, ഒരു ബാച്ചിൽ മാസ്‌കിംഗ് പ്രയോഗിക്കുന്ന ഒരു ലളിതമായ ഫംഗ്‌ഷൻ ഇംപ്ലിമെന്റ് ചെയ്യാം:

```python
def insert_random_mask(batch):
    features = [dict(zip(batch, t)) for t in zip(*batch.values())]
    masked_inputs = data_collator(features)
    # Create a new "masked" column for each column in the dataset
    return {"masked_" + k: v.numpy() for k, v in masked_inputs.items()}
```

അടുത്തതായി, ഈ ഫംഗ്‌ഷൻ നമ്മുടെ ടെസ്‌റ്റ് സെറ്റിൽ പ്രയോഗിച്ച്, മാസ്‌ക് ചെയ്യാത്ത കോളങ്ങൾ ഒഴിവാക്കും, അങ്ങനെ അവയ്ക്ക് പകരം മാസ്‌ക് ചെയ്ത കോളങ്ങൾ വയ്ക്കാം. മുകളിലുള്ള `data_collator`-ന് പകരം അനുയോജ്യമായത് ഉപയോഗിച്ചുകൊണ്ട് ഹോൾ വേഡ് മാസ്‌കിംഗ് നിങ്ങൾക്ക് ഉപയോഗിക്കാം; ആ സാഹചര്യത്തിൽ ഇവിടത്തെ ആദ്യത്തെ വരി നിങ്ങൾ നീക്കം ചെയ്യണം:

```py
downsampled_dataset = downsampled_dataset.remove_columns(["word_ids"])
eval_dataset = downsampled_dataset["test"].map(
    insert_random_mask,
    batched=True,
    remove_columns=downsampled_dataset["test"].column_names,
)
eval_dataset = eval_dataset.rename_columns(
    {
        "masked_input_ids": "input_ids",
        "masked_attention_mask": "attention_mask",
        "masked_labels": "labels",
    }
)
```

തുടർന്ന് പതിവുപോലെ ഡേറ്റാലോഡറുകൾ സെറ്റപ്പ് ചെയ്യാം, എന്നാൽ ഇവാല്യുവേഷൻ സെറ്റിനായി 🤗 Transformers-ലെ `default_data_collator` നമ്മൾ ഉപയോഗിക്കും:

```python
from torch.utils.data import DataLoader
from transformers import default_data_collator

batch_size = 64
train_dataloader = DataLoader(
    downsampled_dataset["train"],
    shuffle=True,
    batch_size=batch_size,
    collate_fn=data_collator,
)
eval_dataloader = DataLoader(
    eval_dataset, batch_size=batch_size, collate_fn=default_data_collator
)
```

ഇവിടെ നിന്ന്, 🤗 Accelerate-ന്റെ സാധാരണ ഘട്ടങ്ങൾ നമ്മൾ പിന്തുടരുന്നു. ആദ്യം ചെയ്യേണ്ടത് പ്രീട്രെയിൻഡ് മോഡലിന്റെ ഒരു പുതിയ പതിപ്പ് ലോഡ് ചെയ്യുകയാണ്:

```
model = AutoModelForMaskedLM.from_pretrained(model_checkpoint)
```

തുടർന്ന് ഒപ്‌റ്റിമൈസർ വ്യക്തമാക്കണം; സാധാരണ `AdamW` നമ്മൾ ഉപയോഗിക്കും:

```python
from torch.optim import AdamW

optimizer = AdamW(model.parameters(), lr=5e-5)
```

ഈ ഒബ്‌ജക്റ്റുകൾ ഉപയോഗിച്ച്, `Accelerator` ഒബ്‌ജക്റ്റ് വഴി ട്രെയിനിംഗിനായി എല്ലാം ഇപ്പോൾ തയ്യാറാക്കാം:

```python
from accelerate import Accelerator

accelerator = Accelerator()
model, optimizer, train_dataloader, eval_dataloader = accelerator.prepare(
    model, optimizer, train_dataloader, eval_dataloader
)
```

നമ്മുടെ മോഡലും ഒപ്‌റ്റിമൈസറും ഡേറ്റാലോഡറുകളും കോൺഫിഗർ ചെയ്തുകഴിഞ്ഞ സ്ഥിതിക്ക്, ലേണിംഗ് റേറ്റ് ഷെഡ്യൂളർ താഴെ കാണുന്നതുപോലെ വ്യക്തമാക്കാം:

```python
from transformers import get_scheduler

num_train_epochs = 3
num_update_steps_per_epoch = len(train_dataloader)
num_training_steps = num_train_epochs * num_update_steps_per_epoch

lr_scheduler = get_scheduler(
    "linear",
    optimizer=optimizer,
    num_warmup_steps=0,
    num_training_steps=num_training_steps,
)
```

ട്രെയിനിംഗിന് മുമ്പ് ചെയ്യാൻ ഇനി ഒരു കാര്യം മാത്രം ബാക്കിയുണ്ട്: Hugging Face Hub-ൽ ഒരു മോഡൽ റിപ്പോസിറ്ററി ഉണ്ടാക്കുക! നമ്മുടെ റിപ്പോയുടെ പൂർണ്ണമായ പേര് ആദ്യം ജനറേറ്റ് ചെയ്യാൻ 🤗 Hub ലൈബ്രറി ഉപയോഗിക്കാം:

```python
from huggingface_hub import get_full_repo_name

model_name = "distilbert-base-uncased-finetuned-imdb-accelerate"
repo_name = get_full_repo_name(model_name)
repo_name
```

```python out
'lewtun/distilbert-base-uncased-finetuned-imdb-accelerate'
```

തുടർന്ന് 🤗 Hub-ലെ `Repository` ക്ലാസ് ഉപയോഗിച്ച് റിപ്പോസിറ്ററി ഉണ്ടാക്കി ക്ലോൺ ചെയ്യുക:

```python
from huggingface_hub import Repository

output_dir = model_name
repo = Repository(output_dir, clone_from=repo_name)
```

അത് കഴിഞ്ഞാൽ, പൂർണ്ണമായ ട്രെയിനിംഗ്, ഇവാല്യുവേഷൻ ലൂപ്പ് എഴുതുക എന്ന ലളിതമായ കാര്യം മാത്രമേ ബാക്കിയുള്ളൂ:

```python
from tqdm.auto import tqdm
import torch
import math

progress_bar = tqdm(range(num_training_steps))

for epoch in range(num_train_epochs):
    # Training
    model.train()
    for batch in train_dataloader:
        outputs = model(**batch)
        loss = outputs.loss
        accelerator.backward(loss)

        optimizer.step()
        lr_scheduler.step()
        optimizer.zero_grad()
        progress_bar.update(1)

    # Evaluation
    model.eval()
    losses = []
    for step, batch in enumerate(eval_dataloader):
        with torch.no_grad():
            outputs = model(**batch)

        loss = outputs.loss
        losses.append(accelerator.gather(loss.repeat(batch_size)))

    losses = torch.cat(losses)
    losses = losses[: len(eval_dataset)]
    try:
        perplexity = math.exp(torch.mean(losses))
    except OverflowError:
        perplexity = float("inf")

    print(f">>> Epoch {epoch}: Perplexity: {perplexity}")

    # Save and upload
    accelerator.wait_for_everyone()
    unwrapped_model = accelerator.unwrap_model(model)
    unwrapped_model.save_pretrained(output_dir, save_function=accelerator.save)
    if accelerator.is_main_process:
        tokenizer.save_pretrained(output_dir)
        repo.push_to_hub(
            commit_message=f"Training in progress epoch {epoch}", blocking=False
        )
```

```python out
>>> Epoch 1: Perplexity: 10.904909330983092
>>> Epoch 2: Perplexity: 10.729503505340409
```

## ഫൈൻ-ട്യൂൻ ചെയ്ത നമ്മുടെ മോഡൽ ഉപയോഗിക്കുന്നു[[using-our-fine-tuned-model]]

Hub-ലെ അതിന്റെ വിജറ്റ് ഉപയോഗിച്ചോ, അല്ലെങ്കിൽ ലോക്കലായി 🤗 Transformers-ലെ `pipeline` ഉപയോഗിച്ചോ, ഫൈൻ-ട്യൂൻ ചെയ്ത നിങ്ങളുടെ മോഡലുമായി നിങ്ങൾക്ക് സംവദിക്കാം. `fill-mask` പൈപ്പ്‌ലൈൻ ഉപയോഗിച്ച് നമ്മുടെ മോഡൽ ഡൗൺലോഡ് ചെയ്യാൻ രണ്ടാമത്തെ രീതി ഉപയോഗിക്കാം:

```python
from transformers import pipeline

mask_filler = pipeline(
    "fill-mask", model="huggingface-course/distilbert-base-uncased-finetuned-imdb"
```
