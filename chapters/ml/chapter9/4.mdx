ഇപ്പോൾ നിങ്ങൾ ഒരു ഡെമോ നിർമ്മിച്ചു കഴിഞ്ഞു, അത് മറ്റുള്ളവരുമായി പങ്കുവയ്ക്കാൻ നിങ്ങൾക്ക് ആഗ്രഹമുണ്ടാകും. Gradio ഡെമോകൾ
രണ്ട് രീതിയിൽ പങ്കുവയ്ക്കാം: ഒരു ***താൽക്കാലിക ഷെയർ ലിങ്ക്*** (temporary share link) ഉപയോഗിച്ചോ, അല്ലെങ്കിൽ ***Spaces-ൽ സ്ഥിരമായി ഹോസ്റ്റ്*** ചെയ്തോ.

ഈ രണ്ട് രീതികളും നമ്മൾ ഉടൻ പരിശോധിക്കും. പക്ഷേ ഡെമോ പങ്കുവയ്ക്കുന്നതിനു മുമ്പ്, അതൊന്ന് മിനുക്കിയെടുക്കാൻ നിങ്ങൾക്ക് താൽപ്പര്യമുണ്ടാകാം 💅.

### നിങ്ങളുടെ Gradio ഡെമോ മിനുക്കിയെടുക്കുന്നു:[[polishing-your-gradio-demo]]

നിങ്ങളുടെ ഡെമോയിലേക്ക് അധിക ഉള്ളടക്കം ചേർക്കാൻ, `Interface` ക്ലാസ് ചില ഓപ്‌ഷണൽ പാരാമീറ്ററുകൾ പിന്തുണയ്ക്കുന്നു:
    - `title`: നിങ്ങളുടെ ഡെമോയ്ക്ക് ഒരു തലക്കെട്ട് നൽകാം; ഇത് ഇൻപുട്ട്, ഔട്ട്‌പുട്ട് കോംപോണന്റുകളുടെ _മുകളിൽ_ പ്രത്യക്ഷപ്പെടും.
    - `description`: ഇന്റർഫേസിന് ഒരു വിവരണം (ടെക്‌സ്‌റ്റ്, Markdown, അല്ലെങ്കിൽ HTML ആയി) നൽകാം; ഇത് ഇൻപുട്ട്, ഔട്ട്‌പുട്ട് കോംപോണന്റുകളുടെ മുകളിലും തലക്കെട്ടിന്റെ താഴെയും പ്രത്യക്ഷപ്പെടും.
    - `article`: ഇന്റർഫേസ് വിശദീകരിക്കുന്ന ഒരു വിപുലീകരിച്ച ലേഖനവും (ടെക്‌സ്‌റ്റ്, Markdown, അല്ലെങ്കിൽ HTML ആയി) നിങ്ങൾക്ക് എഴുതാം. നൽകിയിട്ടുണ്ടെങ്കിൽ, ഇത് ഇൻപുട്ട്, ഔട്ട്‌പുട്ട് കോംപോണന്റുകളുടെ _താഴെ_ പ്രത്യക്ഷപ്പെടും.
    - `theme`: ഡിഫോൾട്ട് നിറങ്ങൾ ഇഷ്ടമല്ലേ? `default`, `huggingface`, `grass`, `peach` ഇവയിലൊന്ന് ഉപയോഗിക്കാൻ theme സെറ്റ് ചെയ്യുക. ഡാർക്ക് തീമിനായി `dark-` എന്ന പ്രിഫിക്‌സും ചേർക്കാം, ഉദാ. `dark-peach` (അല്ലെങ്കിൽ ഡിഫോൾട്ട് ഡാർക്ക് തീമിനായി വെറും `dark`).
    - `examples`: നിങ്ങളുടെ ഡെമോ *ഉപയോഗിക്കാൻ കൂടുതൽ എളുപ്പമാക്കാൻ*, ഫംഗ്‌ഷനായി ചില ഉദാഹരണ ഇൻപുട്ടുകൾ നൽകാം. ഇവ UI കോംപോണന്റുകളുടെ താഴെ പ്രത്യക്ഷപ്പെടും, ഇന്റർഫേസിൽ മൂല്യങ്ങൾ നിറയ്ക്കാൻ ഇവ ഉപയോഗിക്കാം. ഇവ ഒരു നെസ്‌റ്റഡ് ലിസ്‌റ്റായി നൽകണം; അതിൽ പുറത്തെ ലിസ്‌റ്റ് സാമ്പിളുകൾ അടങ്ങിയതും, അകത്തെ ഓരോ ലിസ്‌റ്റും ഓരോ ഇൻപുട്ട് കോംപോണന്റിനോടും ചേരുന്ന ഒരു ഇൻപുട്ട് അടങ്ങിയതുമായിരിക്കും.
    - `live`: നിങ്ങളുടെ ഡെമോ "ലൈവ്" ആക്കണമെങ്കിൽ, അതായത് ഇൻപുട്ട് മാറുമ്പോഴെല്ലാം നിങ്ങളുടെ മോഡൽ വീണ്ടും റൺ ചെയ്യണമെങ്കിൽ, `live=True` എന്ന് സെറ്റ് ചെയ്യാം. വേഗതയുള്ള മോഡലുകളിൽ ഇത് ഉപയോഗിക്കുന്നത് അർത്ഥവത്താണ് (ഈ ഭാഗത്തിന്റെ അവസാനം ഒരു ഉദാഹരണം നമ്മൾ കാണും)
മുകളിലുള്ള ഓപ്‌ഷനുകൾ ഉപയോഗിച്ച്, കൂടുതൽ പൂർണ്ണമായ ഒരു ഇന്റർഫേസ് നമുക്ക് ലഭിക്കുന്നു. Rick and Morty-യുമായി ചാറ്റ് ചെയ്യാൻ താഴെയുള്ള കോഡ് റൺ ചെയ്യുക:

```py
title = "Ask Rick a Question"
description = """
The bot was trained to answer questions based on Rick and Morty dialogues. Ask Rick anything!
<img src="https://huggingface.co/spaces/course-demos/Rick_and_Morty_QA/resolve/main/rick.png" width=200px>
"""

article = "Check out [the original Rick and Morty Bot](https://huggingface.co/spaces/kingabzpro/Rick_and_Morty_Bot) that this demo is based off of."

gr.Interface(
    fn=predict,
    inputs="textbox",
    outputs="text",
    title=title,
    description=description,
    article=article,
    examples=[["What are you doing?"], ["Where should we time travel to?"]],
).launch()
```

മുകളിലുള്ള ഓപ്‌ഷനുകൾ ഉപയോഗിച്ച്, കൂടുതൽ പൂർണ്ണമായ ഒരു ഇന്റർഫേസ് നമുക്ക് ലഭിക്കുന്നു. താഴെയുള്ള ഇന്റർഫേസ് പരീക്ഷിച്ചു നോക്കൂ:

### താൽക്കാലിക ലിങ്കുകൾ ഉപയോഗിച്ച് നിങ്ങളുടെ ഡെമോ പങ്കുവയ്ക്കുന്നു[[sharing-your-demo-with-temporary-links]]
നമ്മുടെ മെഷീൻ ലേണിംഗ് മോഡലിന്റെ പ്രവർത്തിക്കുന്ന ഒരു ഡെമോ ഇപ്പോൾ നമുക്കുള്ളതിനാൽ, നമ്മുടെ ഇന്റർഫേസിലേക്കുള്ള ഒരു ലിങ്ക് എളുപ്പത്തിൽ എങ്ങനെ പങ്കുവയ്ക്കാമെന്ന് പഠിക്കാം.
`launch()` മെത്തേഡിൽ `share=True` എന്ന് സെറ്റ് ചെയ്തുകൊണ്ട് ഇന്റർഫേസുകൾ എളുപ്പത്തിൽ പൊതുവായി പങ്കുവയ്ക്കാം:

```python
gr.Interface(classify_image, "image", "label").launch(share=True)
```

ഇത് ആർക്കും അയച്ചുകൊടുക്കാവുന്ന ഒരു പൊതു, പങ്കുവയ്ക്കാവുന്ന ലിങ്ക് ഉണ്ടാക്കുന്നു! ഈ ലിങ്ക് അയയ്ക്കുമ്പോൾ, മറുവശത്തുള്ള ഉപയോക്താവിന് 72 മണിക്കൂർ വരെ അവരുടെ ബ്രൗസറിൽ മോഡൽ പരീക്ഷിച്ചു നോക്കാം. പ്രോസസ്സിംഗ് നിങ്ങളുടെ ഡിവൈസിലാണ് നടക്കുന്നത് എന്നതിനാൽ (നിങ്ങളുടെ ഡിവൈസ് ഓൺ ആയിരിക്കുന്നിടത്തോളം!), ഡിപ്പൻഡൻസികൾ പാക്കേജ് ചെയ്യുന്നതിനെക്കുറിച്ച് നിങ്ങൾ വിഷമിക്കേണ്ടതില്ല. ഒരു Google Colab നോട്ട്‌ബുക്കിൽ നിന്നാണ് നിങ്ങൾ പ്രവർത്തിക്കുന്നതെങ്കിൽ, ഒരു ഷെയർ ലിങ്ക് എപ്പോഴും സ്വയമേവ ഉണ്ടാക്കപ്പെടും. അത് സാധാരണയായി ഇങ്ങനെയായിരിക്കും: **XXXXX.gradio.app**. ലിങ്ക് ഒരു Gradio ലിങ്കിലൂടെയാണ് നൽകുന്നതെങ്കിലും, ഞങ്ങൾ നിങ്ങളുടെ ലോക്കൽ സെർവറിന്റെ ഒരു പ്രോക്‌സി മാത്രമാണ്; ഇന്റർഫേസുകളിലൂടെ അയയ്ക്കുന്ന ഒരു ഡേറ്റയും ഞങ്ങൾ സംഭരിക്കുന്നില്ല.

എന്നിരുന്നാലും, ഈ ലിങ്കുകൾ പൊതുവായി ആക്‌സസ് ചെയ്യാവുന്നവയാണെന്ന് ഓർക്കുക; അതായത് ആർക്കും നിങ്ങളുടെ മോഡൽ പ്രവചനത്തിനായി ഉപയോഗിക്കാം! അതിനാൽ, നിങ്ങൾ എഴുതുന്ന ഫംഗ്‌ഷനുകളിലൂടെ സെൻസിറ്റീവ് വിവരങ്ങളൊന്നും വെളിപ്പെടുത്താതിരിക്കാനും, നിങ്ങളുടെ ഡിവൈസിൽ നിർണ്ണായകമായ മാറ്റങ്ങളൊന്നും സംഭവിക്കാൻ അനുവദിക്കാതിരിക്കാനും ശ്രദ്ധിക്കുക. `share=False` (ഡിഫോൾട്ട്) എന്ന് സെറ്റ് ചെയ്താൽ, ഒരു ലോക്കൽ ലിങ്ക് മാത്രമേ ഉണ്ടാക്കപ്പെടുകയുള്ളൂ.

### നിങ്ങളുടെ ഡെമോ Hugging Face Spaces-ൽ ഹോസ്റ്റ് ചെയ്യുന്നു[[hosting-your-demo-on-hugging-face-spaces]]

നിങ്ങളുടെ Gradio മോഡൽ ഇന്റർനെറ്റിൽ സ്ഥിരമായി ഹോസ്റ്റ് ചെയ്യാനുള്ള ഇൻഫ്രാസ്ട്രക്‌ചർ Hugging Face Spaces നൽകുന്നു, **സൗജന്യമായി**! (പബ്ലിക് അല്ലെങ്കിൽ പ്രൈവറ്റ്) ഒരു റിപ്പോ ഉണ്ടാക്കാനും അതിലേക്ക് പുഷ് ചെയ്യാനും Spaces നിങ്ങളെ അനുവദിക്കുന്നു;
അവിടെ നിങ്ങളുടെ Gradio
ഇന്റർഫേസ് കോഡ് ഒരു `app.py` ഫയലിൽ ഉണ്ടായിരിക്കും. തുടങ്ങാൻ [ഘട്ടം ഘട്ടമായുള്ള ട്യൂട്ടോറിയൽ വായിക്കുക](https://huggingface.co/blog/gradio-spaces), അല്ലെങ്കിൽ താഴെയുള്ള ഒരു ഉദാഹരണ വീഡിയോ കാണുക.

## ✏️ ഇത് പ്രയോഗിച്ചു നോക്കാം![[lets-apply-it]]

ഇതുവരെയുള്ള ഭാഗങ്ങളിൽ നമ്മൾ പഠിച്ചത് ഉപയോഗിച്ച്, [ഈ അധ്യായത്തിന്റെ ഒന്നാം ഭാഗത്തിൽ](/course/chapter9/1) നമ്മൾ കണ്ട സ്‌കെച്ച് റെക്കഗ്നിഷൻ ഡെമോ ഉണ്ടാക്കാം. നമ്മുടെ ഇന്റർഫേസിൽ കുറച്ച് ഇഷ്ടാനുസൃതമാക്കലുകൾ ചേർക്കുകയും, കൈമാറാവുന്ന ഒരു പൊതു ലിങ്ക് ഉണ്ടാക്കാൻ `share=True` എന്ന് സെറ്റ് ചെയ്യുകയും ചെയ്യാം.

[class_names.txt](https://huggingface.co/spaces/dawood/Sketch-Recognition/blob/main/class_names.txt)-ൽ നിന്ന് ലേബലുകളും, [pytorch_model.bin](https://huggingface.co/spaces/dawood/Sketch-Recognition/blob/main/pytorch_model.bin)-ൽ നിന്ന് പ്രീട്രെയിൻ ചെയ്ത pytorch മോഡലും നമുക്ക് ലോഡ് ചെയ്യാം. ലിങ്ക് പിന്തുടർന്ന്, ഫയൽ പ്രിവ്യൂവിന്റെ മുകളിൽ ഇടതു മൂലയിലുള്ള download ക്ലിക്ക് ചെയ്ത് ഈ ഫയലുകൾ ഡൗൺലോഡ് ചെയ്യുക. നമ്മുടെ മോഡൽ ലോഡ് ചെയ്യാനും ഒരു `predict()` ഫംഗ്‌ഷൻ ഉണ്ടാക്കാനും ഈ ഫയലുകൾ എങ്ങനെ ഉപയോഗിക്കുന്നു എന്ന് കാണാൻ താഴെയുള്ള കോഡ് നോക്കാം:
```py
from pathlib import Path
import torch
import gradio as gr
from torch import nn

LABELS = Path("class_names.txt").read_text().splitlines()

model = nn.Sequential(
    nn.Conv2d(1, 32, 3, padding="same"),
    nn.ReLU(),
    nn.MaxPool2d(2),
    nn.Conv2d(32, 64, 3, padding="same"),
    nn.ReLU(),
    nn.MaxPool2d(2),
    nn.Conv2d(64, 128, 3, padding="same"),
    nn.ReLU(),
    nn.MaxPool2d(2),
    nn.Flatten(),
    nn.Linear(1152, 256),
    nn.ReLU(),
    nn.Linear(256, len(LABELS)),
)
state_dict = torch.load("pytorch_model.bin", map_location="cpu")
model.load_state_dict(state_dict, strict=False)
model.eval()


def predict(im):
    x = torch.tensor(im, dtype=torch.float32).unsqueeze(0).unsqueeze(0) / 255.0
    with torch.no_grad():
        out = model(x)
    probabilities = torch.nn.functional.softmax(out[0], dim=0)
    values, indices = torch.topk(probabilities, 5)
    return {LABELS[i]: v.item() for i, v in zip(indices, values)}
```

ഇപ്പോൾ നമുക്ക് ഒരു `predict()` ഫംഗ്‌ഷൻ ഉണ്ട്. അടുത്ത ഘട്ടം നമ്മുടെ gradio ഇന്റർഫേസ് നിർവചിച്ച് ലോഞ്ച് ചെയ്യുകയാണ്:

```py
interface = gr.Interface(
    predict,
    inputs="sketchpad",
    outputs="label",
    theme="huggingface",
    title="Sketch Recognition",
    description="Who wants to play Pictionary? Draw a common object like a shovel or a laptop, and the algorithm will guess in real time!",
    article="<p style='text-align: center'>Sketch Recognition | Demo Model</p>",
    live=True,
)
interface.launch(share=True)
```

`Interface`-ലെ `live=True` പാരാമീറ്റർ ശ്രദ്ധിക്കുക; അതിനർത്ഥം, ആരെങ്കിലും സ്‌കെച്ച്‌പാഡിൽ വരയ്ക്കുമ്പോഴെല്ലാം
സ്‌കെച്ച് ഡെമോ ഒരു പ്രവചനം നടത്തുന്നു എന്നാണ് (submit ബട്ടൺ ഇല്ല!).

കൂടാതെ, `launch()` മെത്തേഡിൽ `share=True` എന്ന ആർഗ്യുമെന്റും നമ്മൾ സെറ്റ് ചെയ്തു.
ഇത് ആർക്കും അയച്ചുകൊടുക്കാവുന്ന ഒരു പൊതു ലിങ്ക്
ഉണ്ടാക്കും! ഈ ലിങ്ക് അയയ്ക്കുമ്പോൾ, മറുവശത്തുള്ള ഉപയോക്താവിന് സ്‌കെച്ച് റെക്കഗ്നിഷൻ
മോഡൽ പരീക്ഷിച്ചു നോക്കാം. ഒന്നുകൂടി പറയട്ടെ, മോഡൽ Hugging Face Spaces-ലും നിങ്ങൾക്ക് ഹോസ്റ്റ് ചെയ്യാം;
അങ്ങനെയാണ് മുകളിലുള്ള ഡെമോ ഇവിടെ എംബെഡ് ചെയ്യാൻ ഞങ്ങൾക്ക് കഴിയുന്നത്.

അടുത്തതായി, Hugging Face ഇക്കോസിസ്റ്റത്തോടൊപ്പം Gradio ഉപയോഗിക്കാവുന്ന മറ്റു വഴികൾ നമ്മൾ പരിശോധിക്കും!
