ഈ ഭാഗത്തിൽ, `Interface` ക്ലാസിനെ കൂടുതൽ അടുത്ത് പരിശോധിക്കുകയും, ഒന്ന് ഉണ്ടാക്കാൻ ഉപയോഗിക്കുന്ന
പ്രധാന പാരാമീറ്ററുകൾ മനസ്സിലാക്കുകയും ചെയ്യും.

## ഒരു Interface എങ്ങനെ ഉണ്ടാക്കാം[[how-to-create-an-interface]]

`Interface` ക്ലാസിന് നിർബന്ധമായ 3 പാരാമീറ്ററുകൾ ഉണ്ടെന്ന് നിങ്ങൾ ശ്രദ്ധിക്കും:

`Interface(fn, inputs, outputs, ...)`

ഈ പാരാമീറ്ററുകൾ ഇവയാണ്:

  - `fn`: Gradio ഇന്റർഫേസ് പൊതിയുന്ന (wrap ചെയ്യുന്ന) പ്രവചന ഫംഗ്‌ഷൻ. ഈ ഫംഗ്‌ഷന് ഒന്നോ അതിലധികമോ പാരാമീറ്ററുകൾ എടുക്കാനും ഒന്നോ അതിലധികമോ മൂല്യങ്ങൾ തിരികെ നൽകാനും കഴിയും
  - `inputs`: ഇൻപുട്ട് കോംപോണന്റിന്റെ തരം (തരങ്ങൾ). `"image"` അല്ലെങ്കിൽ `"mic"` പോലുള്ള നിരവധി മുൻകൂട്ടി നിർമ്മിച്ച കോംപോണന്റുകൾ Gradio നൽകുന്നു.
  - `outputs`: ഔട്ട്‌പുട്ട് കോംപോണന്റിന്റെ തരം (തരങ്ങൾ). ഇവിടെയും, ഉദാ. `"image"` അല്ലെങ്കിൽ `"label"` പോലുള്ള നിരവധി മുൻകൂട്ടി നിർമ്മിച്ച കോംപോണന്റുകൾ Gradio നൽകുന്നു.

കോംപോണന്റുകളുടെ പൂർണ്ണമായ പട്ടികയ്ക്ക്, [Gradio ഡോക്യുമെന്റേഷൻ കാണുക](https://gradio.app/docs). മുൻകൂട്ടി നിർമ്മിച്ച ഓരോ കോംപോണന്റും, അതിനോട് അനുബന്ധിച്ച ക്ലാസ് ഇൻസ്റ്റാൻഷിയേറ്റ് ചെയ്തുകൊണ്ട് ഇഷ്ടാനുസൃതമാക്കാം.

ഉദാഹരണത്തിന്, [മുൻ ഭാഗത്തിൽ](/course/chapter9/2) നമ്മൾ കണ്ടതുപോലെ,
`inputs` പാരാമീറ്ററിലേക്ക് `"textbox"` നൽകുന്നതിനു പകരം, 7 വരികളും ഒരു ലേബലുമുള്ള ഒരു ടെക്‌സ്‌റ്റ്‌ബോക്‌സ് ഉണ്ടാക്കാൻ `Textbox(lines=7, label="Prompt")` എന്ന ഒരു കോംപോണന്റ് നിങ്ങൾക്ക് നൽകാം.

ഇനി മറ്റൊരു ഉദാഹരണം നോക്കാം, ഇത്തവണ ഒരു `Audio` കോംപോണന്റ് ഉപയോഗിച്ച്.

## ഓഡിയോ ഉപയോഗിച്ചുള്ള ഒരു ലളിതമായ ഉദാഹരണം[[a-simple-example-with-audio]]

മുമ്പ് പറഞ്ഞതുപോലെ, Gradio വ്യത്യസ്തങ്ങളായ നിരവധി ഇൻപുട്ടുകളും ഔട്ട്‌പുട്ടുകളും നൽകുന്നു.
അതിനാൽ ഓഡിയോയുമായി പ്രവർത്തിക്കുന്ന ഒരു `Interface` നിർമ്മിക്കാം.

ഈ ഉദാഹരണത്തിൽ, ഒരു ഓഡിയോ ഫയൽ എടുത്ത് അതിനെ വെറുതെ തിരിച്ചിടുന്ന (reverse ചെയ്യുന്ന)
ഒരു ഓഡിയോ-ടു-ഓഡിയോ ഫംഗ്‌ഷൻ നമ്മൾ നിർമ്മിക്കും.

ഇൻപുട്ടിനായി നമ്മൾ `Audio` കോംപോണന്റ് ഉപയോഗിക്കും. `Audio` കോംപോണന്റ് ഉപയോഗിക്കുമ്പോൾ,
ഓഡിയോയുടെ `source` ഉപയോക്താവ് അപ്‌ലോഡ് ചെയ്യുന്ന ഒരു ഫയൽ ആയിരിക്കണോ, അതോ ഉപയോക്താവ്
ശബ്ദം റെക്കോർഡ് ചെയ്യുന്ന ഒരു മൈക്രോഫോൺ ആയിരിക്കണോ എന്ന് നിങ്ങൾക്ക് വ്യക്തമാക്കാം. ഇവിടെ, അത്
`"microphone"` ആയി സെറ്റ് ചെയ്യാം. രസത്തിനു വേണ്ടി, നമ്മുടെ `Audio`-യ്ക്ക് "Speak here..." എന്ന്
പറയുന്ന ഒരു ലേബലും ചേർക്കും.

കൂടാതെ, എളുപ്പത്തിൽ "തിരിച്ചിടാൻ" കഴിയുന്ന വിധത്തിൽ ഓഡിയോ ഒരു numpy അറേ ആയി ലഭിക്കണമെന്ന്
നമുക്കുണ്ട്. അതിനാൽ `"type"` `"numpy"` ആയി സെറ്റ് ചെയ്യും; ഇത് ഇൻപുട്ട് ഡേറ്റയെ
(`sample_rate`, `data`) എന്ന ഒരു ട്യൂപ്പിൾ ആയി നമ്മുടെ ഫംഗ്‌ഷനിലേക്ക് കൈമാറുന്നു.

സാമ്പിൾ റേറ്റും ഡേറ്റയുടെ numpy അറേയും അടങ്ങിയ ഒരു ട്യൂപ്പിളിനെ പ്ലേ ചെയ്യാവുന്ന ഒരു ഓഡിയോ ഫയലായി
സ്വയമേവ റെൻഡർ ചെയ്യാൻ കഴിയുന്ന `Audio` ഔട്ട്‌പുട്ട് കോംപോണന്റും നമ്മൾ ഉപയോഗിക്കും.
ഇവിടെ, ഒരു ഇഷ്ടാനുസൃതമാക്കലും ആവശ്യമില്ലാത്തതിനാൽ, `"audio"` എന്ന സ്ട്രിംഗ്
കുറുക്കുവഴി (shortcut) നമ്മൾ ഉപയോഗിക്കും.


```py
import numpy as np
import gradio as gr


def reverse_audio(audio):
    sr, data = audio
    reversed_audio = (sr, np.flipud(data))
    return reversed_audio


mic = gr.Audio(source="microphone", type="numpy", label="Speak here...")
gr.Interface(reverse_audio, mic, "audio").launch()
```

മുകളിലുള്ള കോഡ് താഴെ കാണുന്നതുപോലുള്ള ഒരു ഇന്റർഫേസ് ഉണ്ടാക്കും (നിങ്ങളുടെ ബ്രൗസർ മൈക്രോഫോൺ
അനുമതി ചോദിക്കുന്നില്ലെങ്കിൽ, <a href="https://huggingface.co/spaces/course-demos/audio-reverse" target="_blank">ഡെമോ ഒരു പ്രത്യേക ടാബിൽ തുറക്കുക</a>.)

## ഒന്നിലധികം ഇൻപുട്ടുകളും ഔട്ട്‌പുട്ടുകളും കൈകാര്യം ചെയ്യുന്നു[[handling-multiple-inputs-and-outputs]]

ഒന്നിലധികം ഇൻപുട്ടുകളും ഔട്ട്‌പുട്ടുകളുമുള്ള, കുറച്ചുകൂടി സങ്കീർണ്ണമായ ഒരു ഫംഗ്‌ഷൻ നമുക്കുണ്ടെന്ന് കരുതുക.
താഴെയുള്ള ഉദാഹരണത്തിൽ, ഒരു ഡ്രോപ്‌ഡൗൺ ഇൻഡെക്‌സും, ഒരു സ്ലൈഡർ മൂല്യവും, ഒരു സംഖ്യയും എടുത്ത്,
ഒരു സംഗീത സ്വരത്തിന്റെ (musical tone) ഓഡിയോ സാമ്പിൾ തിരികെ നൽകുന്ന ഒരു ഫംഗ്‌ഷൻ നമുക്കുണ്ട്.

ഇൻപുട്ട്, ഔട്ട്‌പുട്ട് കോംപോണന്റുകളുടെ ഒരു ലിസ്‌റ്റ് നമ്മൾ എങ്ങനെ കൈമാറുന്നു എന്ന് നോക്കുക,
എന്താണ് സംഭവിക്കുന്നത് എന്ന് പിന്തുടരാൻ കഴിയുന്നുണ്ടോ എന്ന് പരിശോധിക്കുക.

ഇവിടെ പ്രധാന കാര്യം ഇതാണ്, നിങ്ങൾ കൈമാറുമ്പോൾ:
* ഇൻപുട്ട് കോംപോണന്റുകളുടെ ഒരു ലിസ്‌റ്റ്, ഓരോ കോംപോണന്റും ക്രമത്തിൽ ഒരു പാരാമീറ്ററിനോട് ചേരുന്നു.
* ഔട്ട്‌പുട്ട് കോംപോണന്റുകളുടെ ഒരു ലിസ്‌റ്റ്, ഓരോ കോംപോണന്റും തിരികെ നൽകുന്ന ഒരു മൂല്യത്തോട് ചേരുന്നു.

മൂന്ന് ഇൻപുട്ട് കോംപോണന്റുകൾ `generate_tone()` ഫംഗ്‌ഷന്റെ മൂന്ന് ആർഗ്യുമെന്റുകളുമായി എങ്ങനെ ചേർന്നുവരുന്നു എന്ന് താഴെയുള്ള കോഡ് കാണിക്കുന്നു:

```py
import numpy as np
import gradio as gr

notes = ["C", "C#", "D", "D#", "E", "F", "F#", "G", "G#", "A", "A#", "B"]


def generate_tone(note, octave, duration):
    sr = 48000
    a4_freq, tones_from_a4 = 440, 12 * (octave - 4) + (note - 9)
    frequency = a4_freq * 2 ** (tones_from_a4 / 12)
    duration = int(duration)
    audio = np.linspace(0, duration, duration * sr)
    audio = (20000 * np.sin(audio * (2 * np.pi * frequency))).astype(np.int16)
    return (sr, audio)


gr.Interface(
    generate_tone,
    [
        gr.Dropdown(notes, type="index"),
        gr.Slider(minimum=4, maximum=6, step=1),
        gr.Number(value=1, label="Duration in seconds"),
    ],
    "audio",
).launch()
```

### `launch()` മെത്തേഡ്[[the-launch-method]]

ഇതുവരെ, ഇന്റർഫേസ് ലോഞ്ച് ചെയ്യാൻ നമ്മൾ `launch()` മെത്തേഡ് ഉപയോഗിച്ചു, പക്ഷേ
അത് എന്താണ് ചെയ്യുന്നത് എന്ന് നമ്മൾ ശരിക്കും ചർച്ച ചെയ്തിട്ടില്ല.

ഡിഫോൾട്ടായി, `launch()` മെത്തേഡ് ലോക്കലായി റൺ ചെയ്യുന്ന ഒരു വെബ് സെർവറിൽ ഡെമോ
ലോഞ്ച് ചെയ്യും. നിങ്ങളുടെ കോഡ് ഒരു Jupyter അല്ലെങ്കിൽ Colab നോട്ട്‌ബുക്കിലാണ് റൺ ചെയ്യുന്നതെങ്കിൽ,
നിങ്ങൾക്ക് എളുപ്പത്തിൽ ഉപയോഗിക്കാൻ Gradio ഡെമോ GUI നോട്ട്‌ബുക്കിനുള്ളിൽ തന്നെ എംബെഡ് ചെയ്യും.

വ്യത്യസ്ത പാരാമീറ്ററുകളിലൂടെ `launch()`-ന്റെ പെരുമാറ്റം നിങ്ങൾക്ക് ഇഷ്ടാനുസൃതമാക്കാം:

  - `inline` - Python നോട്ട്‌ബുക്കുകളിൽ ഇന്റർഫേസ് ഇൻലൈനായി കാണിക്കണോ എന്ന്.
  - `inbrowser` - ഡിഫോൾട്ട് ബ്രൗസറിലെ ഒരു പുതിയ ടാബിൽ ഇന്റർഫേസ് സ്വയമേവ ലോഞ്ച് ചെയ്യണോ എന്ന്.
  - `share` - ഇന്റർഫേസിനായി നിങ്ങളുടെ കമ്പ്യൂട്ടറിൽ നിന്ന് പൊതുവായി പങ്കുവയ്ക്കാവുന്ന ഒരു ലിങ്ക് ഉണ്ടാക്കണോ എന്ന്. ഒരു Google Drive ലിങ്ക് പോലെ!

`share` പാരാമീറ്ററിനെക്കുറിച്ച് അടുത്ത ഭാഗത്തിൽ കൂടുതൽ വിശദമായി നമ്മൾ പറയും!

## ✏️ ഇത് പ്രയോഗിച്ചു നോക്കാം![[lets-apply-it]]

ഒരു **സ്‌പീച്ച്-റെക്കഗ്നിഷൻ** (speech-recognition) മോഡൽ ഡെമോ ചെയ്യാൻ അനുവദിക്കുന്ന ഒരു ഇന്റർഫേസ് നിർമ്മിക്കാം.
ഇത് രസകരമാക്കാൻ, ഒരു മൈക്ക് ഇൻപുട്ട് *അല്ലെങ്കിൽ* അപ്‌ലോഡ് ചെയ്ത ഒരു ഫയൽ - ഇവയിൽ ഏതും നമ്മൾ സ്വീകരിക്കും.

പതിവുപോലെ, 🤗 Transformers-ലെ `pipeline()` ഫംഗ്‌ഷൻ ഉപയോഗിച്ച് നമ്മുടെ സ്‌പീച്ച് റെക്കഗ്നിഷൻ മോഡൽ ലോഡ് ചെയ്യും.
ഒന്ന് പെട്ടെന്ന് ഓർമ്മ പുതുക്കണമെങ്കിൽ, [അധ്യായം 1-ലെ ആ ഭാഗത്തേക്ക്](/course/chapter1/3) തിരികെ പോകാം.   അടുത്തതായി, ഓഡിയോ പ്രോസസ്സ് ചെയ്ത് ട്രാൻസ്‌ക്രിപ്‌ഷൻ തിരികെ നൽകുന്ന ഒരു `transcribe_audio()` ഫംഗ്‌ഷൻ നമ്മൾ ഇംപ്ലിമെന്റ് ചെയ്യും. അവസാനം, ഇൻപുട്ടുകൾക്കായി `Audio` കോംപോണന്റുകളും ഔട്ട്‌പുട്ടിനായി വെറും ടെക്‌സ്‌റ്റും ഉള്ള ഒരു `Interface`-ൽ ഈ ഫംഗ്‌ഷൻ പൊതിയും. മൊത്തത്തിൽ, ഈ ആപ്ലിക്കേഷന്റെ കോഡ് ഇതാണ്:

```py
from transformers import pipeline
import gradio as gr

model = pipeline("automatic-speech-recognition")


def transcribe_audio(audio):
    transcription = model(audio)["text"]
    return transcription


gr.Interface(
    fn=transcribe_audio,
    inputs=gr.Audio(type="filepath"),
    outputs="text",
).launch()
```

നിങ്ങളുടെ ബ്രൗസർ മൈക്രോഫോൺ അനുമതി ചോദിക്കുന്നില്ലെങ്കിൽ, <a href="https://huggingface.co/spaces/course-demos/audio-reverse" target="_blank">ഡെമോ ഒരു പ്രത്യേക ടാബിൽ തുറക്കുക</a>.

അത്രമാത്രം! ഓഡിയോ ട്രാൻസ്‌ക്രൈബ് ചെയ്യാൻ ഇപ്പോൾ ഈ ഇന്റർഫേസ് നിങ്ങൾക്ക് ഉപയോഗിക്കാം. ഇവിടെ ശ്രദ്ധിക്കുക,
`optional` പാരാമീറ്റർ `True` ആയി നൽകുന്നതിലൂടെ, ഒരു മൈക്രോഫോണോ ഒരു ഓഡിയോ ഫയലോ
(അല്ലെങ്കിൽ രണ്ടുമില്ലാതെയോ - പക്ഷേ അത് ഒരു എറർ സന്ദേശം തിരികെ നൽകും) നൽകാൻ നമ്മൾ ഉപയോക്താവിനെ അനുവദിക്കുന്നു.

നിങ്ങളുടെ ഇന്റർഫേസ് മറ്റുള്ളവരുമായി എങ്ങനെ പങ്കുവയ്ക്കാമെന്ന് കാണാൻ തുടരുക!
