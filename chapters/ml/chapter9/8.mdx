# Gradio, പഠിച്ചു കഴിഞ്ഞു![[gradio-check]]

    chapter={9}

Gradio ഉപയോഗിച്ച് മികച്ച ML ഡെമോകൾ നിർമ്മിക്കുന്നതിനെക്കുറിച്ചുള്ള അധ്യായം ഇതോടെ അവസാനിക്കുന്നു - നിങ്ങൾ ഇത് ആസ്വദിച്ചു എന്ന് ഞങ്ങൾ പ്രതീക്ഷിക്കുന്നു! ചുരുക്കത്തിൽ, ഈ അധ്യായത്തിൽ നമ്മൾ പഠിച്ചത്:

- ഹൈ-ലെവൽ `Interface` API ഉപയോഗിച്ച് Gradio ഡെമോകൾ എങ്ങനെ ഉണ്ടാക്കാം, വ്യത്യസ്ത ഇൻപുട്ട്, ഔട്ട്‌പുട്ട് മോഡാലിറ്റികൾ എങ്ങനെ കോൺഫിഗർ ചെയ്യാം.
- താൽക്കാലിക ലിങ്കുകളിലൂടെയും [Hugging Face Spaces](https://huggingface.co/spaces)-ൽ ഹോസ്റ്റ് ചെയ്തും Gradio ഡെമോകൾ പങ്കുവയ്ക്കാനുള്ള വ്യത്യസ്ത വഴികൾ.
- Hugging Face Hub-ലെ മോഡലുകളും Spaces-ഉം ഉപയോഗിച്ച് Gradio ഡെമോകൾ എങ്ങനെ ഇന്റഗ്രേറ്റ് ചെയ്യാം.
- ഒരു ഡെമോയിൽ state സംഭരിക്കുന്നതോ ഓതന്റിക്കേഷൻ നൽകുന്നതോ പോലുള്ള അഡ്വാൻസ്‌ഡ് ഫീച്ചറുകൾ.
- Gradio Blocks ഉപയോഗിച്ച് നിങ്ങളുടെ ഡെമോയുടെ ഡേറ്റാ ഫ്ലോയുടെയും ലേഔട്ടിന്റെയും മേൽ എങ്ങനെ പൂർണ്ണ നിയന്ത്രണം നേടാം.

ഈ അധ്യായത്തിൽ പഠിച്ച ആശയങ്ങളെക്കുറിച്ചുള്ള നിങ്ങളുടെ ധാരണ പരീക്ഷിക്കണമെങ്കിൽ, അടുത്ത ഭാഗത്തിലെ ക്വിസ് നോക്കൂ!

## അടുത്തത് എവിടേക്ക്?[[where-to-next]]

Gradio-യെക്കുറിച്ച് കൂടുതൽ പഠിക്കണമെങ്കിൽ നിങ്ങൾക്ക്

- റിപ്പോയിലെ [Demos](https://github.com/gradio-app/gradio/tree/main/demo) നോക്കാം; അവിടെ ധാരാളം ഉദാഹരണങ്ങളുണ്ട്.
- [Guides](https://gradio.app/guides/) പേജ് കാണാം; അവിടെ മികച്ചതും അഡ്വാൻസ്‌ഡുമായ ഫീച്ചറുകളെക്കുറിച്ചുള്ള ഗൈഡുകൾ കണ്ടെത്താം.
- വിശദാംശങ്ങൾ പഠിക്കാൻ [Docs](https://gradio.app/docs/) പേജ് പരിശോധിക്കാം.
