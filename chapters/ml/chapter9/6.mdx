ഒരു അടിസ്ഥാന ഇന്റർഫേസ് നിർമ്മിക്കാനും പങ്കുവയ്ക്കാനും ഇപ്പോൾ നമുക്ക് കഴിയുന്നതിനാൽ, സ്‌റ്റേറ്റ് (state), ഇന്റർപ്രെറ്റേഷൻ (interpretation) പോലുള്ള കുറച്ചുകൂടി അഡ്വാൻസ്‌ഡ് ഫീച്ചറുകൾ പരിശോധിക്കാം.

### ഡേറ്റ നിലനിർത്താൻ state ഉപയോഗിക്കുന്നു[[using-state-to-persist-data]]

Gradio *സെഷൻ സ്‌റ്റേറ്റ്* (session state) പിന്തുണയ്ക്കുന്നു; അതിൽ ഒരു പേജ് ലോഡിനുള്ളിലെ ഒന്നിലധികം സബ്‌മിറ്റുകളിലുടനീളം
ഡേറ്റ നിലനിൽക്കുന്നു. ഉദാഹരണത്തിന്, ഉപയോക്താവ് മോഡലുമായി ഇടപഴകുമ്പോൾ ഡേറ്റ നിലനിർത്തേണ്ട ചാറ്റ്‌ബോട്ടുകളുടെ
ഡെമോകൾ നിർമ്മിക്കാൻ സെഷൻ സ്‌റ്റേറ്റ് ഉപകാരപ്രദമാണ്. നിങ്ങളുടെ മോഡലിന്റെ വ്യത്യസ്ത ഉപയോക്താക്കൾക്കിടയിൽ സെഷൻ സ്‌റ്റേറ്റ് ഡേറ്റ പങ്കുവയ്ക്കുന്നില്ല എന്ന് ശ്രദ്ധിക്കുക.

ഒരു സെഷൻ സ്‌റ്റേറ്റിൽ ഡേറ്റ സംഭരിക്കാൻ, നിങ്ങൾ മൂന്ന് കാര്യങ്ങൾ ചെയ്യേണ്ടതുണ്ട്:

1. ഇന്റർഫേസിന്റെ സ്‌റ്റേറ്റിനെ പ്രതിനിധീകരിക്കുന്ന ഒരു *അധിക പാരാമീറ്റർ* നിങ്ങളുടെ ഫംഗ്‌ഷനിലേക്ക് കൈമാറുക.
1. ഫംഗ്‌ഷന്റെ അവസാനം, സ്‌റ്റേറ്റിന്റെ പുതുക്കിയ മൂല്യം ഒരു *അധിക റിട്ടേൺ മൂല്യമായി* തിരികെ നൽകുക.
1. നിങ്ങളുടെ `Interface` ഉണ്ടാക്കുമ്പോൾ 'state' ഇൻപുട്ട്, 'state' ഔട്ട്‌പുട്ട് കോംപോണന്റുകൾ ചേർക്കുക.

താഴെയുള്ള ചാറ്റ്‌ബോട്ട് ഉദാഹരണം കാണുക:

```py
import random

import gradio as gr


def chat(message, history):
    history = history or []
    if message.startswith("How many"):
        response = random.randint(1, 10)
    elif message.startswith("How"):
        response = random.choice(["Great", "Good", "Okay", "Bad"])
    elif message.startswith("Where"):
        response = random.choice(["Here", "There", "Somewhere"])
    else:
        response = "I don't know"
    history.append((message, response))
    return history, history


iface = gr.Interface(
    chat,
    ["text", "state"],
    ["chatbot", "state"],
    allow_screenshot=False,
    allow_flagging="never",
)
iface.launch()
```

ഔട്ട്‌പുട്ട് കോംപോണന്റിന്റെ സ്‌റ്റേറ്റ് സബ്‌മിറ്റുകളിലുടനീളം എങ്ങനെ നിലനിൽക്കുന്നു എന്ന് ശ്രദ്ധിക്കുക.
കുറിപ്പ്: state പാരാമീറ്ററിലേക്ക് ഒരു ഡിഫോൾട്ട് മൂല്യം നിങ്ങൾക്ക് കൈമാറാം;
അത് സ്‌റ്റേറ്റിന്റെ പ്രാരംഭ മൂല്യമായി ഉപയോഗിക്കും.

### പ്രവചനങ്ങൾ മനസ്സിലാക്കാൻ interpretation ഉപയോഗിക്കുന്നു[[using-interpretation-to-understand-predictions]]

മിക്ക മെഷീൻ ലേണിംഗ് മോഡലുകളും ബ്ലാക്ക് ബോക്‌സുകളാണ്; ഫംഗ്‌ഷന്റെ ആന്തരിക ലോജിക് അന്തിമ ഉപയോക്താവിൽ നിന്ന് മറഞ്ഞിരിക്കുന്നു. സുതാര്യത പ്രോത്സാഹിപ്പിക്കാൻ, Interface ക്ലാസിലെ interpretation കീവേഡ് default ആയി സെറ്റ് ചെയ്യുന്നതിലൂടെ മാത്രം നിങ്ങളുടെ മോഡലിലേക്ക് ഇന്റർപ്രെറ്റേഷൻ ചേർക്കുന്നത് ഞങ്ങൾ വളരെ എളുപ്പമാക്കിയിട്ടുണ്ട്. ഇൻപുട്ടിന്റെ ഏതു ഭാഗങ്ങളാണ് ഔട്ട്‌പുട്ടിന് കാരണമായത് എന്ന് മനസ്സിലാക്കാൻ ഇത് നിങ്ങളുടെ ഉപയോക്താക്കളെ അനുവദിക്കുന്നു. ഇന്റർപ്രെറ്റേഷനും ഉൾപ്പെടുന്ന ഒരു ഇമേജ് ക്ലാസിഫയർ കാണിക്കുന്ന താഴെയുള്ള ലളിതമായ ഇന്റർഫേസ് നോക്കുക:

```py
import requests
import tensorflow as tf

import gradio as gr

inception_net = tf.keras.applications.MobileNetV2()  # load the model

# Download human-readable labels for ImageNet.
response = requests.get("https://git.io/JJkYN")
labels = response.text.split("\n")


def classify_image(inp):
    inp = inp.reshape((-1, 224, 224, 3))
    inp = tf.keras.applications.mobilenet_v2.preprocess_input(inp)
    prediction = inception_net.predict(inp).flatten()
    return {labels[i]: float(prediction[i]) for i in range(1000)}


image = gr.Image(shape=(224, 224))
label = gr.Label(num_top_classes=3)

title = "Gradio Image Classifiction + Interpretation Example"
gr.Interface(
    fn=classify_image, inputs=image, outputs=label, interpretation="default", title=title
).launch()
```

ഒരു ഇൻപുട്ട് സബ്‌മിറ്റ് ചെയ്ത ശേഷം, ഔട്ട്‌പുട്ട് കോംപോണന്റിന്റെ താഴെയുള്ള Interpret ക്ലിക്ക് ചെയ്ത് ഇന്റർപ്രെറ്റേഷൻ ഫംഗ്‌ഷൻ പരീക്ഷിക്കുക.

Gradio നൽകുന്ന ഡിഫോൾട്ട് ഇന്റർപ്രെറ്റേഷൻ രീതിക്കു പുറമേ, `interpretation` പാരാമീറ്ററിനായി `shap` എന്ന് വ്യക്തമാക്കുകയും `num_shap` പാരാമീറ്റർ സെറ്റ് ചെയ്യുകയും ചെയ്യാം. ഇത് Shapley അധിഷ്ഠിത ഇന്റർപ്രെറ്റേഷൻ ഉപയോഗിക്കുന്നു; അതിനെക്കുറിച്ച് കൂടുതൽ [ഇവിടെ](https://christophm.github.io/interpretable-ml-book/shap.html) വായിക്കാം.
അവസാനമായി, നിങ്ങളുടെ സ്വന്തം ഇന്റർപ്രെറ്റേഷൻ ഫംഗ്‌ഷനും `interpretation` പാരാമീറ്ററിലേക്ക് കൈമാറാം. Gradio-യുടെ getting started പേജിൽ [ഇവിടെ](https://gradio.app/getting_started/) ഒരു ഉദാഹരണം കാണുക.

ഇതോടെ Gradio-യുടെ `Interface` ക്ലാസിലേക്കുള്ള നമ്മുടെ ആഴത്തിലുള്ള പരിശോധന അവസാനിക്കുന്നു. നമ്മൾ കണ്ടതുപോലെ, കുറച്ച് വരി Python കോഡിൽ മെഷീൻ ലേണിംഗ് ഡെമോകൾ ഉണ്ടാക്കുന്നത് ഈ ക്ലാസ് ലളിതമാക്കുന്നു. എന്നിരുന്നാലും, ചിലപ്പോൾ ലേഔട്ട് മാറ്റിയോ ഒന്നിലധികം പ്രവചന ഫംഗ്‌ഷനുകൾ ഒന്നിനു പിന്നാലെ ഒന്നായി ചേർത്തോ (chaining) നിങ്ങളുടെ ഡെമോ ഇഷ്ടാനുസൃതമാക്കാൻ നിങ്ങൾ ആഗ്രഹിക്കും. `Interface`-നെ ഏതെങ്കിലും വിധത്തിൽ ഇഷ്ടാനുസൃതമാക്കാവുന്ന "ബ്ലോക്കുകളായി" വിഭജിക്കാൻ കഴിഞ്ഞിരുന്നെങ്കിൽ നന്നായിരുന്നില്ലേ? ഭാഗ്യവശാൽ, അതിനു വഴിയുണ്ട്! അതാണ് അവസാന ഭാഗത്തിന്റെ വിഷയം.
