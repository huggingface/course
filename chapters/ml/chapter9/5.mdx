നിങ്ങളുടെ ജീവിതം ഇനിയും എളുപ്പമാക്കാൻ, Gradio Hugging Face Hub-മായും Hugging Face Spaces-മായും നേരിട്ട് ഇന്റഗ്രേറ്റ് ചെയ്യുന്നു.
വെറും *ഒരു വരി കോഡ്* ഉപയോഗിച്ച് Hub-ൽ നിന്നും Spaces-ൽ നിന്നും ഡെമോകൾ ലോഡ് ചെയ്യാം.

### Hugging Face Hub-ൽ നിന്ന് മോഡലുകൾ ലോഡ് ചെയ്യുന്നു[[loading-models-from-the-hugging-face-hub]]
തുടക്കമായി, [അധ്യായം 4](/course/chapter4/2)-ൽ വിവരിച്ചതുപോലെ, Hub-ലൂടെ Hugging Face നൽകുന്ന ആയിരക്കണക്കിന് മോഡലുകളിൽ ഒന്ന് തിരഞ്ഞെടുക്കുക.

പ്രത്യേകമായ `Interface.load()` മെത്തേഡ് ഉപയോഗിച്ച്, `"model/"` (അല്ലെങ്കിൽ, അതിനു തുല്യമായ `"huggingface/"`) 
എന്നതിനു പിന്നാലെ മോഡലിന്റെ പേര് നിങ്ങൾ കൈമാറുന്നു. 
ഉദാഹരണത്തിന്, ഒരു വലിയ ലാംഗ്വേജ് മോഡലായ [GPT-J](https://huggingface.co/EleutherAI/gpt-j-6B)-യ്ക്ക് ഒരു ഡെമോ നിർമ്മിക്കാനും, രണ്ട് ഉദാഹരണ ഇൻപുട്ടുകൾ ചേർക്കാനുമുള്ള കോഡ് ഇതാ:

```py
import gradio as gr

title = "GPT-J-6B"
description = "Gradio Demo for GPT-J 6B, a transformer model trained using Ben Wang's Mesh Transformer JAX. 'GPT-J' refers to the class of model, while '6B' represents the number of trainable parameters. To use it, simply add your text, or click one of the examples to load them. Read more at the links below."
article = "<p style='text-align: center'><a href='https://github.com/kingoflolz/mesh-transformer-jax' target='_blank'>GPT-J-6B: A 6 Billion Parameter Autoregressive Language Model</a></p>"

gr.Interface.load(
    "huggingface/EleutherAI/gpt-j-6B",
    inputs=gr.Textbox(lines=5, label="Input Text"),
    title=title,
    description=description,
    article=article,
).launch()
```
    
മുകളിലുള്ള കോഡ് താഴെയുള്ള ഇന്റർഫേസ് ഉണ്ടാക്കും:

ഈ രീതിയിൽ ഒരു മോഡൽ ലോഡ് ചെയ്യുമ്പോൾ, മോഡൽ മെമ്മറിയിൽ ലോഡ് ചെയ്യുന്നതിനു പകരം, Hugging Face-ന്റെ [Inference API](https://huggingface.co/inference-api)
ഉപയോഗിക്കുന്നു. ഒരുപാട് RAM ആവശ്യമുള്ള GPT-J അല്ലെങ്കിൽ T0pp പോലുള്ള
 വലിയ മോഡലുകൾക്ക് ഇത് ഏറ്റവും അനുയോജ്യമാണ്.

### Hugging Face Spaces-ൽ നിന്ന് ലോഡ് ചെയ്യുന്നു[[loading-from-hugging-face-spaces]]
Hugging Face Hub-ൽ നിന്ന് ഏതെങ്കിലും Space ലോഡ് ചെയ്ത് ലോക്കലായി പുനഃസൃഷ്ടിക്കാൻ, `spaces/` എന്നതിനു പിന്നാലെ Space-ന്റെ പേര് ചേർത്ത് `Interface`-ലേക്ക് കൈമാറാം.

ഒരു ചിത്രത്തിന്റെ പശ്ചാത്തലം നീക്കം ചെയ്യുന്ന, ഒന്നാം ഭാഗത്തിലെ ഡെമോ ഓർമ്മയുണ്ടോ? അത് Hugging Face Spaces-ൽ നിന്ന് ലോഡ് ചെയ്യാം:

```py
gr.Interface.load("spaces/abidlabs/remove-bg").launch()
```

Hub-ൽ നിന്നോ Spaces-ൽ നിന്നോ ഡെമോകൾ ലോഡ് ചെയ്യുന്നതിന്റെ ഒരു രസകരമായ കാര്യം, ഏതെങ്കിലും 
പാരാമീറ്റർ ഓവർറൈഡ് ചെയ്തുകൊണ്ട് 
അവ ഇഷ്ടാനുസൃതമാക്കാം എന്നതാണ്. ഇവിടെ, ഒരു തലക്കെട്ട് ചേർക്കുകയും, പകരം ഒരു വെബ്‌ക്യാമുമായി പ്രവർത്തിക്കാൻ അതിനെ സജ്ജമാക്കുകയും ചെയ്യുന്നു:

```py
gr.Interface.load(
    "spaces/abidlabs/remove-bg", inputs="webcam", title="Remove your webcam background!"
).launch()
```

Gradio-യെ Hugging Face Hub-മായി ഇന്റഗ്രേറ്റ് ചെയ്യാനുള്ള ചില വഴികൾ നമ്മൾ പരിശോധിച്ചു കഴിഞ്ഞു; ഇനി `Interface` ക്ലാസിന്റെ ചില അഡ്വാൻസ്‌ഡ് ഫീച്ചറുകൾ നോക്കാം. അതാണ് അടുത്ത ഭാഗത്തിന്റെ വിഷയം!
