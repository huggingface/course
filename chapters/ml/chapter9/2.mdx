Gradio ഇൻസ്റ്റാൾ ചെയ്തുകൊണ്ട് തുടങ്ങാം! ഇത് ഒരു Python പാക്കേജായതിനാൽ, ഇത്രമാത്രം റൺ ചെയ്താൽ മതി:

`$ pip install gradio `

നിങ്ങളുടെ ഇഷ്ട Python IDE-യിൽ ആയാലും, Jupyter നോട്ട്‌ബുക്കുകളിൽ ആയാലും, എന്തിന് Google Colab-ൽ പോലും 🤯, എവിടെയും Gradio റൺ ചെയ്യാം!
അതുകൊണ്ട് നിങ്ങൾ Python റൺ ചെയ്യുന്നിടത്ത് Gradio ഇൻസ്റ്റാൾ ചെയ്യുക!

Gradio-യുടെ സിന്റാക്‌സുമായി പരിചയപ്പെടാൻ ഒരു ലളിതമായ “Hello World” ഉദാഹരണത്തോടെ തുടങ്ങാം:

```py
import gradio as gr


def greet(name):
    return "Hello " + name


demo = gr.Interface(fn=greet, inputs="text", outputs="text")

demo.launch()
```

മുകളിലുള്ള കോഡ് ഒന്ന് വിശദമായി നോക്കാം:

- ആദ്യം, `greet()` എന്ന ഒരു ഫംഗ്‌ഷൻ നമ്മൾ നിർവചിക്കുന്നു. ഇവിടെ അത് നിങ്ങളുടെ പേരിനു മുന്നിൽ "Hello" ചേർക്കുന്ന ഒരു ലളിതമായ ഫംഗ്‌ഷനാണ്, പക്ഷേ പൊതുവേ അത് *ഏത്* Python ഫംഗ്‌ഷനും ആകാം. ഉദാഹരണത്തിന്, മെഷീൻ ലേണിംഗ് ആപ്ലിക്കേഷനുകളിൽ, ഈ ഫംഗ്‌ഷൻ ഒരു ഇൻപുട്ടിൽ *പ്രവചനം നടത്താൻ ഒരു മോഡലിനെ വിളിക്കുകയും* ഔട്ട്‌പുട്ട് തിരികെ നൽകുകയും ചെയ്യും.
- പിന്നീട്, `fn`, `inputs`, `outputs` എന്നീ മൂന്ന് ആർഗ്യുമെന്റുകളോടെ ഒരു Gradio `Interface` നമ്മൾ ഉണ്ടാക്കുന്നു. ഈ ആർഗ്യുമെന്റുകൾ പ്രവചന ഫംഗ്‌ഷനും, നമുക്ക് വേണ്ട ഇൻപുട്ട്, ഔട്ട്‌പുട്ട് കോംപോണന്റുകളുടെ _തരവും_ നിർവചിക്കുന്നു. നമ്മുടെ കാര്യത്തിൽ, രണ്ട് കോംപോണന്റുകളും ലളിതമായ ടെക്‌സ്‌റ്റ് ബോക്‌സുകളാണ്.
- തുടർന്ന് നമ്മൾ ഉണ്ടാക്കിയ `Interface`-ൽ `launch()` മെത്തേഡ് വിളിക്കുന്നു.

ഈ കോഡ് റൺ ചെയ്താൽ, താഴെയുള്ള ഇന്റർഫേസ് ഒരു Jupyter/Colab നോട്ട്‌ബുക്കിനുള്ളിൽ സ്വയമേവ പ്രത്യക്ഷപ്പെടും; ഒരു സ്‌ക്രിപ്‌റ്റിൽ നിന്നാണ് റൺ ചെയ്യുന്നതെങ്കിൽ **[http://localhost:7860](http://localhost:7860/)**-ൽ ഒരു ബ്രൗസറിൽ തുറന്നുവരും.

നിങ്ങളുടെ സ്വന്തം പേരോ മറ്റെന്തെങ്കിലും ഇൻപുട്ടോ നൽകി ഈ GUI ഇപ്പോൾ തന്നെ ഉപയോഗിച്ചു നോക്കൂ!

ഈ GUI-യിൽ, ഇൻപുട്ട് പാരാമീറ്ററിന്റെ പേര് (`name`) Gradio സ്വയമേവ മനസ്സിലാക്കി
ടെക്‌സ്‌റ്റ്‌ബോക്‌സിന്റെ മുകളിൽ ഒരു ലേബലായി ചേർത്തതായി നിങ്ങൾ ശ്രദ്ധിക്കും. അത് മാറ്റണമെങ്കിൽ എന്തു ചെയ്യും?
അല്ലെങ്കിൽ ടെക്‌സ്‌റ്റ്‌ബോക്‌സ് മറ്റേതെങ്കിലും വിധത്തിൽ ഇഷ്ടാനുസൃതമാക്കണമെങ്കിൽ? അങ്ങനെയെങ്കിൽ, ഇൻപുട്ട് കോംപോണന്റിനെ
പ്രതിനിധീകരിക്കുന്ന ഒരു ക്ലാസ് ഒബ്‌ജക്റ്റ് നിങ്ങൾക്ക് ഇൻസ്റ്റാൻഷിയേറ്റ് ചെയ്യാം.

താഴെയുള്ള ഉദാഹരണം നോക്കുക:

```py
import gradio as gr


def greet(name):
    return "Hello " + name


# We instantiate the Textbox class
textbox = gr.Textbox(label="Type your name here:", placeholder="John Doe", lines=2)

gr.Interface(fn=greet, inputs=textbox, outputs="text").launch()
```

ഇവിടെ, ഒരു ലേബലും, ഒരു പ്ലേസ്‌ഹോൾഡറും, നിശ്ചിത എണ്ണം വരികളും ഉള്ള ഒരു ഇൻപുട്ട് ടെക്‌സ്‌റ്റ്‌ബോക്‌സ് നമ്മൾ ഉണ്ടാക്കി.
ഔട്ട്‌പുട്ട് ടെക്‌സ്‌റ്റ്‌ബോക്‌സിനും ഇതുപോലെ ചെയ്യാം, പക്ഷേ അത് ഇപ്പോൾ നമുക്ക് വിടാം.

വെറും കുറച്ച് വരി കോഡുകൊണ്ട്, ഏതു തരം ഇൻപുട്ടുകളോ ഔട്ട്‌പുട്ടുകളോ ഉള്ള ഏത് ഫംഗ്‌ഷനു ചുറ്റും
ഒരു ലളിതമായ ഇന്റർഫേസ് ഉണ്ടാക്കാൻ Gradio നിങ്ങളെ അനുവദിക്കുന്നു എന്ന് നമ്മൾ കണ്ടു. ഈ ഭാഗത്തിൽ, ഒരു
ലളിതമായ ടെക്‌സ്‌റ്റ്‌ബോക്‌സിൽ നിന്നാണ് നമ്മൾ തുടങ്ങിയത്, പക്ഷേ അടുത്ത ഭാഗങ്ങളിൽ മറ്റു തരം ഇൻപുട്ടുകളും ഔട്ട്‌പുട്ടുകളും നമ്മൾ പരിശോധിക്കും. ഇനി ഒരു Gradio ആപ്ലിക്കേഷനിൽ കുറച്ച് NLP ഉൾപ്പെടുത്തുന്നത് നോക്കാം.


## 🤖 മോഡൽ പ്രവചനങ്ങൾ ഉൾപ്പെടുത്തുന്നു[[including-model-predictions]]

ഇനി GPT-2 പോലുള്ള ഒരു **ടെക്‌സ്‌റ്റ്-ജനറേഷൻ** മോഡൽ ഡെമോ ചെയ്യാൻ അനുവദിക്കുന്ന ഒരു ലളിതമായ ഇന്റർഫേസ് നിർമ്മിക്കാം.

🤗 Transformers-ലെ `pipeline()` ഫംഗ്‌ഷൻ ഉപയോഗിച്ച് നമ്മുടെ മോഡൽ ലോഡ് ചെയ്യും.
ഒന്ന് പെട്ടെന്ന് ഓർമ്മ പുതുക്കണമെങ്കിൽ, [അധ്യായം 1-ലെ ആ ഭാഗത്തേക്ക്](/course/chapter1/3#text-generation) തിരികെ പോകാം.

ആദ്യം, ഒരു ടെക്‌സ്‌റ്റ് പ്രോംപ്‌റ്റ് എടുത്ത് ടെക്‌സ്‌റ്റ് പൂർത്തീകരണം (completion) തിരികെ നൽകുന്ന ഒരു പ്രവചന ഫംഗ്‌ഷൻ നമ്മൾ നിർവചിക്കുന്നു:

```py
from transformers import pipeline

model = pipeline("text-generation")


def predict(prompt):
    completion = model(prompt)[0]["generated_text"]
    return completion
```

നിങ്ങൾ നൽകുന്ന പ്രോംപ്‌റ്റുകൾ ഈ ഫംഗ്‌ഷൻ പൂർത്തിയാക്കുന്നു; ഇത് എങ്ങനെ പ്രവർത്തിക്കുന്നു എന്ന് കാണാൻ നിങ്ങളുടെ സ്വന്തം ഇൻപുട്ട് പ്രോംപ്‌റ്റുകൾ നൽകി ഇത് റൺ ചെയ്യാം. ഒരു ഉദാഹരണം ഇതാ (നിങ്ങൾക്ക് വ്യത്യസ്തമായ ഒരു പൂർത്തീകരണം ലഭിക്കാം):

```
predict("My favorite programming language is")
```

```
>> My favorite programming language is Haskell. I really enjoyed the Haskell language, but it doesn't have all the features that can be applied to any other language. For example, all it does is compile to a byte array.
```

പ്രവചനങ്ങൾ ഉണ്ടാക്കാനുള്ള ഒരു ഫംഗ്‌ഷൻ ഇപ്പോൾ നമുക്കുള്ളതിനാൽ, മുമ്പ് ചെയ്തതുപോലെ തന്നെ ഒരു `Interface` ഉണ്ടാക്കി ലോഞ്ച് ചെയ്യാം:

```py
import gradio as gr

gr.Interface(fn=predict, inputs="text", outputs="text").launch()
```
