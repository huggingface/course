നിങ്ങൾ പ്രവർത്തിക്കുന്ന NLP ടാസ്‌കും പ്രത്യേക ഉപയോഗ സന്ദർഭവും (use case) ആപ്ലിക്കേഷനും അനുസരിച്ച്, നിങ്ങളുടെ ഡേറ്റയും അനോട്ടേഷൻ ടാസ്‌കും വ്യത്യസ്തമായി കാണപ്പെടും. കോഴ്‌സിന്റെ ഈ ഭാഗത്ത്, രണ്ട് ടാസ്‌കുകൾ പൂർത്തിയാക്കാൻ നമ്മൾ [വാർത്തകൾ ശേഖരിച്ച ഒരു ഡേറ്റാസെറ്റ്](https://huggingface.co/datasets/SetFit/ag_news) ഉപയോഗിക്കും: ഓരോ ടെക്‌സ്‌റ്റിന്റെയും വിഷയം അടിസ്ഥാനമാക്കിയുള്ള ഒരു ടെക്‌സ്‌റ്റ് ക്ലാസിഫിക്കേഷനും, പരാമർശിക്കപ്പെട്ട നെയിംഡ് എന്റിറ്റികൾ (named entities) തിരിച്ചറിയാനുള്ള ഒരു ടോക്കൺ ക്ലാസിഫിക്കേഷനും.

Argilla UI ഉപയോഗിച്ച് നേരിട്ട് Hub-ൽനിന്ന് ഡേറ്റാസെറ്റുകൾ ഇംപോർട്ട് ചെയ്യാൻ സാധിക്കും, എന്നാൽ ആവശ്യമെങ്കിൽ ഡേറ്റയിൽ കൂടുതൽ മാറ്റങ്ങൾ എങ്ങനെ വരുത്താമെന്ന് പഠിക്കാൻ നമ്മൾ SDK ഉപയോഗിക്കും.

## നിങ്ങളുടെ ഡേറ്റാസെറ്റ് കോൺഫിഗർ ചെയ്യുക

ആദ്യ ഘട്ടം, മുൻ വിഭാഗത്തിൽ ചെയ്തതുപോലെ നമ്മുടെ Argilla ഇൻസ്‌റ്റൻസുമായി കണക്റ്റ് ചെയ്യുകയാണ്:

```python
import argilla as rg

HF_TOKEN = "..."  # only for private spaces

client = rg.Argilla(
    api_url="...",
    api_key="...",
    headers={"Authorization": f"Bearer {HF_TOKEN}"},  # only for private spaces
)
```

ഇപ്പോൾ Argilla-യിലെ നമ്മുടെ ഡേറ്റാസെറ്റിന്റെ സെറ്റിംഗ്‌സിനെക്കുറിച്ച് ചിന്തിക്കാം. നമ്മുടെ ഡേറ്റയിൽ നമ്മൾ ചെയ്യാൻ പോകുന്ന അനോട്ടേഷൻ ടാസ്‌കിനെയാണ് ഇവ പ്രതിനിധീകരിക്കുന്നത്. ആദ്യം, ഡേറ്റാസെറ്റ് ശരിയായി കോൺഫിഗർ ചെയ്യുന്നുവെന്ന് ഉറപ്പാക്കാൻ, Hub-ൽനിന്ന് ഡേറ്റാസെറ്റ് ലോഡ് ചെയ്ത് അതിന്റെ ഫീച്ചറുകൾ പരിശോധിക്കാം.

```python
from datasets import load_dataset

data = load_dataset("SetFit/ag_news", split="train")
data.features
```

ഇവയാണ് നമ്മുടെ ഡേറ്റാസെറ്റിന്റെ ഫീച്ചറുകൾ:

```python out
{'text': Value(dtype='string', id=None),
 'label': Value(dtype='int64', id=None),
 'label_text': Value(dtype='string', id=None)}
```

അതിൽ ഒരു `text`-ഉം, ടെക്‌സ്‌റ്റ് ക്ലാസിഫിക്കേഷനുള്ള ചില പ്രാരംഭ ലേബലുകളും അടങ്ങിയിരിക്കുന്നു. നെയിംഡ് എന്റിറ്റികൾക്കായുള്ള ഒരു `spans` ചോദ്യത്തോടൊപ്പം ഇവ നമ്മൾ ഡേറ്റാസെറ്റ് സെറ്റിംഗ്‌സിൽ ചേർക്കും:

```python
settings = rg.Settings(
    fields=[rg.TextField(name="text")],
    questions=[
        rg.LabelQuestion(
            name="label", title="Classify the text:", labels=data.unique("label_text")
        ),
        rg.SpanQuestion(
            name="entities",
            title="Highlight all the entities in the text:",
            labels=["PERSON", "ORG", "LOC", "EVENT"],
            field="text",
        ),
    ],
)
```

ഈ സെറ്റിംഗ്‌സ് എന്താണ് അർത്ഥമാക്കുന്നത് എന്ന് കുറച്ചുകൂടി ആഴത്തിൽ നോക്കാം. ആദ്യം, നമ്മൾ **fields** നിർവചിച്ചു; നമ്മൾ അനോട്ടേറ്റ് ചെയ്യാൻ പോകുന്ന വിവരങ്ങൾ ഇവയിൽ ഉൾപ്പെടുന്നു. ഈ സന്ദർഭത്തിൽ, നമുക്ക് ഒരു ഫീൽഡ് മാത്രമേയുള്ളൂ, അത് ഒരു ടെക്‌സ്‌റ്റിന്റെ രൂപത്തിലാണ്; അതിനാൽ നമ്മൾ ഒരു `TextField` തിരഞ്ഞെടുത്തു.

തുടർന്ന്, നമ്മുടെ ഡേറ്റയിൽ ചെയ്യാൻ ആഗ്രഹിക്കുന്ന ടാസ്‌കുകളെ പ്രതിനിധീകരിക്കുന്ന **questions** നമ്മൾ നിർവചിക്കുന്നു:

- ടെക്‌സ്‌റ്റ് ക്ലാസിഫിക്കേഷൻ ടാസ്‌കിനായി നമ്മൾ ഒരു `LabelQuestion` തിരഞ്ഞെടുത്തു, ഡേറ്റാസെറ്റിൽ ഇതിനകം നിലവിലുള്ള ലേബലുകളുമായി ചോദ്യം പൊരുത്തപ്പെടുന്നുവെന്ന് ഉറപ്പാക്കാൻ `label_text` കോളത്തിലെ അനന്യമായ (unique) മൂല്യങ്ങളെ നമ്മുടെ ലേബലുകളായി ഉപയോഗിച്ചു.
- ടോക്കൺ ക്ലാസിഫിക്കേഷൻ ടാസ്‌കിനായി നമുക്ക് ഒരു `SpanQuestion` ആവശ്യമാണ്. ആ ടാസ്‌കിനായി ഉപയോഗിക്കുന്ന ഒരു കൂട്ടം ലേബലുകളും, സ്‌പാനുകൾ (spans) അടയാളപ്പെടുത്തേണ്ട ഫീൽഡും നമ്മൾ നിർവചിച്ചു.

ലഭ്യമായ എല്ലാത്തരം ഫീൽഡുകളെയും ചോദ്യങ്ങളെയും കുറിച്ചും, മെറ്റാഡേറ്റ, വെക്റ്ററുകൾ എന്നിവ പോലുള്ള മറ്റ് അഡ്വാൻസ്‌ഡ് സെറ്റിംഗ്‌സിനെക്കുറിച്ചും കൂടുതൽ അറിയാൻ, [Argilla docs](https://docs.argilla.io/latest/how_to_guides/dataset/#define-dataset-settings) സന്ദർശിക്കുക.

## ഡേറ്റാസെറ്റ് അപ്‌ലോഡ് ചെയ്യുക

ഇപ്പോൾ നമ്മൾ ചില സെറ്റിംഗ്‌സ് നിർവചിച്ചതിനാൽ, ഡേറ്റാസെറ്റ് സൃഷ്ടിക്കാം:

```python
dataset = rg.Dataset(name="ag_news", settings=settings)

dataset.create()
```

ഡേറ്റാസെറ്റ് ഇപ്പോൾ നമ്മുടെ Argilla ഇൻസ്‌റ്റൻസിൽ കാണാം, എന്നാൽ അത് ശൂന്യമാണെന്ന് നിങ്ങൾ കാണും:

ഇപ്പോൾ നമ്മൾ അനോട്ടേറ്റ് ചെയ്യാൻ പോകുന്ന റെക്കോർഡുകൾ, അതായത് നമ്മുടെ ഡേറ്റാസെറ്റിലെ വരികൾ, ചേർക്കേണ്ടതുണ്ട്. അതിനായി, ഡേറ്റ റെക്കോർഡുകളായി ലോഗ് ചെയ്യുകയും, Hub ഡേറ്റാസെറ്റിലും Argilla ഡേറ്റാസെറ്റിലും ഒരേ പേരില്ലാത്ത ഘടകങ്ങൾക്ക് ഒരു മാപ്പിംഗ് നൽകുകയും ചെയ്താൽ മതി:

```python
dataset.records.log(data, mapping={"label_text": "label"})
```

നമ്മുടെ മാപ്പിംഗിൽ, ഡേറ്റാസെറ്റിലെ `label_text` കോളം `label` എന്ന പേരുള്ള ചോദ്യത്തിലേക്ക് മാപ്പ് ചെയ്യണമെന്ന് നമ്മൾ വ്യക്തമാക്കി. ഇങ്ങനെ, ഡേറ്റാസെറ്റിൽ നിലവിലുള്ള ലേബലുകൾ പ്രീ-അനോട്ടേഷനുകളായി ഉപയോഗിക്കുന്നതിലൂടെ നമുക്ക് വേഗത്തിൽ അനോട്ടേറ്റ് ചെയ്യാൻ കഴിയും.

റെക്കോർഡുകൾ ലോഗ് ചെയ്യുന്നത് തുടരുമ്പോൾ തന്നെ, Argilla UI-യിൽ നിങ്ങളുടെ ഡേറ്റാസെറ്റുമായി പ്രവർത്തിക്കാൻ തുടങ്ങാം. ഈ ഘട്ടത്തിൽ, അത് ഇങ്ങനെ കാണപ്പെടണം:
