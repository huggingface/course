Argilla ഉപയോഗിക്കാൻ തുടങ്ങുന്നതിന്, ആദ്യം നിങ്ങൾ സ്വന്തമായി ഒരു Argilla ഇൻസ്‌റ്റൻസ് സജ്ജീകരിക്കേണ്ടതുണ്ട്. തുടർന്ന്, Python കോഡ് ഉപയോഗിച്ച് Argilla കൈകാര്യം ചെയ്യാൻ കഴിയുന്ന വിധത്തിൽ Python SDK ഇൻസ്‌റ്റാൾ ചെയ്യേണ്ടതുണ്ട്.

## Argilla UI ഡിപ്ലോയ് ചെയ്യുക

നിങ്ങളുടെ Argilla ഇൻസ്‌റ്റൻസ് സജ്ജീകരിക്കാനുള്ള ഏറ്റവും എളുപ്പമുള്ള മാർഗം Hugging Face Spaces വഴിയാണ്. നിങ്ങളുടെ Argilla Space സൃഷ്ടിക്കാൻ, [ഈ ഫോം](https://huggingface.co/new-space?template=argilla%2Fargilla-template-space) പിന്തുടർന്നാൽ മതി. കൂടുതൽ മാർഗനിർദേശം ആവശ്യമെങ്കിൽ, [Argilla quickstart](https://docs.argilla.io/latest/getting_started/quickstart/) പരിശോധിക്കുക.

> ⚠️ Space താൽക്കാലികമായി നിർത്തുകയോ (pause) പുനരാരംഭിക്കുകയോ ചെയ്താൽ ഡേറ്റ നഷ്ടപ്പെടാതിരിക്കാൻ **Persistent storage** പ്രവർത്തനക്ഷമമാക്കുന്നത് നല്ലതാണ്.

Argilla പ്രവർത്തനസജ്ജമായിക്കഴിഞ്ഞാൽ, നിങ്ങളുടെ ക്രെഡൻഷ്യലുകൾ ഉപയോഗിച്ച് ലോഗിൻ ചെയ്യാം.

## Python SDK ഇൻസ്‌റ്റാൾ ചെയ്ത് കണക്റ്റ് ചെയ്യുക

ഇപ്പോൾ നിങ്ങളുടെ Python എൻവയോൺമെന്റിലേക്കോ നോട്ട്‌ബുക്കിലേക്കോ പോയി argilla ലൈബ്രറി ഇൻസ്‌റ്റാൾ ചെയ്യാം:

`!pip install argilla`

നമ്മുടെ Argilla ഇൻസ്‌റ്റൻസുമായി കണക്റ്റ് ചെയ്യാം. അതിനായി നിങ്ങൾക്ക് താഴെപ്പറയുന്ന വിവരങ്ങൾ ആവശ്യമാണ്:

- **നിങ്ങളുടെ API URL**: Argilla പ്രവർത്തിക്കുന്ന URL ആണിത്. നിങ്ങൾ ഒരു Space ഉപയോഗിക്കുന്നുണ്ടെങ്കിൽ, Space തുറന്ന്, മുകളിൽ വലതുവശത്തെ മൂന്ന് കുത്തുകളിൽ ക്ലിക്ക് ചെയ്ത്, തുടർന്ന് "Embed this Space" തിരഞ്ഞെടുത്ത് **Direct URL** കോപ്പി ചെയ്യാം. അത് ഏകദേശം `https://<your-username>.<space-name>.hf.space` എന്നപോലെ കാണപ്പെടും.
- **നിങ്ങളുടെ API key**: നിങ്ങളുടെ key ലഭിക്കാൻ, Argilla ഇൻസ്‌റ്റൻസിൽ ലോഗിൻ ചെയ്ത് "My Settings"-ലേക്ക് പോയി API key കോപ്പി ചെയ്യുക.
- **നിങ്ങളുടെ HF token**: നിങ്ങളുടെ Space പ്രൈവറ്റ് ആണെങ്കിൽ, നിങ്ങളുടെ Hugging Face Hub അക്കൗണ്ടിൽ എഴുതാനുള്ള അനുമതിയോടുകൂടിയ (write permissions) ഒരു Access Token ആവശ്യമായി വരും.

```python
import argilla as rg

HF_TOKEN = "..."  # only for private spaces

client = rg.Argilla(
    api_url="...",
    api_key="...",
    headers={"Authorization": f"Bearer {HF_TOKEN}"},  # only for private spaces
)
```

എല്ലാം ശരിയായി പ്രവർത്തിക്കുന്നുണ്ടോ എന്ന് പരിശോധിക്കാൻ, നമ്മൾ `me` വിളിക്കും. ഇത് നമ്മുടെ ഉപയോക്താവിനെ (user) തിരികെ നൽകണം:

```python
client.me
```

ഇത് പ്രവർത്തിച്ചെങ്കിൽ, നിങ്ങളുടെ Argilla ഇൻസ്‌റ്റൻസ് പ്രവർത്തനസജ്ജമാണ്, നിങ്ങൾ അതിലേക്ക് കണക്റ്റ് ചെയ്തിരിക്കുന്നു! അഭിനന്ദനങ്ങൾ!

ഇനി നമുക്ക് നമ്മുടെ ആദ്യ ഡേറ്റാസെറ്റ് Argilla-യിലേക്ക് ലോഡ് ചെയ്യാൻ തുടങ്ങാം.
