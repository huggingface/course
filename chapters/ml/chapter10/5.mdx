Argilla-യിൽ നമുക്കുള്ള അനോട്ടേറ്റ് ചെയ്ത ഡേറ്റ എങ്ങനെ എക്‌സ്‌പോർട്ട് ചെയ്ത് ഉപയോഗിക്കാമെന്ന് ഇപ്പോൾ നമ്മൾ പഠിക്കും.

## ഡേറ്റാസെറ്റ് ലോഡ് ചെയ്യുക

ആദ്യം, മുൻ ഘട്ടങ്ങളിലേതുപോലെ നമ്മൾ നമ്മുടെ Argilla ഇൻസ്‌റ്റൻസുമായി കണക്റ്റ് ചെയ്തിട്ടുണ്ടെന്ന് ഉറപ്പാക്കേണ്ടതുണ്ട്:

```python
import argilla as rg

HF_TOKEN = "..."  # only for private spaces

client = rg.Argilla(
    api_url="...",
    api_key="...",
    headers={"Authorization": f"Bearer {HF_TOKEN}"},  # only for private spaces
)
```

ഇപ്പോൾ, നമ്മൾ പ്രവർത്തിക്കാൻ പോകുന്ന ഡേറ്റാസെറ്റ് ലോഡ് ചെയ്യാം:

```python
dataset = client.datasets(name="ag_news")
```

ഡേറ്റാസെറ്റ് ലോഡ് ചെയ്ത് `dataset.records` ഉപയോഗിച്ച് അതിന്റെ റെക്കോർഡുകൾ വിളിക്കുന്നത്, നിങ്ങളുടെ സ്വന്തം ആവശ്യങ്ങൾക്കും പൈപ്പ്‌ലൈനുകൾക്കുമായി ഡേറ്റാസെറ്റും റെക്കോർഡുകളും ഉപയോഗിക്കാൻ തുടങ്ങാൻ മതിയാകും. എന്നിരുന്നാലും, റെക്കോർഡുകൾ ഫിൽറ്റർ ചെയ്യുക, നിങ്ങളുടെ ഡേറ്റാസെറ്റ് Hugging Face Hub-ലേക്ക് എക്‌സ്‌പോർട്ട് ചെയ്യുക എന്നിവ പോലുള്ള ചില ഓപ്‌ഷണൽ പ്രവർത്തനങ്ങൾ എങ്ങനെ ചെയ്യാമെന്നും നമ്മൾ പഠിക്കും.

## ഡേറ്റാസെറ്റ് ഫിൽറ്റർ ചെയ്യുക

ചിലപ്പോൾ പൂർത്തിയാക്കിയ റെക്കോർഡുകൾ മാത്രം ഉപയോഗിക്കാൻ നിങ്ങൾ ആഗ്രഹിച്ചേക്കാം; അതിനാൽ ആദ്യം നമ്മുടെ ഡേറ്റാസെറ്റിലെ റെക്കോർഡുകൾ അവയുടെ സ്‌റ്ററ്റസ് അടിസ്ഥാനമാക്കി ഫിൽറ്റർ ചെയ്യാം:

```python
status_filter = rg.Query(filter=rg.Filter([("status", "==", "completed")]))

filtered_records = dataset.records(status_filter)
```

>[!TIP]
>⚠️ `completed` സ്‌റ്ററ്റസുള്ള റെക്കോർഡുകൾക്ക് (അതായത്, ടാസ്‌ക് ഡിസ്‌ട്രിബ്യൂഷൻ സെറ്റിംഗ്‌സിൽ കോൺഫിഗർ ചെയ്ത കുറഞ്ഞ സമർപ്പിത പ്രതികരണങ്ങളുടെ എണ്ണം തികഞ്ഞ റെക്കോർഡുകൾ) ഒന്നിലധികം പ്രതികരണങ്ങൾ ഉണ്ടാകാമെന്നും, ഓരോ പ്രതികരണത്തിനും `submitted`, `draft` അല്ലെങ്കിൽ `discarded` എന്നിവയിൽ ഏത് സ്‌റ്ററ്റസും ആകാമെന്നും ശ്രദ്ധിക്കുക.

റെക്കോർഡുകൾ ക്വറി ചെയ്യുന്നതിനെയും ഫിൽറ്റർ ചെയ്യുന്നതിനെയും കുറിച്ച് കൂടുതൽ അറിയാൻ [Argilla docs](https://docs.argilla.io/latest/how_to_guides/query/) കാണുക.

## Hub-ലേക്ക് എക്‌സ്‌പോർട്ട് ചെയ്യുക

ഇപ്പോൾ നമ്മുടെ അനോട്ടേഷനുകൾ മറ്റുള്ളവരുമായി പങ്കുവയ്ക്കാൻ കഴിയുന്ന വിധത്തിൽ Hugging Face Hub-ലേക്ക് എക്‌സ്‌പോർട്ട് ചെയ്യാം. അതിനായി, റെക്കോർഡുകളെ ഒരു 🤗 Dataset-ആക്കി മാറ്റി അത് Hub-ലേക്ക് പുഷ് ചെയ്യേണ്ടതുണ്ട്:

```python
filtered_records.to_datasets().push_to_hub("argilla/ag_news_annotated")
```

പകരമായി, പൂർണ്ണമായ Argilla ഡേറ്റാസെറ്റ് (തീർപ്പാക്കാത്ത റെക്കോർഡുകൾ ഉൾപ്പെടെ) ഇങ്ങനെ നേരിട്ട് എക്‌സ്‌പോർട്ട് ചെയ്യാം:

```python
dataset.to_hub(repo_id="argilla/ag_news_annotated")
```

മറ്റുള്ളവർക്ക് അവരുടെ Argilla ഇൻസ്‌റ്റൻസുകളിൽ ഈ ഡേറ്റാസെറ്റ് തുറക്കാൻ ആഗ്രഹമുണ്ടെങ്കിൽ ഇത് രസകരമായ ഒരു തിരഞ്ഞെടുപ്പാണ്; കാരണം സെറ്റിംഗ്‌സ് സ്വയമേവ സേവ് ചെയ്യപ്പെടുന്നു, അവർക്ക് ഒരൊറ്റ വരി കോഡ് ഉപയോഗിച്ച് പൂർണ്ണ ഡേറ്റാസെറ്റ് ഇംപോർട്ട് ചെയ്യാം:

```python
dataset = rg.Dataset.from_hub(repo_id="argilla/ag_news_annotated")
```
