മുൻ ഭാഗത്തിൽ, ഏറ്റവും ലളിതമായ ഉപയോഗസന്ദർഭം നമ്മൾ പരിശോധിച്ചു: ചെറിയ നീളമുള്ള ഒരൊറ്റ സീക്വൻസിൽ ഇൻഫറൻസ് നടത്തുക. എന്നാൽ, ഇപ്പോൾ തന്നെ ചില ചോദ്യങ്ങൾ ഉയർന്നുവരുന്നു:

- ഒന്നിലധികം സീക്വൻസുകൾ നമ്മൾ എങ്ങനെ കൈകാര്യം ചെയ്യും?
- *വ്യത്യസ്ത നീളമുള്ള* ഒന്നിലധികം സീക്വൻസുകൾ നമ്മൾ എങ്ങനെ കൈകാര്യം ചെയ്യും?
- ഒരു മോഡൽ നന്നായി പ്രവർത്തിക്കാൻ സഹായിക്കുന്ന ഒരേയൊരു ഇൻപുട്ട് വൊക്കാബുലറി ഇൻഡെക്‌സുകൾ മാത്രമാണോ?
- വളരെ നീണ്ട സീക്വൻസ് എന്നൊരു കാര്യമുണ്ടോ?

ഈ ചോദ്യങ്ങൾ ഏതുതരം പ്രശ്നങ്ങളാണ് ഉയർത്തുന്നത് എന്നും, 🤗 Transformers API ഉപയോഗിച്ച് അവ എങ്ങനെ പരിഹരിക്കാം എന്നും നോക്കാം.

## മോഡലുകൾ പ്രതീക്ഷിക്കുന്നത് ഇൻപുട്ടുകളുടെ ഒരു ബാച്ചാണ്[[models-expect-a-batch-of-inputs]]

മുൻ അഭ്യാസത്തിൽ, സീക്വൻസുകൾ എങ്ങനെ സംഖ്യകളുടെ ലിസ്‌റ്റുകളായി മാറ്റപ്പെടുന്നു എന്ന് നിങ്ങൾ കണ്ടു. ഈ സംഖ്യകളുടെ ലിസ്‌റ്റിനെ ഒരു ടെൻസറാക്കി മാറ്റി മോഡലിലേക്ക് അയയ്ക്കാം:

```py
import torch
from transformers import AutoTokenizer, AutoModelForSequenceClassification

checkpoint = "distilbert-base-uncased-finetuned-sst-2-english"
tokenizer = AutoTokenizer.from_pretrained(checkpoint)
model = AutoModelForSequenceClassification.from_pretrained(checkpoint)

sequence = "I've been waiting for a HuggingFace course my whole life."

tokens = tokenizer.tokenize(sequence)
ids = tokenizer.convert_tokens_to_ids(tokens)
input_ids = torch.tensor(ids)
# This line will fail.
model(input_ids)
```

```python out
IndexError: Dimension out of range (expected to be in range of [-1, 0], but got 1)
```

അയ്യോ! ഇത് എന്തുകൊണ്ടാണ് പരാജയപ്പെട്ടത്? ഭാഗം 2-ലെ പൈപ്പ്‌ലൈനിലെ ഘട്ടങ്ങൾ തന്നെയാണല്ലോ നമ്മൾ പിന്തുടർന്നത്.

പ്രശ്നം ഇതാണ്: നമ്മൾ മോഡലിലേക്ക് ഒരൊറ്റ സീക്വൻസ് അയച്ചു, എന്നാൽ 🤗 Transformers മോഡലുകൾ ഡിഫോൾട്ടായി ഒന്നിലധികം വാക്യങ്ങളാണ് പ്രതീക്ഷിക്കുന്നത്. ഒരു `sequence`-ൽ ടോക്കണൈസർ പ്രയോഗിച്ചപ്പോൾ അത് തിരശ്ശീലയ്ക്ക് പിന്നിൽ ചെയ്ത എല്ലാ കാര്യങ്ങളും ഇവിടെ നമ്മൾ സ്വയം ചെയ്യാൻ ശ്രമിച്ചു. എന്നാൽ സൂക്ഷിച്ചുനോക്കിയാൽ, ടോക്കണൈസർ ഇൻപുട്ട് ID-കളുടെ ലിസ്‌റ്റിനെ വെറുതെ ഒരു ടെൻസറാക്കി മാറ്റുക മാത്രമല്ല ചെയ്തത്, അതിന് മുകളിൽ ഒരു ഡൈമെൻഷൻ കൂടി ചേർത്തു എന്ന് നിങ്ങൾ കാണും:

```py
tokenized_inputs = tokenizer(sequence, return_tensors="pt")
print(tokenized_inputs["input_ids"])
```

```python out
tensor([[  101,  1045,  1005,  2310,  2042,  3403,  2005,  1037, 17662, 12172,
          2607,  2026,  2878,  2166,  1012,   102]])
```

ഒരു പുതിയ ഡൈമെൻഷൻ ചേർത്ത് വീണ്ടും ശ്രമിക്കാം:

```py
import torch
from transformers import AutoTokenizer, AutoModelForSequenceClassification

checkpoint = "distilbert-base-uncased-finetuned-sst-2-english"
tokenizer = AutoTokenizer.from_pretrained(checkpoint)
model = AutoModelForSequenceClassification.from_pretrained(checkpoint)

sequence = "I've been waiting for a HuggingFace course my whole life."

tokens = tokenizer.tokenize(sequence)
ids = tokenizer.convert_tokens_to_ids(tokens)

input_ids = torch.tensor([ids])
print("Input IDs:", input_ids)

output = model(input_ids)
print("Logits:", output.logits)
```

ഇൻപുട്ട് ID-കളും അതിന്റെ ഫലമായി ലഭിക്കുന്ന ലോജിറ്റുകളും നമ്മൾ പ്രിന്റ് ചെയ്യുന്നു — ഔട്ട്‌പുട്ട് ഇതാ:

```python out
Input IDs: [[ 1045,  1005,  2310,  2042,  3403,  2005,  1037, 17662, 12172,  2607, 2026,  2878,  2166,  1012]]
Logits: [[-2.7276,  2.8789]]
```

ഒന്നിലധികം വാക്യങ്ങൾ ഒരുമിച്ച്, ഒറ്റയടിക്ക് മോഡലിലൂടെ കടത്തിവിടുന്നതിനെയാണ് *ബാച്ചിംഗ്* (batching) എന്ന് പറയുന്നത്. നിങ്ങൾക്ക് ഒരു വാക്യം മാത്രമേ ഉള്ളൂവെങ്കിൽ, ഒരൊറ്റ സീക്വൻസ് ഉള്ള ഒരു ബാച്ച് ഉണ്ടാക്കിയാൽ മതി: 

```
batched_ids = [ids, ids]
```

ഇത് ഒരേപോലുള്ള രണ്ട് സീക്വൻസുകളുടെ ഒരു ബാച്ചാണ്!

> [!TIP]
> ✏️ **സ്വയം പരീക്ഷിക്കുക!** ഈ `batched_ids` ലിസ്‌റ്റിനെ ഒരു ടെൻസറാക്കി മാറ്റി നിങ്ങളുടെ മോഡലിലൂടെ കടത്തിവിടുക. മുമ്പത്തെ അതേ ലോജിറ്റുകൾ തന്നെയാണ് (പക്ഷേ രണ്ടുതവണ) നിങ്ങൾക്ക് ലഭിക്കുന്നത് എന്ന് ഉറപ്പുവരുത്തുക!

ഒന്നിലധികം വാക്യങ്ങൾ നൽകുമ്പോൾ മോഡൽ പ്രവർത്തിക്കാൻ ബാച്ചിംഗ് സഹായിക്കുന്നു. ഒന്നിലധികം സീക്വൻസുകൾ ഉപയോഗിക്കുന്നത്, ഒരൊറ്റ സീക്വൻസ് ഉള്ള ഒരു ബാച്ച് ഉണ്ടാക്കുന്നതുപോലെ തന്നെ ലളിതമാണ്. എന്നാൽ, രണ്ടാമതൊരു പ്രശ്നമുണ്ട്. രണ്ടോ (അതിലധികമോ) വാക്യങ്ങൾ ഒരുമിച്ച് ബാച്ച് ചെയ്യാൻ ശ്രമിക്കുമ്പോൾ, അവ വ്യത്യസ്ത നീളമുള്ളവയായിരിക്കാം. നിങ്ങൾ മുമ്പ് ടെൻസറുകളുമായി പ്രവർത്തിച്ചിട്ടുണ്ടെങ്കിൽ, അവ ചതുരാകൃതിയിലുള്ളവയായിരിക്കണം (rectangular shape) എന്ന് നിങ്ങൾക്കറിയാം; അതിനാൽ ഇൻപുട്ട് ID-കളുടെ ലിസ്‌റ്റിനെ നേരിട്ട് ഒരു ടെൻസറാക്കി മാറ്റാൻ നിങ്ങൾക്ക് കഴിയില്ല. ഈ പ്രശ്നം മറികടക്കാൻ, സാധാരണയായി നമ്മൾ ഇൻപുട്ടുകളെ *പാഡ്* (pad) ചെയ്യുന്നു.

## ഇൻപുട്ടുകൾ പാഡ് ചെയ്യുന്നു[[padding-the-inputs]]

താഴെയുള്ള ലിസ്‌റ്റുകളുടെ ലിസ്‌റ്റ് ഒരു ടെൻസറാക്കി മാറ്റാൻ കഴിയില്ല:

```py no-format
batched_ids = [
    [200, 200, 200],
    [200, 200]
]
```

ഇത് മറികടക്കാൻ, നമ്മുടെ ടെൻസറുകൾക്ക് ചതുരാകൃതി ലഭിക്കാനായി നമ്മൾ *പാഡിംഗ്* (padding) ഉപയോഗിക്കും. കുറച്ച് മൂല്യങ്ങൾ മാത്രമുള്ള വാക്യങ്ങളിലേക്ക് *പാഡിംഗ് ടോക്കൺ* എന്ന് വിളിക്കുന്ന ഒരു പ്രത്യേക വാക്ക് ചേർത്ത്, നമ്മുടെ എല്ലാ വാക്യങ്ങൾക്കും ഒരേ നീളം ഉണ്ടെന്ന് പാഡിംഗ് ഉറപ്പാക്കുന്നു. ഉദാഹരണത്തിന്, 10 വാക്കുകൾ വീതമുള്ള 10 വാക്യങ്ങളും 20 വാക്കുകളുള്ള 1 വാക്യവും നിങ്ങൾക്കുണ്ടെങ്കിൽ, എല്ലാ വാക്യങ്ങൾക്കും 20 വാക്കുകൾ ഉണ്ടെന്ന് പാഡിംഗ് ഉറപ്പാക്കും. നമ്മുടെ ഉദാഹരണത്തിൽ, ഫലമായി ലഭിക്കുന്ന ടെൻസർ ഇങ്ങനെയിരിക്കും:

```py no-format
padding_id = 100

batched_ids = [
    [200, 200, 200],
    [200, 200, padding_id],
]
```

പാഡിംഗ് ടോക്കണിന്റെ ID `tokenizer.pad_token_id`-ൽ കാണാം. ഇത് ഉപയോഗിച്ച്, നമ്മുടെ രണ്ട് വാക്യങ്ങളെ വെവ്വേറെയായും ഒരുമിച്ച് ബാച്ച് ചെയ്തും മോഡലിലൂടെ കടത്തിവിടാം:

```py no-format
model = AutoModelForSequenceClassification.from_pretrained(checkpoint)

sequence1_ids = [[200, 200, 200]]
sequence2_ids = [[200, 200]]
batched_ids = [
    [200, 200, 200],
    [200, 200, tokenizer.pad_token_id],
]

print(model(torch.tensor(sequence1_ids)).logits)
print(model(torch.tensor(sequence2_ids)).logits)
print(model(torch.tensor(batched_ids)).logits)
```

```python out
tensor([[ 1.5694, -1.3895]], grad_fn=<AddmmBackward>)
tensor([[ 0.5803, -0.4125]], grad_fn=<AddmmBackward>)
tensor([[ 1.5694, -1.3895],
        [ 1.3373, -1.2163]], grad_fn=<AddmmBackward>)
```

നമ്മുടെ ബാച്ച് ചെയ്ത പ്രവചനങ്ങളിലെ ലോജിറ്റുകളിൽ എന്തോ പിശകുണ്ട്: രണ്ടാമത്തെ വരി രണ്ടാമത്തെ വാക്യത്തിന്റെ ലോജിറ്റുകൾക്ക് തുല്യമായിരിക്കണം, പക്ഷേ നമുക്ക് ലഭിച്ചത് തീർത്തും വ്യത്യസ്തമായ മൂല്യങ്ങളാണ്!

ഓരോ ടോക്കണിനെയും *സന്ദർഭവത്കരിക്കുന്ന* (contextualize) അറ്റൻഷൻ ലെയറുകളാണ് Transformer മോഡലുകളുടെ പ്രധാന സവിശേഷത എന്നതാണ് ഇതിന് കാരണം. ഒരു സീക്വൻസിലെ എല്ലാ ടോക്കണുകളിലേക്കും ഇവ ശ്രദ്ധ കൊടുക്കുന്നതിനാൽ (attend), പാഡിംഗ് ടോക്കണുകളെയും ഇവ കണക്കിലെടുക്കും. വ്യത്യസ്ത നീളമുള്ള വാക്യങ്ങളെ വെവ്വേറെ മോഡലിലൂടെ കടത്തിവിടുമ്പോഴും, അതേ വാക്യങ്ങളെ പാഡിംഗ് പ്രയോഗിച്ച് ഒരു ബാച്ചായി കടത്തിവിടുമ്പോഴും ഒരേ ഫലം ലഭിക്കാൻ, പാഡിംഗ് ടോക്കണുകളെ അവഗണിക്കാൻ ആ അറ്റൻഷൻ ലെയറുകളോട് നമ്മൾ പറയേണ്ടതുണ്ട്. ഒരു അറ്റൻഷൻ മാസ്‌ക് ഉപയോഗിച്ചാണ് ഇത് ചെയ്യുന്നത്.

## അറ്റൻഷൻ മാസ്‌ക്കുകൾ[[attention-masks]]

*അറ്റൻഷൻ മാസ്‌ക്കുകൾ* (attention masks) എന്നത് ഇൻപുട്ട് ID-കളുടെ ടെൻസറിന്റെ അതേ ആകൃതിയുള്ള (shape), 0-കളും 1-കളും നിറഞ്ഞ ടെൻസറുകളാണ്: 1-കൾ അതത് ടോക്കണുകളിലേക്ക് ശ്രദ്ധ കൊടുക്കണം എന്ന് സൂചിപ്പിക്കുന്നു, 0-കൾ അതത് ടോക്കണുകളിലേക്ക് ശ്രദ്ധ കൊടുക്കേണ്ടതില്ല എന്ന് സൂചിപ്പിക്കുന്നു (അതായത്, മോഡലിന്റെ അറ്റൻഷൻ ലെയറുകൾ അവയെ അവഗണിക്കണം).

മുൻ ഉദാഹരണം ഒരു അറ്റൻഷൻ മാസ്‌ക് ചേർത്ത് പൂർത്തിയാക്കാം:

```py no-format
batched_ids = [
    [200, 200, 200],
    [200, 200, tokenizer.pad_token_id],
]

attention_mask = [
    [1, 1, 1],
    [1, 1, 0],
]

outputs = model(torch.tensor(batched_ids), attention_mask=torch.tensor(attention_mask))
print(outputs.logits)
```

```python out
tensor([[ 1.5694, -1.3895],
        [ 0.5803, -0.4125]], grad_fn=<AddmmBackward>)
```

ഇപ്പോൾ ബാച്ചിലെ രണ്ടാമത്തെ വാക്യത്തിന് നമുക്ക് അതേ ലോജിറ്റുകൾ ലഭിക്കുന്നു.

രണ്ടാമത്തെ സീക്വൻസിന്റെ അവസാന മൂല്യം ഒരു പാഡിംഗ് ID ആണെന്നും, അറ്റൻഷൻ മാസ്‌ക്കിൽ അത് 0 എന്ന മൂല്യമാണെന്നും ശ്രദ്ധിക്കുക.

> [!TIP]
> ✏️ **സ്വയം പരീക്ഷിക്കുക!** ഭാഗം 2-ൽ ഉപയോഗിച്ച രണ്ട് വാക്യങ്ങളിൽ ("I've been waiting for a HuggingFace course my whole life.", "I hate this so much!") ടോക്കണൈസേഷൻ സ്വയം (manually) പ്രയോഗിക്കുക. അവയെ മോഡലിലൂടെ കടത്തിവിട്ട്, ഭാഗം 2-ലെ അതേ ലോജിറ്റുകൾ തന്നെയാണ് ലഭിക്കുന്നത് എന്ന് ഉറപ്പുവരുത്തുക. ഇനി പാഡിംഗ് ടോക്കൺ ഉപയോഗിച്ച് അവയെ ഒരുമിച്ച് ബാച്ച് ചെയ്യുക, തുടർന്ന് ശരിയായ അറ്റൻഷൻ മാസ്‌ക് ഉണ്ടാക്കുക. മോഡലിലൂടെ കടത്തിവിടുമ്പോൾ അതേ ഫലങ്ങൾ തന്നെ ലഭിക്കുന്നു എന്ന് ഉറപ്പുവരുത്തുക!

## കൂടുതൽ നീണ്ട സീക്വൻസുകൾ[[longer-sequences]]

Transformer മോഡലുകളുടെ കാര്യത്തിൽ, മോഡലുകളിലേക്ക് നമുക്ക് നൽകാൻ കഴിയുന്ന സീക്വൻസുകളുടെ നീളത്തിന് ഒരു പരിധിയുണ്ട്. മിക്ക മോഡലുകളും 512 അല്ലെങ്കിൽ 1024 ടോക്കണുകൾ വരെയുള്ള സീക്വൻസുകൾ കൈകാര്യം ചെയ്യുന്നു, അതിലും നീണ്ട സീക്വൻസുകൾ പ്രോസസ്സ് ചെയ്യാൻ ആവശ്യപ്പെട്ടാൽ അവ ക്രാഷ് ആകും. ഈ പ്രശ്നത്തിന് രണ്ട് പരിഹാരങ്ങളുണ്ട്:

- കൂടുതൽ നീണ്ട സീക്വൻസ് നീളം പിന്തുണയ്ക്കുന്ന ഒരു മോഡൽ ഉപയോഗിക്കുക.
- നിങ്ങളുടെ സീക്വൻസുകൾ വെട്ടിച്ചുരുക്കുക (truncate).

വ്യത്യസ്ത മോഡലുകൾ വ്യത്യസ്ത സീക്വൻസ് നീളങ്ങളാണ് പിന്തുണയ്ക്കുന്നത്, ചിലവ വളരെ നീണ്ട സീക്വൻസുകൾ കൈകാര്യം ചെയ്യുന്നതിൽ പ്രത്യേക വൈദഗ്ധ്യമുള്ളവയാണ്. [Longformer](https://huggingface.co/docs/transformers/model_doc/longformer) ഒരു ഉദാഹരണമാണ്, മറ്റൊന്ന് [LED](https://huggingface.co/docs/transformers/model_doc/led) ആണ്. വളരെ നീണ്ട സീക്വൻസുകൾ ആവശ്യമുള്ള ഒരു ടാസ്‌ക്കിലാണ് നിങ്ങൾ പ്രവർത്തിക്കുന്നതെങ്കിൽ, ആ മോഡലുകൾ ഒന്ന് നോക്കാൻ ഞങ്ങൾ ശുപാർശ ചെയ്യുന്നു.

അല്ലാത്തപക്ഷം, `max_sequence_length` പാരാമീറ്റർ വ്യക്തമാക്കി നിങ്ങളുടെ സീക്വൻസുകൾ വെട്ടിച്ചുരുക്കാൻ ഞങ്ങൾ ശുപാർശ ചെയ്യുന്നു:

```py
sequence = sequence[:max_sequence_length]
```
