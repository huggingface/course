[Hugging Face Hub](https://huggingface.co/) –- ഞങ്ങളുടെ പ്രധാന വെബ്‌സൈറ്റ് –- അത്യാധുനിക (state-of-the-art) മോഡലുകളും ഡേറ്റാസെറ്റുകളും കണ്ടെത്താനും ഉപയോഗിക്കാനും പുതിയവ സംഭാവന ചെയ്യാനും ആർക്കും കഴിയുന്ന ഒരു കേന്ദ്ര പ്ലാറ്റ്‌ഫോമാണ്. പലതരത്തിലുള്ള മോഡലുകൾ ഇത് ഹോസ്‌റ്റ് ചെയ്യുന്നു; അവയിൽ 10,000-ത്തിലധികം പൊതുവായി ലഭ്യമാണ്. ഈ അധ്യായത്തിൽ നമ്മൾ മോഡലുകളിലാണ് ശ്രദ്ധ കേന്ദ്രീകരിക്കുന്നത്; ഡേറ്റാസെറ്റുകൾ അധ്യായം 5-ൽ നോക്കാം.

Hub-ലെ മോഡലുകൾ 🤗 Transformers-ലോ NLP-യിലോ മാത്രം ഒതുങ്ങുന്നില്ല. ചിലത് മാത്രം പറയുകയാണെങ്കിൽ, NLP-ക്കായി [Flair](https://github.com/flairNLP/flair), [AllenNLP](https://github.com/allenai/allennlp) എന്നിവയിൽ നിന്നുള്ള മോഡലുകളും, സ്പീച്ചിനായി [Asteroid](https://github.com/asteroid-team/asteroid), [pyannote](https://github.com/pyannote/pyannote-audio) എന്നിവയിൽ നിന്നുള്ളവയും, വിഷനായി [timm](https://github.com/rwightman/pytorch-image-models)-ൽ നിന്നുള്ളവയും ഇവിടെയുണ്ട്. 

ഈ മോഡലുകൾ ഓരോന്നും ഒരു Git റിപ്പോസിറ്ററിയായാണ് ഹോസ്‌റ്റ് ചെയ്യപ്പെടുന്നത്; ഇത് വേർഷനിംഗും (versioning) പുനരുൽപ്പാദനക്ഷമതയും (reproducibility) സാധ്യമാക്കുന്നു. ഒരു മോഡൽ Hub-ൽ പങ്കുവെക്കുക എന്നാൽ അത് കമ്മ്യൂണിറ്റിക്ക് തുറന്നുകൊടുക്കുകയും, എളുപ്പത്തിൽ ഉപയോഗിക്കാൻ ആഗ്രഹിക്കുന്ന ആർക്കും അത് ലഭ്യമാക്കുകയും ചെയ്യുക എന്നാണ്; അതുവഴി അവർക്ക് സ്വന്തമായി ഒരു മോഡൽ ട്രെയിൻ ചെയ്യേണ്ട ആവശ്യം ഇല്ലാതാകുകയും, പങ്കുവെക്കലും ഉപയോഗവും ലളിതമാകുകയും ചെയ്യുന്നു. 

കൂടാതെ, ഒരു മോഡൽ Hub-ൽ പങ്കുവെക്കുമ്പോൾ ആ മോഡലിനായി ഒരു ഹോസ്‌റ്റഡ് Inference API സ്വയമേവ ഡിപ്ലോയ് ചെയ്യപ്പെടുന്നു. കമ്മ്യൂണിറ്റിയിലെ ആർക്കും, സ്വന്തം ഇൻപുട്ടുകളും അനുയോജ്യമായ വിജറ്റുകളും ഉപയോഗിച്ച്, മോഡലിന്റെ പേജിൽ നേരിട്ട് അത് പരീക്ഷിച്ചുനോക്കാം.

ഏറ്റവും നല്ല കാര്യം, Hub-ലെ ഏത് പൊതു മോഡലും പങ്കുവെക്കുന്നതും ഉപയോഗിക്കുന്നതും പൂർണ്ണമായും സൗജന്യമാണ് എന്നതാണ്! മോഡലുകൾ സ്വകാര്യമായി പങ്കുവെക്കാൻ ആഗ്രഹിക്കുന്നെങ്കിൽ [പെയ്ഡ് പ്ലാനുകളും](https://huggingface.co/pricing) ലഭ്യമാണ്.

Hub-ൽ എങ്ങനെ സഞ്ചരിക്കാം (navigate) എന്ന് താഴെയുള്ള വീഡിയോ കാണിക്കുന്നു.
