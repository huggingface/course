അനുയോജ്യമായ മോഡൽ തിരഞ്ഞെടുക്കുന്നത് Model Hub ലളിതമാക്കുന്നു; അതുവഴി ഏത് ഡൗൺസ്ട്രീം ലൈബ്രറിയിലും ഏതാനും വരി കോഡ് കൊണ്ട് അത് ഉപയോഗിക്കാൻ കഴിയും. ഈ മോഡലുകളിൽ ഒന്ന് യഥാർത്ഥത്തിൽ എങ്ങനെ ഉപയോഗിക്കാമെന്നും, കമ്മ്യൂണിറ്റിക്ക് തിരികെ എങ്ങനെ സംഭാവന ചെയ്യാമെന്നും നോക്കാം.

മാസ്‌ക് ഫില്ലിംഗ് ചെയ്യാൻ കഴിയുന്ന, ഫ്രഞ്ച് ഭാഷ അടിസ്ഥാനമാക്കിയ ഒരു മോഡലാണ് നമ്മൾ തിരയുന്നത് എന്ന് കരുതുക.

ഇത് പരീക്ഷിച്ചുനോക്കാൻ നമ്മൾ `camembert-base` ചെക്ക്‌പോയിന്റ് തിരഞ്ഞെടുക്കുന്നു. ഇത് ഉപയോഗിക്കാൻ തുടങ്ങാൻ `camembert-base` എന്ന ഐഡന്റിഫയർ മാത്രം മതി! മുൻ അധ്യായങ്ങളിൽ കണ്ടതുപോലെ, `pipeline()` ഫംഗ്‌ഷൻ ഉപയോഗിച്ച് നമുക്ക് ഇത് ഇൻസ്‌റ്റാൻഷിയേറ്റ് ചെയ്യാം:

```py
from transformers import pipeline

camembert_fill_mask = pipeline("fill-mask", model="camembert-base")
results = camembert_fill_mask("Le camembert est <mask> :)")
```

നിങ്ങൾ കാണുന്നതുപോലെ, ഒരു പൈപ്പ്‌ലൈനിനുള്ളിൽ ഒരു മോഡൽ ലോഡ് ചെയ്യുന്നത് അതീവ ലളിതമാണ്. തിരഞ്ഞെടുത്ത ചെക്ക്‌പോയിന്റ് അത് ഉപയോഗിക്കാൻ പോകുന്ന ടാസ്‌ക്കിന് അനുയോജ്യമാണോ എന്നത് മാത്രമാണ് നിങ്ങൾ ശ്രദ്ധിക്കേണ്ട ഒരേയൊരു കാര്യം. ഉദാഹരണത്തിന്, ഇവിടെ നമ്മൾ `camembert-base` ചെക്ക്‌പോയിന്റ് `fill-mask` പൈപ്പ്‌ലൈനിൽ ലോഡ് ചെയ്യുന്നു, അത് തികച്ചും ശരിയാണ്. എന്നാൽ ഈ ചെക്ക്‌പോയിന്റ് `text-classification` പൈപ്പ്‌ലൈനിൽ ലോഡ് ചെയ്താൽ, ഫലങ്ങൾക്ക് ഒരു അർത്ഥവുമുണ്ടാകില്ല, കാരണം `camembert-base`-ന്റെ ഹെഡ് (head) ഈ ടാസ്‌ക്കിന് അനുയോജ്യമല്ല! അനുയോജ്യമായ ചെക്ക്‌പോയിന്റുകൾ തിരഞ്ഞെടുക്കാൻ Hugging Face Hub ഇന്റർഫേസിലെ ടാസ്‌ക് സെലക്ടർ ഉപയോഗിക്കാൻ ഞങ്ങൾ ശുപാർശ ചെയ്യുന്നു:

മോഡൽ ആർക്കിടെക്‌ചർ നേരിട്ട് ഉപയോഗിച്ചും നിങ്ങൾക്ക് ചെക്ക്‌പോയിന്റ് ഇൻസ്‌റ്റാൻഷിയേറ്റ് ചെയ്യാം:

{#if fw === 'pt'}
```py
from transformers import CamembertTokenizer, CamembertForMaskedLM

tokenizer = CamembertTokenizer.from_pretrained("camembert-base")
model = CamembertForMaskedLM.from_pretrained("camembert-base")
```

എന്നിരുന്നാലും, പകരം [`Auto*` ക്ലാസുകൾ](https://huggingface.co/transformers/model_doc/auto?highlight=auto#auto-classes) ഉപയോഗിക്കാനാണ് ഞങ്ങൾ ശുപാർശ ചെയ്യുന്നത്, കാരണം ഇവ രൂപകൽപ്പനയിൽ തന്നെ ആർക്കിടെക്‌ചർ-നിരപേക്ഷമാണ് (architecture-agnostic). മുമ്പത്തെ കോഡ് സാമ്പിൾ ഉപയോക്താക്കളെ CamemBERT ആർക്കിടെക്‌ചറിൽ ലോഡ് ചെയ്യാവുന്ന ചെക്ക്‌പോയിന്റുകളിലേക്ക് പരിമിതപ്പെടുത്തുമ്പോൾ, `Auto*` ക്ലാസുകൾ ഉപയോഗിക്കുന്നത് ചെക്ക്‌പോയിന്റുകൾ മാറ്റുന്നത് ലളിതമാക്കുന്നു:

```py
from transformers import AutoTokenizer, AutoModelForMaskedLM

tokenizer = AutoTokenizer.from_pretrained("camembert-base")
model = AutoModelForMaskedLM.from_pretrained("camembert-base")
```

from transformers import CamembertTokenizer, TFCamembertForMaskedLM

എന്നിരുന്നാലും, പകരം [`TFAuto*` ക്ലാസുകൾ](https://huggingface.co/transformers/model_doc/auto?highlight=auto#auto-classes) ഉപയോഗിക്കാനാണ് ഞങ്ങൾ ശുപാർശ ചെയ്യുന്നത്, കാരണം ഇവ രൂപകൽപ്പനയിൽ തന്നെ ആർക്കിടെക്‌ചർ-നിരപേക്ഷമാണ് (architecture-agnostic). മുമ്പത്തെ കോഡ് സാമ്പിൾ ഉപയോക്താക്കളെ CamemBERT ആർക്കിടെക്‌ചറിൽ ലോഡ് ചെയ്യാവുന്ന ചെക്ക്‌പോയിന്റുകളിലേക്ക് പരിമിതപ്പെടുത്തുമ്പോൾ, `TFAuto*` ക്ലാസുകൾ ഉപയോഗിക്കുന്നത് ചെക്ക്‌പോയിന്റുകൾ മാറ്റുന്നത് ലളിതമാക്കുന്നു:

```py
from transformers import AutoTokenizer, TFAutoModelForMaskedLM

tokenizer = AutoTokenizer.from_pretrained("camembert-base")
model = TFAutoModelForMaskedLM.from_pretrained("camembert-base")
```

> [!TIP]
> ഒരു പ്രീട്രെയിൻഡ് മോഡൽ ഉപയോഗിക്കുമ്പോൾ, അത് എങ്ങനെ ട്രെയിൻ ചെയ്തു, ഏതൊക്കെ ഡേറ്റാസെറ്റുകളിൽ, അതിന്റെ പരിമിതികൾ, അതിന്റെ പക്ഷപാതങ്ങൾ (biases) എന്നിവ പരിശോധിക്കാൻ മറക്കരുത്. ഈ വിവരങ്ങളെല്ലാം അതിന്റെ മോഡൽ കാർഡിൽ സൂചിപ്പിച്ചിരിക്കണം.
