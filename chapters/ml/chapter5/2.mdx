ഡേറ്റാസെറ്റുകൾ ഡൗൺലോഡ് ചെയ്യാൻ [Hugging Face Hub](https://huggingface.co/datasets) എങ്ങനെ ഉപയോഗിക്കണമെന്ന് നിങ്ങൾക്ക് അറിയാം, എന്നാൽ നിങ്ങളുടെ ലാപ്‌ടോപ്പിലോ ഒരു റിമോട്ട് സെർവറിലോ സൂക്ഷിച്ചിരിക്കുന്ന ഡേറ്റയുമായി പ്രവർത്തിക്കേണ്ടി വരുന്ന സാഹചര്യങ്ങൾ നിങ്ങൾക്ക് പലപ്പോഴും ഉണ്ടാകും. Hugging Face Hub-ൽ ലഭ്യമല്ലാത്ത ഡേറ്റാസെറ്റുകൾ ലോഡ് ചെയ്യാൻ 🤗 Datasets എങ്ങനെ ഉപയോഗിക്കാമെന്ന് ഈ ഭാഗത്തിൽ ഞങ്ങൾ നിങ്ങൾക്ക് കാണിച്ചുതരും.

## ലോക്കൽ, റിമോട്ട് ഡേറ്റാസെറ്റുകളുമായി പ്രവർത്തിക്കുന്നു[[working-with-local-and-remote-datasets]]

ലോക്കൽ, റിമോട്ട് ഡേറ്റാസെറ്റുകൾ ലോഡ് ചെയ്യുന്നത് കൈകാര്യം ചെയ്യാൻ 🤗 Datasets ലോഡിംഗ് സ്‌ക്രിപ്‌റ്റുകൾ (loading scripts) നൽകുന്നു. താഴെപ്പറയുന്നവ പോലുള്ള നിരവധി സാധാരണ ഡേറ്റാ ഫോർമാറ്റുകളെ ഇത് പിന്തുണയ്ക്കുന്നു:

|    ഡേറ്റാ ഫോർമാറ്റ്     | ലോഡിംഗ് സ്‌ക്രിപ്‌റ്റ് |                         ഉദാഹരണം                         |
| :----------------: | :------------: | :-----------------------------------------------------: |
|     CSV & TSV      |     `csv`      |     `load_dataset("csv", data_files="my_file.csv")`     |
|     ടെക്‌സ്‌റ്റ് ഫയലുകൾ     |     `text`     |    `load_dataset("text", data_files="my_file.txt")`     |
| JSON & JSON Lines  |     `json`     |   `load_dataset("json", data_files="my_file.jsonl")`    |
| പിക്കിൾ ചെയ്ത DataFrame-കൾ |    `pandas`    | `load_dataset("pandas", data_files="my_dataframe.pkl")` |

പട്ടികയിൽ കാണിച്ചിരിക്കുന്നതുപോലെ, ഓരോ ഡേറ്റാ ഫോർമാറ്റിനും `load_dataset()` ഫംഗ്‌ഷനിൽ ലോഡിംഗ് സ്‌ക്രിപ്‌റ്റിന്റെ തരവും, ഒന്നോ അതിലധികമോ ഫയലുകളുടെ പാത വ്യക്തമാക്കുന്ന ഒരു `data_files` ആർഗ്യുമെന്റും നൽകിയാൽ മാത്രം മതി. ലോക്കൽ ഫയലുകളിൽ നിന്ന് ഒരു ഡേറ്റാസെറ്റ് ലോഡ് ചെയ്തുകൊണ്ട് നമുക്ക് തുടങ്ങാം; റിമോട്ട് ഫയലുകളുമായി ഇതേ കാര്യം എങ്ങനെ ചെയ്യാമെന്ന് പിന്നീട് നോക്കാം.

## ഒരു ലോക്കൽ ഡേറ്റാസെറ്റ് ലോഡ് ചെയ്യുന്നു[[loading-a-local-dataset]]

ഈ ഉദാഹരണത്തിനായി നമ്മൾ [SQuAD-it ഡേറ്റാസെറ്റ്](https://github.com/crux82/squad-it/) ഉപയോഗിക്കും; ഇറ്റാലിയൻ ഭാഷയിലെ ചോദ്യോത്തരത്തിനുള്ള (question answering) ഒരു വലിയ ഡേറ്റാസെറ്റാണിത്.

ട്രെയിനിംഗ്, ടെസ്‌റ്റ് സ്‌പ്ലിറ്റുകൾ GitHub-ൽ ഹോസ്‌റ്റ് ചെയ്തിരിക്കുന്നതിനാൽ, ഒരു ലളിതമായ `wget` കമാൻഡ് ഉപയോഗിച്ച് നമുക്ക് അവ ഡൗൺലോഡ് ചെയ്യാം:

```python
!wget https://github.com/crux82/squad-it/raw/master/SQuAD_it-train.json.gz
!wget https://github.com/crux82/squad-it/raw/master/SQuAD_it-test.json.gz
```

ഇത് *SQuAD_it-train.json.gz*, *SQuAD_it-test.json.gz* എന്നീ രണ്ട് കംപ്രസ് ചെയ്ത ഫയലുകൾ ഡൗൺലോഡ് ചെയ്യും; Linux-ലെ `gzip` കമാൻഡ് ഉപയോഗിച്ച് നമുക്ക് അവ ഡീകംപ്രസ് ചെയ്യാം:

```python
!gzip -dkv SQuAD_it-*.json.gz
```

```bash
SQuAD_it-test.json.gz:	   87.4% -- replaced with SQuAD_it-test.json
SQuAD_it-train.json.gz:	   82.2% -- replaced with SQuAD_it-train.json
```

കംപ്രസ് ചെയ്ത ഫയലുകൾക്ക് പകരം _SQuAD_it-train.json_, _SQuAD_it-test.json_ എന്നിവ വന്നിരിക്കുന്നതായും, ഡേറ്റ JSON ഫോർമാറ്റിലാണ് സൂക്ഷിച്ചിരിക്കുന്നതെന്നും നമുക്ക് കാണാം.

> [!TIP]
> ✎ മുകളിലെ ഷെൽ കമാൻഡുകളിൽ എന്തിനാണ് ഒരു `!` ചിഹ്നം എന്ന് നിങ്ങൾ ആലോചിക്കുന്നുണ്ടെങ്കിൽ, അതിന് കാരണം നമ്മൾ അവ ഒരു Jupyter നോട്ട്‌ബുക്കിനുള്ളിലാണ് റൺ ചെയ്യുന്നത് എന്നതാണ്. ഒരു ടെർമിനലിനുള്ളിൽ ഡേറ്റാസെറ്റ് ഡൗൺലോഡ് ചെയ്ത് അൺസിപ്പ് ചെയ്യണമെങ്കിൽ ആ പ്രിഫിക്‌സ് ഒഴിവാക്കിയാൽ മതി.

`load_dataset()` ഫംഗ്‌ഷൻ ഉപയോഗിച്ച് ഒരു JSON ഫയൽ ലോഡ് ചെയ്യാൻ, നമ്മൾ കൈകാര്യം ചെയ്യുന്നത് സാധാരണ JSON ആണോ (ഒരു നെസ്‌റ്റഡ് ഡിക്‌ഷണറിക്ക് സമാനമായത്) അതോ JSON Lines ആണോ (വരികളായി വേർതിരിച്ച JSON) എന്ന് അറിഞ്ഞാൽ മാത്രം മതി. പല ചോദ്യോത്തര ഡേറ്റാസെറ്റുകളെയും പോലെ, SQuAD-it നെസ്‌റ്റഡ് ഫോർമാറ്റാണ് ഉപയോഗിക്കുന്നത്; എല്ലാ ടെക്‌സ്‌റ്റും ഒരു `data` ഫീൽഡിലാണ് സൂക്ഷിച്ചിരിക്കുന്നത്. അതായത്, താഴെ കാണിച്ചിരിക്കുന്നതുപോലെ `field` ആർഗ്യുമെന്റ് വ്യക്തമാക്കിക്കൊണ്ട് നമുക്ക് ഡേറ്റാസെറ്റ് ലോഡ് ചെയ്യാം:

```py
from datasets import load_dataset

squad_it_dataset = load_dataset("json", data_files="SQuAD_it-train.json", field="data")
```

ഡിഫോൾട്ടായി, ലോക്കൽ ഫയലുകൾ ലോഡ് ചെയ്യുമ്പോൾ ഒരു `train` സ്‌പ്ലിറ്റോടുകൂടിയ ഒരു `DatasetDict` ഒബ്‌ജക്റ്റ് ഉണ്ടാകുന്നു. `squad_it_dataset` ഒബ്‌ജക്റ്റ് പരിശോധിച്ചാൽ നമുക്ക് ഇത് കാണാം:

```py
squad_it_dataset
```

```python out
DatasetDict({
    train: Dataset({
        features: ['title', 'paragraphs'],
        num_rows: 442
    })
})
```

ട്രെയിനിംഗ് സെറ്റുമായി ബന്ധപ്പെട്ട വരികളുടെ എണ്ണവും കോളങ്ങളുടെ പേരുകളും ഇത് നമുക്ക് കാണിച്ചുതരുന്നു. താഴെ കാണിച്ചിരിക്കുന്നതുപോലെ `train` സ്‌പ്ലിറ്റിലേക്ക് ഇൻഡെക്‌സ് ചെയ്തുകൊണ്ട് ഉദാഹരണങ്ങളിലൊന്ന് നമുക്ക് കാണാം:

```py
squad_it_dataset["train"][0]
```

```python out
{
    "title": "Terremoto del Sichuan del 2008",
    "paragraphs": [
        {
            "context": "Il terremoto del Sichuan del 2008 o il terremoto...",
            "qas": [
                {
                    "answers": [{"answer_start": 29, "text": "2008"}],
                    "id": "56cdca7862d2951400fa6826",
                    "question": "In quale anno si è verificato il terremoto nel Sichuan?",
                },
                ...
            ],
        },
        ...
    ],
}
```

കൊള്ളാം, നമ്മുടെ ആദ്യത്തെ ലോക്കൽ ഡേറ്റാസെറ്റ് നമ്മൾ ലോഡ് ചെയ്തു! എന്നാൽ ട്രെയിനിംഗ് സെറ്റിന് ഇത് പ്രവർത്തിച്ചെങ്കിലും, നമുക്ക് ശരിക്കും വേണ്ടത് `train`, `test` സ്‌പ്ലിറ്റുകൾ രണ്ടും ഒരൊറ്റ `DatasetDict` ഒബ്‌ജക്റ്റിൽ ഉൾപ്പെടുത്തുകയാണ്; അപ്പോൾ രണ്ട് സ്‌പ്ലിറ്റുകളിലും ഒരേസമയം `Dataset.map()` ഫംഗ്‌ഷനുകൾ പ്രയോഗിക്കാൻ നമുക്ക് കഴിയും. ഇതിനായി, ഓരോ സ്‌പ്ലിറ്റിന്റെ പേരിനെയും ആ സ്‌പ്ലിറ്റുമായി ബന്ധപ്പെട്ട ഒരു ഫയലുമായി ബന്ധിപ്പിക്കുന്ന ഒരു ഡിക്‌ഷണറി `data_files` ആർഗ്യുമെന്റിന് നമുക്ക് നൽകാം:

```py
data_files = {"train": "SQuAD_it-train.json", "test": "SQuAD_it-test.json"}
squad_it_dataset = load_dataset("json", data_files=data_files, field="data")
squad_it_dataset
```

```python out
DatasetDict({
    train: Dataset({
        features: ['title', 'paragraphs'],
        num_rows: 442
    })
    test: Dataset({
        features: ['title', 'paragraphs'],
        num_rows: 48
    })
})
```

ഇതാണ് നമുക്ക് കൃത്യമായി വേണ്ടിയിരുന്നത്. ഇപ്പോൾ, ഡേറ്റ വൃത്തിയാക്കാനും റിവ്യൂകൾ ടോക്കണൈസ് ചെയ്യാനും മറ്റുമായി വിവിധ പ്രീപ്രോസസ്സിംഗ് ടെക്‌നിക്കുകൾ നമുക്ക് പ്രയോഗിക്കാം.

> [!TIP]
> `load_dataset()` ഫംഗ്‌ഷന്റെ `data_files` ആർഗ്യുമെന്റ് വളരെ ഫ്ലെക്‌സിബിൾ ആണ്; ഇത് ഒരൊറ്റ ഫയൽ പാതയോ, ഫയൽ പാതകളുടെ ഒരു ലിസ്‌റ്റോ, അല്ലെങ്കിൽ സ്‌പ്ലിറ്റ് പേരുകളെ ഫയൽ പാതകളുമായി ബന്ധിപ്പിക്കുന്ന ഒരു ഡിക്‌ഷണറിയോ ആകാം. Unix ഷെൽ ഉപയോഗിക്കുന്ന നിയമങ്ങൾ അനുസരിച്ച്, ഒരു നിശ്ചിത പാറ്റേണുമായി പൊരുത്തപ്പെടുന്ന ഫയലുകൾ glob ചെയ്യാനും നിങ്ങൾക്ക് കഴിയും (ഉദാ., `data_files="*.json"` എന്ന് സെറ്റ് ചെയ്തുകൊണ്ട് ഒരു ഡയറക്ടറിയിലെ എല്ലാ JSON ഫയലുകളും ഒരൊറ്റ സ്‌പ്ലിറ്റായി glob ചെയ്യാം). കൂടുതൽ വിവരങ്ങൾക്ക് 🤗 Datasets [ഡോക്യുമെന്റേഷൻ](https://huggingface.co/docs/datasets/loading#local-and-remote-files) കാണുക.

🤗 Datasets-ലെ ലോഡിംഗ് സ്‌ക്രിപ്‌റ്റുകൾ ഇൻപുട്ട് ഫയലുകളുടെ സ്വയമേവയുള്ള ഡീകംപ്രഷൻ യഥാർത്ഥത്തിൽ പിന്തുണയ്ക്കുന്നുണ്ട്; അതിനാൽ `data_files` ആർഗ്യുമെന്റ് നേരിട്ട് കംപ്രസ് ചെയ്ത ഫയലുകളിലേക്ക് ചൂണ്ടിക്കൊണ്ട് `gzip`-ന്റെ ഉപയോഗം നമുക്ക് ഒഴിവാക്കാമായിരുന്നു:

```py
data_files = {"train": "SQuAD_it-train.json.gz", "test": "SQuAD_it-test.json.gz"}
squad_it_dataset = load_dataset("json", data_files=data_files, field="data")
```

ധാരാളം GZIP ഫയലുകൾ സ്വയം (manually) ഡീകംപ്രസ് ചെയ്യാൻ നിങ്ങൾക്ക് താൽപ്പര്യമില്ലെങ്കിൽ ഇത് ഉപകാരപ്രദമാകും. ZIP, TAR പോലുള്ള മറ്റ് സാധാരണ ഫോർമാറ്റുകൾക്കും സ്വയമേവയുള്ള ഡീകംപ്രഷൻ ബാധകമാണ്; അതിനാൽ `data_files` കംപ്രസ് ചെയ്ത ഫയലുകളിലേക്ക് ചൂണ്ടിയാൽ മാത്രം മതി, എല്ലാം തയ്യാർ!

നിങ്ങളുടെ ലാപ്‌ടോപ്പിലോ ഡെസ്‌ക്‌ടോപ്പിലോ ഉള്ള ലോക്കൽ ഫയലുകൾ എങ്ങനെ ലോഡ് ചെയ്യാമെന്ന് ഇപ്പോൾ നിങ്ങൾക്ക് അറിയാം; ഇനി റിമോട്ട് ഫയലുകൾ ലോഡ് ചെയ്യുന്നത് നോക്കാം.

## ഒരു റിമോട്ട് ഡേറ്റാസെറ്റ് ലോഡ് ചെയ്യുന്നു[[loading-a-remote-dataset]]

നിങ്ങൾ ഒരു കമ്പനിയിൽ ഡേറ്റാ സയന്റിസ്‌റ്റായോ കോഡറായോ ജോലി ചെയ്യുന്നുണ്ടെങ്കിൽ, നിങ്ങൾ വിശകലനം ചെയ്യാൻ ആഗ്രഹിക്കുന്ന ഡേറ്റാസെറ്റുകൾ ഏതെങ്കിലും റിമോട്ട് സെർവറിലായിരിക്കാൻ നല്ല സാധ്യതയുണ്ട്. ഭാഗ്യവശാൽ, റിമോട്ട് ഫയലുകൾ ലോഡ് ചെയ്യുന്നത് ലോക്കൽ ഫയലുകൾ ലോഡ് ചെയ്യുന്നതുപോലെ തന്നെ ലളിതമാണ്! ലോക്കൽ ഫയലുകളിലേക്കുള്ള പാത നൽകുന്നതിന് പകരം, റിമോട്ട് ഫയലുകൾ സൂക്ഷിച്ചിരിക്കുന്ന ഒന്നോ അതിലധികമോ URL-കളിലേക്ക് `load_dataset()`-ന്റെ `data_files` ആർഗ്യുമെന്റ് നമ്മൾ ചൂണ്ടുന്നു. ഉദാഹരണത്തിന്, GitHub-ൽ ഹോസ്‌റ്റ് ചെയ്തിരിക്കുന്ന SQuAD-it ഡേറ്റാസെറ്റിന്, താഴെ കാണിച്ചിരിക്കുന്നതുപോലെ `data_files` _SQuAD_it-*.json.gz_ URL-കളിലേക്ക് ചൂണ്ടിയാൽ മാത്രം മതി:

```py
url = "https://github.com/crux82/squad-it/raw/master/"
data_files = {
    "train": url + "SQuAD_it-train.json.gz",
    "test": url + "SQuAD_it-test.json.gz",
}
squad_it_dataset = load_dataset("json", data_files=data_files, field="data")
```

ഇത് മുകളിൽ ലഭിച്ച അതേ `DatasetDict` ഒബ്‌ജക്റ്റ് തന്നെ റിട്ടേൺ ചെയ്യുന്നു, എന്നാൽ _SQuAD_it-*.json.gz_ ഫയലുകൾ സ്വയം ഡൗൺലോഡ് ചെയ്ത് ഡീകംപ്രസ് ചെയ്യുന്ന ഘട്ടം നമുക്ക് ലാഭിക്കാം. Hugging Face Hub-ൽ ഹോസ്‌റ്റ് ചെയ്യാത്ത ഡേറ്റാസെറ്റുകൾ ലോഡ് ചെയ്യാനുള്ള വിവിധ വഴികളിലേക്കുള്ള നമ്മുടെ ഈ ചെറുയാത്ര ഇവിടെ അവസാനിക്കുന്നു. ഇപ്പോൾ പരീക്ഷിക്കാൻ ഒരു ഡേറ്റാസെറ്റ് കൈയിലുള്ളതിനാൽ, ഡേറ്റ കൈകാര്യം ചെയ്യാനുള്ള (data-wrangling) വിവിധ ടെക്‌നിക്കുകളുമായി നമുക്ക് നേരിട്ട് ഇറങ്ങി പണിയെടുക്കാം!

> [!TIP]
> ✏️ **സ്വയം പരീക്ഷിക്കുക!** GitHub-ലോ [UCI Machine Learning Repository](https://archive.ics.uci.edu/ml/index.php)-യിലോ ഹോസ്‌റ്റ് ചെയ്തിരിക്കുന്ന മറ്റൊരു ഡേറ്റാസെറ്റ് തിരഞ്ഞെടുത്ത്, മുകളിൽ പരിചയപ്പെടുത്തിയ ടെക്‌നിക്കുകൾ ഉപയോഗിച്ച് അത് ലോക്കലായും റിമോട്ടായും ലോഡ് ചെയ്യാൻ ശ്രമിക്കുക. ബോണസ് പോയിന്റുകൾക്കായി, CSV അല്ലെങ്കിൽ ടെക്‌സ്‌റ്റ് ഫോർമാറ്റിൽ സൂക്ഷിച്ചിരിക്കുന്ന ഒരു ഡേറ്റാസെറ്റ് ലോഡ് ചെയ്യാൻ ശ്രമിക്കുക (ഈ ഫോർമാറ്റുകളെക്കുറിച്ചുള്ള കൂടുതൽ വിവരങ്ങൾക്ക് [ഡോക്യുമെന്റേഷൻ](https://huggingface.co/docs/datasets/loading#local-and-remote-files) കാണുക).
