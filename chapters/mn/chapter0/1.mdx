## Python виртуал орчин ашиглах[[using-a-python-virtual-environment]]

Хэрэв та Python виртуал орчин ашиглахыг илүүд үзвэл, эхний алхам бол системдээ Python суулгах явдал. Эхлэхийн тулд [энэ гарын авлага](https://realpython.com/installing-python/)-ыг дагахыг зөвлөж байна.

Python суулгасны дараа, терминал дээрээ Python команд ажиллуулж чадах ёстой. Дараагийн алхам руу орохоос өмнө `python --version` командыг ажиллуулж, зөв суусан эсэхийг шалгаж болно. Энэ нь таны системд одоо байгаа Python-ийн хувилбарыг хэвлэх ёстой.

Терминал дээрээ `python --version` гэх мэт Python команд ажиллуулахад, таны командыг ажиллуулж буй программыг системийн "үндсэн" Python гэж бодох хэрэгтэй. Бид энэ үндсэн суулгацыг ямар ч багцгүй цэвэр байлгаж, ажилладаг програм бүртээ тусдаа орчин үүсгэхэд ашиглахыг зөвлөж байна — ингэснээр програм бүр өөрийн хамаарал, багцтай болж, бусад програмтай зөрчилдөх асуудлаас санаа зовох хэрэггүй болно.

Python дээр үүнийг [*виртуал орчин*](https://docs.python.org/3/tutorial/venv.html)-оор хийдэг. Эдгээр нь тодорхой Python хувилбар болон програмд шаардлагатай бүх багцыг агуулсан, өөрөө агуулагдах директорийн мод юм. Ийм виртуал орчныг янз бүрийн багажаар үүсгэж болох ч, бид үүнд зориулсан албан ёсны Python багц болох [`venv`](https://docs.python.org/3/library/venv.html#module-venv)-ийг ашиглана.

Эхлээд програмаа байршуулах директороо үүсгэ — Жишээ нь: home директорийнхоо үндэс дээр *transformers-course* нэртэй шинэ директори үүсгэж болно:

```
mkdir ~/transformers-course
cd ~/transformers-course
```

Энэ директори дотроос Python-ийн `venv` модулийг ашиглан виртуал орчин үүсгэ:

```
python -m venv .env
```

Одоо хоосон байсан хавтсанд тань *.env* нэртэй директори үүссэн байх ёстой:

```
ls -a
```

```out
.      ..    .env
```

`activate`, `deactivate` скриптүүдээр виртуал орчин руугаа орж, гарч болно:

```
# Виртуал орчныг идэвхжүүлэх
source .env/bin/activate

# Виртуал орчныг идэвхгүй болгох
deactivate
```

`which python` командыг ажиллуулж орчин идэвхжсэн эсэхийг шалгаж болно: хэрэв виртуал орчин руу зааж байвал амжилттай идэвхжсэн гэсэн үг!

```
which python
```

```out
/home/<user>/transformers-course/.env/bin/python
```

### Хамааралтай сангуудыг суулгах[[installing-dependencies]]

Colab хэсэгт дурдсаны адил, одоо үргэлжлүүлэхэд шаардлагатай багцуудыг суулгах хэрэгтэй. Дахин хэлэхэд, `pip` багц менежерээр 🤗 Transformers-ийн хөгжүүлэлтийн хувилбарыг суулгаж болно:

```
pip install "transformers[sentencepiece]"
```

Одоо та бүрэн бэлэн боллоо!
