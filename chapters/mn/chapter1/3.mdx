## Pipeline-тэй ажиллах[[working-with-pipelines]]

<Youtube id="tiZFewofSLM" />

🤗 Transformers сангийн хамгийн суурь объект бол `pipeline()` функц юм. Энэ нь загварыг шаардлагатай урьдчилсан боловсруулалт болон дараах боловсруулалтын алхмуудтай холбож, бид ямар ч текстийг шууд оруулж, ойлгомжтой хариулт авах боломжийг олгодог:

```python
from transformers import pipeline

classifier = pipeline("sentiment-analysis")
classifier("I've been waiting for a HuggingFace course my whole life.")
```

```python out
[{'label': 'POSITIVE', 'score': 0.9598047137260437}]
```

Бид бүр хэд хэдэн өгүүлбэр дамжуулж болно!

```python
classifier(
    ["I've been waiting for a HuggingFace course my whole life.", "I hate this so much!"]
)
```

```python out
[{'label': 'POSITIVE', 'score': 0.9598047137260437},
 {'label': 'NEGATIVE', 'score': 0.9994558095932007}]
```

Анхдагч байдлаар энэ pipeline нь англи хэлний сэтгэгдлийн хандлагын шинжилгээнд (sentiment analysis) fine-tune хийгдсэн тодорхой нэг урьдчилан сургагдсан загварыг сонгодог. `classifier` объектыг үүсгэх үед загвар татагдаж, кэшлэгдэнэ. Командыг дахин ажиллуулбал кэшлэгдсэн загвар ашиглагдах тул загварыг дахин татах шаардлагагүй.

Pipeline руу текст дамжуулахад гурван үндсэн алхам хийгддэг:

1. Текстийг загварын ойлгох формат руу урьдчилан боловсруулна.
2. Урьдчилан боловсруулсан оролтыг загвар руу дамжуулна.
3. Загварын таамаглалыг таны ойлгохуйц байдлаар дараах боловсруулалт хийнэ.

## Өөр өөр модальд зориулсан боломжит pipeline-ууд

`pipeline()` функц нь олон модалийг дэмждэг бөгөөд текст, зураг, аудио, тэр байтугай мультимодал даалгавруудтай ажиллах боломжийг олгодог. Энэ курст бид текстийн даалгаварт анхаарлаа хандуулах боловч transformer архитектурын боломжийг ойлгох нь хэрэгтэй тул товч тоймлон үзье.

Ашиглах боломжтой зүйлсийн ерөнхий тойм:

> [!TIP]
> Pipeline-уудын бүрэн, шинэчлэгдсэн жагсаалтыг [🤗 Transformers баримт бичиг](https://huggingface.co/docs/hub/en/models-tasks)-ээс харж болно.

### Текстийн pipeline-ууд

- `text-generation`: Prompt-оос текст үүсгэх
- `text-classification`: Текстийг урьдчилан тодорхойлсон ангилалд хуваах
- `summarization`: Гол мэдээллийг хадгалан текстийн богино хувилбар үүсгэх
- `translation`: Текстийг нэг хэлнээс нөгөө хэл рүү орчуулах
- `zero-shot-classification`: Тодорхой шошгон дээр урьдчилан сургалгүйгээр текстийг ангилах
- `feature-extraction`: Текстийн вектор дүрслэлийг гаргаж авах

### Зургийн pipeline-ууд

- `image-to-text`: Зургийн текстэн тайлбар үүсгэх
- `image-classification`: Зураг дээрх объектыг таних
- `object-detection`: Зураг дээрх объектуудын байршлыг тогтоож, таних

### Аудио pipeline-ууд

- `automatic-speech-recognition`: Яриаг текст рүү хөрвүүлэх
- `audio-classification`: Аудиог ангилалд хуваах
- `text-to-speech`: Текстийг яриа (аудио) болгон хөрвүүлэх

### Мультимодал pipeline-ууд

- `image-text-to-text`: Текст prompt-д үндэслэн зурагт хариулах

Эдгээр pipeline-уудын заримыг илүү дэлгэрэнгүй судалцгаая!

## Zero-shot ангилал[[zero-shot-classification]]

Бид шошголоогүй текстүүдийг ангилах шаардлагатай илүү хэцүү даалгавраас эхэлье. Текстийг шошголох нь ихэвчлэн их цаг зарцуулдаг бөгөөд тухайн салбарын мэдлэг шаарддаг тул энэ нь бодит төслүүдэд түгээмэл тохиолддог нөхцөл юм. Ийм тохиолдолд `zero-shot-classification` pipeline маш хүчирхэг: энэ нь ангилалд ямар шошго ашиглахыг өөрөө тодорхойлох боломж олгодог тул урьдчилан сургагдсан загварын шошгонд найдах шаардлагагүй. Загвар өгүүлбэрийг эерэг эсвэл сөрөг гэсэн хоёр шошгоор хэрхэн ангилж болохыг та аль хэдийн харсан — гэхдээ энэ нь таны хүссэн өөр ямар ч шошгоны багцаар текстийг ангилж чадна.

```python
from transformers import pipeline

classifier = pipeline("zero-shot-classification")
classifier(
    "This is a course about the Transformers library",
    candidate_labels=["education", "politics", "business"],
)
```

```python out
{'sequence': 'This is a course about the Transformers library',
 'labels': ['education', 'business', 'politics'],
 'scores': [0.8445963859558105, 0.111976258456707, 0.043427448719739914]}
```

Энэ pipeline-ийг _zero-shot_ гэж нэрлэдэг шалтгаан нь та үүнийг ашиглахын тулд загвараа өөрийн өгөгдөл дээр fine-tune хийх шаардлагагүй. Энэ нь таны хүссэн ямар ч шошгоны жагсаалтад магадлалын оноог шууд буцааж чадна!

> [!TIP]
> ✏️ **Туршаад үзээрэй!** Өөрийн өгүүлбэр, шошгуудаар туршиж, загвар хэрхэн ажиллахыг ажиглаарай.


## Текст үүсгэх[[text-generation]]

Одоо pipeline ашиглан текст хэрхэн үүсгэхийг харцгаая. Гол санаа нь та prompt өгөхөд загвар үлдсэн текстийг үүсгэн автоматаар гүйцээнэ. Энэ нь олон утсанд байдаг таамаглах текст (predictive text) функцтэй төстэй. Текст үүсгэх нь санамсаргүй байдлыг агуулдаг тул доор харуулсантай ижил үр дүн гарахгүй байх нь хэвийн.

```python
from transformers import pipeline

generator = pipeline("text-generation")
generator("In this course, we will teach you how to")
```

```python out
[{'generated_text': 'In this course, we will teach you how to understand and use '
                    'data flow and data interchange when handling user data. We '
                    'will be working with one or more of the most commonly used '
                    'data flows — data flows of various types, as seen by the '
                    'HTTP'}]
```

`num_return_sequences` аргументаар хэдэн өөр дараалал үүсгэхийг, `max_length` аргументаар гаралтын текстийн нийт уртыг хянаж болно.

> [!TIP]
> ✏️ **Туршаад үзээрэй!** `num_return_sequences` болон `max_length` аргументуудыг ашиглан тус бүр 15 үгтэй хоёр өгүүлбэр үүсгээрэй.

## Hub-аас дурын загварыг pipeline-д ашиглах[[using-any-model-from-the-hub-in-a-pipeline]]

Өмнөх жишээнүүд тухайн даалгаврын анхдагч загварыг ашигласан боловч та тодорхой даалгаварт — жишээлбэл текст үүсгэхэд — pipeline-д ашиглах загвараа Hub-аас сонгож болно. [Model Hub](https://huggingface.co/models) руу орж, зүүн талд байгаа харгалзах шошгон дээр дарж зөвхөн тухайн даалгаврыг дэмждэг загваруудыг харуулаарай. Та [ийм](https://huggingface.co/models?pipeline_tag=text-generation) хуудас руу орох ёстой.

[`HuggingFaceTB/SmolLM2-360M`](https://huggingface.co/HuggingFaceTB/SmolLM2-360M) загварыг туршаад үзье! Өмнөхтэй ижил pipeline-д хэрхэн ачаалахыг доор харуулав:

```python
from transformers import pipeline

generator = pipeline("text-generation", model="HuggingFaceTB/SmolLM2-360M")
generator(
    "In this course, we will teach you how to",
    max_length=30,
    num_return_sequences=2,
)
```

```python out
[{'generated_text': 'In this course, we will teach you how to manipulate the world and '
                    'move your mental and physical capabilities to your advantage.'},
 {'generated_text': 'In this course, we will teach you how to become an expert and '
                    'practice realtime, and with a hands on experience on both real '
                    'time and real'}]
```

Та хэлний шошго дээр дарж загварын хайлтыг илүү нарийвчлах боломжтой бөгөөд өөр хэлээр текст үүсгэх загварыг сонгож болно. Model Hub-д хэд хэдэн хэлийг зэрэг дэмждэг олон хэлний загваруудын checkpoint-ууд ч мөн агуулагддаг.

Загвар дээр дарж сонгосны дараа түүнийг онлайнаар шууд туршиж үзэх боломжтой виджет байгааг харах болно. Ингэснээр загварыг татахаасаа өмнө түүний чадварыг хурдан туршиж болно.

> [!TIP]
> ✏️ **Туршаад үзээрэй!** Шүүлтүүрүүдийг ашиглан өөр хэлний текст үүсгэх загвар олоорой. Виджеттэй тоглож, pipeline-д ашиглаад үзээрэй!

### Inference Providers[[inference-providers]]

Бүх загварыг Hugging Face-ийн [вэбсайт](https://huggingface.co/docs/inference-providers/en/index) дээр байдаг Inference Providers-ийг ашиглан хөтөч дээрээсээ шууд туршиж болно. Энэ хуудсан дээр өөрийн текстийг оруулж, загвар оролтын өгөгдлийг хэрхэн боловсруулахыг харж загвартай шууд тоглож болно.

Виджетийг ажиллуулдаг Inference Providers нь төлбөртэй бүтээгдэхүүн хэлбэрээр бас байдаг бөгөөд таны ажлын урсгалд хэрэгтэй бол ашигтай. Дэлгэрэнгүйг [үнийн хуудас](https://huggingface.co/docs/inference-providers/en/pricing)-аас үзнэ үү.

## Маск нөхөх[[mask-filling]]

Таны турших дараагийн pipeline бол `fill-mask`. Энэ даалгаврын санаа нь өгөгдсөн текст дэх хоосон зайг нөхөх явдал юм:

```python
from transformers import pipeline

unmasker = pipeline("fill-mask")
unmasker("This course will teach you all about <mask> models.", top_k=2)
```

```python out
[{'sequence': 'This course will teach you all about mathematical models.',
  'score': 0.19619831442832947,
  'token': 30412,
  'token_str': ' mathematical'},
 {'sequence': 'This course will teach you all about computational models.',
  'score': 0.04052725434303284,
  'token': 38163,
  'token_str': ' computational'}]
```

`top_k` аргумент нь хэдэн боломжит хувилбарыг харуулахыг хянадаг. Энд загвар тусгай `<mask>` үгийг нөхөж байгааг анхаараарай, үүнийг ихэвчлэн *маск token* гэж нэрлэдэг. Бусад маск нөхөх загварууд өөр маск token-той байж болох тул өөр загвар судлахдаа зөв маск үгийг шалгах нь үргэлж зүйтэй. Шалгах нэг арга нь виджетэд ашиглагдсан маск үгийг харах явдал юм.

> [!TIP]
> ✏️ **Туршаад үзээрэй!** Hub дээрээс `bert-base-cased` загварыг хайж, Inference API виджет дэх маск үгийг нь олоорой. Дээрх `pipeline` жишээн дэх өгүүлбэрт энэ загвар юу таамаглаж байна вэ?

## Нэрлэсэн объект таних[[named-entity-recognition]]

Нэрлэсэн объект таних (NER) нь оролтын текстийн аль хэсэг нь хүн, байршил, байгууллага зэрэг объектод харгалзаж байгааг загвар олох даалгавар юм. Жишээ харцгаая:

```python
from transformers import pipeline

ner = pipeline("ner", aggregation_strategy="simple")
ner("My name is Sylvain and I work at Hugging Face in Brooklyn.")
```

```python out
[{'entity_group': 'PER', 'score': 0.99816, 'word': 'Sylvain', 'start': 11, 'end': 18}, 
 {'entity_group': 'ORG', 'score': 0.97960, 'word': 'Hugging Face', 'start': 33, 'end': 45}, 
 {'entity_group': 'LOC', 'score': 0.99321, 'word': 'Brooklyn', 'start': 49, 'end': 57}
]
```

Энд загвар Sylvain-ийг хүн (PER), Hugging Face-ийг байгууллага (ORG), Brooklyn-ийг байршил (LOC) гэж зөв таньсан.

Бид pipeline үүсгэх функцэд `aggregation_strategy="simple"` сонголтыг дамжуулж, өгүүлбэрийн нэг объектод харгалзах хэсгүүдийг дахин нэгтгэхийг pipeline-д зааж өгсөн: энд нэр нь олон үгээс бүрдсэн ч загвар "Hugging", "Face"-ийг нэг байгууллага болгон зөв бүлэглэсэн. Үнэндээ дараагийн бүлэгт харах ёсоор урьдчилсан боловсруулалт зарим үгийг бүр жижиг хэсгүүдэд хуваадаг. Жишээлбэл: `Sylvain` нь `S`, `##yl`, `##va`, `##in` гэсэн дөрвөн хэсэгт хуваагддаг. Дараах боловсруулалтын алхамд pipeline эдгээр хэсгүүдийг амжилттай дахин нэгтгэсэн.

> [!TIP]
> ✏️ **Туршаад үзээрэй!** Model Hub-аас англи хэлний үгийн аймгийг тэмдэглэх (part-of-speech tagging, ихэвчлэн POS гэж товчилдог) чадвартай загвар хайгаарай. Дээрх жишээн дэх өгүүлбэрт энэ загвар юу таамаглаж байна вэ?

## Асуултад хариулах[[question-answering]]

`question-answering` pipeline нь өгөгдсөн контекстийн мэдээллийг ашиглан асуултад хариулдаг:

```python
from transformers import pipeline

question_answerer = pipeline("question-answering")
question_answerer(
    question="Where do I work?",
    context="My name is Sylvain and I work at Hugging Face in Brooklyn",
)
```

```python out
{'score': 0.6385916471481323, 'start': 33, 'end': 45, 'answer': 'Hugging Face'}
```

Энэ pipeline нь өгөгдсөн контекстээс мэдээлэл гаргаж авах замаар ажилладаг бөгөөд хариултыг шинээр үүсгэдэггүй гэдгийг анхаараарай.

## Хураангуйлах[[summarization]]

Хураангуйлах гэдэг нь текстэд дурдагдсан чухал талуудыг бүгдийг (эсвэл ихэнхийг) хадгалан текстийг илүү богино болгох даалгавар юм. Жишээ:

```python
from transformers import pipeline

summarizer = pipeline("summarization")
summarizer(
    """
    America has changed dramatically during recent years. Not only has the number of 
    graduates in traditional engineering disciplines such as mechanical, civil, 
    electrical, chemical, and aeronautical engineering declined, but in most of 
    the premier American universities engineering curricula now concentrate on 
    and encourage largely the study of engineering science. As a result, there 
    are declining offerings in engineering subjects dealing with infrastructure, 
    the environment, and related issues, and greater concentration on high 
    technology subjects, largely supporting increasingly complex scientific 
    developments. While the latter is important, it should not be at the expense 
    of more traditional engineering.

    Rapidly developing economies such as China and India, as well as other 
    industrial countries in Europe and Asia, continue to encourage and advance 
    the teaching of engineering. Both China and India, respectively, graduate 
    six and eight times as many traditional engineers as does the United States. 
    Other industrial countries at minimum maintain their output, while America 
    suffers an increasingly serious decline in the number of engineering graduates 
    and a lack of well-educated engineers.
"""
)
```

```python out
[{'summary_text': ' America has changed dramatically during recent years . The '
                  'number of engineering graduates in the U.S. has declined in '
                  'traditional engineering disciplines such as mechanical, civil '
                  ', electrical, chemical, and aeronautical engineering . Rapidly '
                  'developing economies such as China and India, as well as other '
                  'industrial countries in Europe and Asia, continue to encourage '
                  'and advance engineering .'}]
```

Текст үүсгэхтэй адил үр дүнгийн `max_length` эсвэл `min_length`-ийг зааж өгч болно.


## Орчуулга[[translation]]

Орчуулгын хувьд даалгаврын нэрэнд хэлний хос (жишээ нь `"translation_en_to_fr"`) зааж өгвөл анхдагч загварыг ашиглаж болох ч хамгийн хялбар арга нь [Model Hub](https://huggingface.co/models)-аас ашиглах загвараа сонгох юм. Энд бид франц хэлнээс англи хэл рүү орчуулж үзье:

```python
from transformers import pipeline

translator = pipeline("translation", model="Helsinki-NLP/opus-mt-fr-en")
translator("Ce cours est produit par Hugging Face.")
```

```python out
[{'translation_text': 'This course is produced by Hugging Face.'}]
```

Текст үүсгэх, хураангуйлахтай адил үр дүнгийн `max_length` эсвэл `min_length`-ийг зааж өгч болно.

> [!TIP]
> ✏️ **Туршаад үзээрэй!** Өөр хэлүүдийн орчуулгын загвар хайж, өмнөх өгүүлбэрийг хэд хэдэн өөр хэл рүү орчуулж үзээрэй.

## Олон эх сурвалжийн өгөгдлийг нэгтгэх

Transformer загваруудын хүчирхэг хэрэглээний нэг нь олон эх сурвалжийн өгөгдлийг нэгтгэж боловсруулах чадвар юм. Энэ нь дараах үед ялангуяа хэрэгтэй:

1. Олон өгөгдлийн сан эсвэл репозиторид хайлт хийх
2. Өөр өөр форматын (текст, зураг, аудио) мэдээллийг нэгтгэх
3. Холбогдох мэдээллийн нэгдсэн дүр зургийг бий болгох

Жишээлбэл: Та дараах системийг бүтээж болно:
- Текст, зураг гэх мэт олон модалийн өгөгдлийн сангаас мэдээлэл хайх.
- Өөр өөр эх сурвалжийн үр дүнг нэг уялдаатай хариулт болгон нэгтгэх. Жишээ нь аудио файл болон текст тайлбараас.
- Баримт бичиг, мета өгөгдлийн сангаас хамгийн хамааралтай мэдээллийг харуулах.

## Дүгнэлт

Энэ бүлэгт үзүүлсэн pipeline-ууд нь голдуу жишээ харуулах зориулалттай. Тэдгээр нь тодорхой даалгаварт зориулан програмчлагдсан бөгөөд түүний хувилбаруудыг гүйцэтгэж чадахгүй. Дараагийн бүлэгт та `pipeline()` функцийн дотор юу байдгийг болон түүний ажиллагааг хэрхэн өөрчлөхийг сурах болно.
